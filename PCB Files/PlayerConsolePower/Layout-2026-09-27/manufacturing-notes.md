# R1 RC1 制造与装配说明

本版本是完整布线的制造候选。README 中的 FPC、电池、原理图警告和制造/首板条件尚未闭合，不能凭本文件跳过确认直接批量生产。

## 制板参数

| 参数 | 值 |
| --- | --- |
| 外形 | 80×80 mm，四角 R5；按 GKO 加工 |
| 层数/厚度 | 2 层，标称 1.6 mm；原生叠层总厚度约 1.600 mm |
| 材料/外层铜 | FR-4，1 oz；阻抗相关介质参数由板厂复核 |
| 表面处理建议 | ENIG，适用于本版细间距器件；板厂工艺确认优先 |
| 阻焊/丝印 | 双面阻焊、顶面白色丝印；底面无装配器件 |
| 最小设计线宽/线间规则 | 0.15 mm / 约 0.102 mm；不要选择要求更大间隙而未经复核的工艺 |
| 最小过孔 | 标称孔 0.30 mm、盘 0.60 mm；原生单位量化值为约 0.29972/0.59944 mm |
| 安装孔 | 4×3.4 mm 镀通孔，中心(5,5)/(75,5)/(75,75)/(5,75) mm |
| 其他孔 | J1 固定槽/定位孔，J3 电池焊线孔；按 PTH/NPTH 文件区分 |

79 个过孔均设置双面阻焊覆盖。U1 EP 区顶面仍须开窗焊接，位于 EP 内的四个孔不会因单独过孔盖油设置而消失；底面盖油。未指定树脂塞孔/填孔。需贴装厂确认该过孔/钢网组合可接受，避免吸锡影响 EP 焊接；不是已取得工厂确认。

U1 EP 锡膏边界每边缩进 0.15 mm，约保留 70% 面积。其余焊盘按原生封装钢网层；0.1 mm 钢网仅作为与工厂讨论的起点，最终开窗/分窗由装配工艺确认。[JLC 过孔覆盖说明](https://jlcpcb.com/help/article/pcb-via-covering)

丝印位号采用 1.0 mm 字高、0.15 mm 线宽。J1/J2 库封装外壳丝印有少量超出板框，属于连接器伸出边界，板厂裁掉板外油墨即可；铜焊盘未被挪出板框。USB 5V/DATA、BAT+/BAT−、POWER/RST 与 FPC PIN1=D− 为功能文字，不代替位号。

## 装配

1. 只上传 Manufacturing-RC1 内的 Gerber、BOM、CPL，三者是同一版。CSV 已规范为 UTF-8；CPL 坐标带 mm 单位、Y 下方为负，保持原生 datum。不要自行翻转 Y 或镜像顶层。
2. 67 件顶面贴装，J3 仅裸孔手工焊电池正负两线，不装排针。焊后另做线材应力固定。
3. 装配平台逐件复核 U1/U2/U5/U7/U9/U10 Pin1、D1/Q1/Q2/Q3 极性、J1/J2 开口方向及 SW1/SW2。CPL 旋转与 EDA 一致，不代表供应商零度库自动一致。
4. J2 物理焊盘 1=D−、2=D+、3=RST、4=屏幕TX、5=屏幕RX、6/7/9=NC、8=GND、10=5V、11/12=固定脚GND。母座候选为 C2856798，下接点、要求尾端 0.30±0.03 mm，实物未确认前不得替换为同针距任意母座。
5. 接受普通 1S 4.2 V 终止充电的受保护电池。J3.1=BAT+，J3.2=GND；本板没有反接保护。不能把 USB 5V 接到电池焊盘。
6. 下单前重新核实料号、贴装库存和损耗，尤其 SC18IM704 C5190383。现有库存快照不代表采购占用。

## 文件规范化

原生导出 CSV 实际为 UTF-16 制表符文件，现转换为标准 CSV。原生贴片坐标包含 J3，其不在 BOM 中，已明确排除。BOM/CPL 最终均是相同的 67 个位号。

原生 Gerber 中 `Drill_PTH_Through.DRL` 共 89 个孔/槽对象，已经含 79 个过孔；`Drill_PTH_Through_Via.DRL` 的 79 条为重复子集。规范包去掉后者，保留一份 PTH 与一份 NPTH，另有 8 个必需 Gerber 层。未修改铜/阻焊/钢网/板框几何。原始文件在 NativeExports，仅供核对。

制造前还需板厂 DFM、装配预览和 USB 叠层复核。首件通过 bringup-checklist.md 后再判断后续批量放行；本任务没有创建订单或发送文件给板厂。
