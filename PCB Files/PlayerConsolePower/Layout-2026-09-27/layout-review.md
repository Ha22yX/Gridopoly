## 同步与固定几何

布局前后均按器件唯一编号比较原理图/PCB，而非按画布上的名字猜测。68 个器件、243 个引脚完全一致。POWER/RST 原先作为 PCB 位号，与原理图 SW1/SW2 不一致；恢复正式位号后，原生网表差异消失，同时在原标识位置保留 POWER/RST 功能字样。没有把导入按钮返回超时当作同步成功证据。

原生坐标以左上板框为基准，X 向右，Y 向上（下方为负）；下表 Y 为便于机械阅读的向下正值，角度为 EDA 原生角度。

| --- | ---: | ---: | ---: |
| J1 USB-C | 40.000 | 75.438 | 0° |
| J2 FPC | 3.810 | 58.801 | 270° |
| SW1 POWER | 75.311 | 26.792 | 90° |

四孔保留原有 3.4 mm 镀通孔、5 mm 铜环及不接网属性，没有擅自改成非镀孔；每孔附近设置半径 4 mm 的元件/走线/铜保护区。板框的八段原生路径保持不变。固定位置逐字段核对证据见 fixed-constraints.json 与 layout-verification.json。

## 布局依据

- USB-C 附近放置 ESD、Type-C 电流能力识别及输入部分。USB 数据沿左下区域经过 U7 至左侧 J2，避开右側电感和开关节点。
- U1 BQ24074 靠近输入和系统电源，输入/电池/系统电容就近；EP 接上下地铜，配置四个散热过孔。
- U2 TPS61023 与 L1、C7、C8/C9 集中布局，手工布置开关功率回路。SW 铜只连接电感与芯片，反馈分压靠近 FB，避免把反馈线穿过电感/开关铜。
- 5V 主干主要为顶面宽线，局部换层处配置并联过孔。电池焊线孔附近放置电量计，C19 紧靠其供电端；电池连接不占用板上电池托架。
- U9 串口/I²C 桥靠近 J2，其稳压与去耦电容在附近。电量计常供电域和屏幕开关供电域按原理图分别连接。
- 欠压检测和开关锁存在右侧 POWER 按键附近，避开升压 SW；RST 通过既定走线直接控制屏幕复位。
- 独立旋转变换后比较全部 68 个封装包络，无相交。包络检查不能替代实际排线弯折、插拔空间或外壳验证。

布局依据：[TI TPS61023 数据手册 Layout](https://www.ti.com/lit/ds/symlink/tps61023.pdf)、[TI BQ24074 数据手册 Layout](https://www.ti.com/lit/ds/symlink/bq24074.pdf)、[TI TS3USB221A](https://www.ti.com/lit/ds/symlink/ts3usb221a.pdf)。

## 布线与规则

两层板，全部贴装在顶层。手工完成关键电源与 USB 连接，其余信号使用原生布线后检查并修正；删除/重布了靠近 USB 宽线的冲突地过孔/短线，重新铺铜后运行严格 DRC。

| 项目 | 当前值/状态 |
| --- | --- |
| 线段、过孔 | 532、79 |
| GND 铜 | 顶、底两层；底层主要作为参考地 |
| 信号线 | 通常 0.20 mm，允许最小 0.15 mm |
| 线间规则 | 最小约 0.102 mm；线到焊盘/过孔约 0.152 mm，铜区间隙 0.254 mm |
| 电源线 | 命名规则默认 0.40 mm；主功率通路 0.8–1.2 mm、细间距扇出局部减小 |
| 过孔 | 标称 0.60/0.30 mm；原生布线器部分为 0.61/0.305 mm |
| USB 主线 | 顶层约 1.15 mm 宽、0.20 mm 间距；短扇出为 0.20–0.25 mm |
| USB 参考铜 | 顶层两处禁止铺铜区避免宽差分线旁不受控的近铜；底层提供主要参考 |
| 原生 PCB DRC | 严格检查返回空数组；没有未连接、短路、间距或网表差异条目 |

USB 为 ESP32-S3 原生全速链路。为处理 USB-C 双方向引脚和 J2 反向脚序，D− 有局部底层跨线；D+/D− 的过孔数不相等。导出的总线段长度为 HOST D+ 24.0134 mm / D− 25.2530 mm，SCREEN D+ 22.9682 mm / D− 25.0095 mm；其中 HOST 含分支，这些数值不是精确端到端时延。没有启用正式差分对等长验收，也没有把这些线宽称为板厂已验证的 90Ω 控阻。USB 波形/可靠枚举与实物排线影响仍须首板验收；若板厂叠层/阻抗复核要求调整，须在保留固定接口位置的前提下调整线宽间距并重新 DRC、导出。

参考：[Espressif USB 布局要求](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/pcb-layout-design.html)、[板厂阻抗计算器说明](https://jlcpcb.com/help/article/user-guide-to-the-jlcpcb-impedance-calculator)。本次未获得板厂阻抗确认单。
