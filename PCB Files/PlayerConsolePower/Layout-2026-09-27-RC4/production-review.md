# R1 RC4 电池插座更换复核

用户要求将 J3 改成可插拔电池连接器。本轮以 RC3 为起点，只更换 J3 及其局部连接、必要的说明和版本丝印；未重做既有整板电气设计。[RC3 全面审查](../Layout-2026-09-27-RC3/production-review.md)中的电源、USB、FPC、温升与实测限制继续适用。

## 更改与检查

J3 从不装配的 2.54 mm 裸焊线孔改为 JST B2B-PH-K-S(LF)(SN)，C131337，封装 CONN-TH_B2B-PH-K-S，位于 (40,5) mm、旋转 180°。唯一编号 gge60 保留；1=BAT_PACK、2=GND。PCB 顶视图左正右负，原有 BAT+/BAT− 文字保留，J3 位号移动到插座上方。原理图网络端口重新连接至新符号实际引脚；用户已完成“导入更新”，最终严格 PCB DRC 返回空列表。

器件库初始孔径及 API 孔属性存在单位回读差异，不能直接用回读数值当毫米。最终以实际 Excellon 钻孔复核：两孔均 0.80 mm，分别约 (38.9992,-5.0013)/(41.0007,-5.0013) mm。铜盘直径约 1.60 mm；制造孔距约 2.0015 mm。孔径按 JST 0.7～0.8 mm 推荐范围选 0.80 mm，生产公差由板厂 DFM 确认。封装外壳约 5.9×4.5 mm，连接器本体约 6 mm 高，插上线束后约 8 mm，并需留电线弯曲空间。[JST PH 图纸](https://www.jst.co.uk/downloads/series/TSSC017.01(PH).pdf)

仅调整两段 BAT_PACK 末端走线接到新正极焊盘，保持 0.6 mm 线宽；重铺地铜。其他 67 件位置、82 个过孔和全部电气引脚网络与 RC3 一致。USB-C、FPC、POWER/RST、板框与四个安装孔均保持。J3 更换检查 9/9、原有布局/网表/制造检查 34/34 通过；41 网实际铜层连通性检查通过。顶面 Gerber 预览已查看，正负极文字对应实际孔位。

BOM 和 CPL 各增加 J3，当前为 68 个装配位号、30 个料号，其中 67 件 SMT、1 件直插。立创产品页查询库存为 76,900，未锁料；JLC 页面将该型号列为插件波峰焊，标准型装配需包含这项工艺或明确后焊。[LCSC](https://www.lcsc.com/product-detail/C131337.html) · [JLC 装配属性](https://jlcpcb.com/partdetail/JST-B2B_PH_K_S_LF_SN/C131337)

## 电池连接和保留事项

配对插壳为 PHR-2，压接端子与线径遵从 PH 数据手册。建议 AWG24 短线，2 A 额定值适用于相应线径与合格压接；截图只写“2.0”不足以证明就是 PH 系列。采购时明确 PH2.0-2P 和本板针号，实物上电前测量红线电池正极到 J3.1、黑线负极到 J3.2。塑壳防错插不等于电池反接保护，本板仍没有反接保护。

原理图 API 仍只给出 41 条 warning 总数，未分类；FPC 尾端厚度、500 mA/触点与实际屏幕负载、电池保护与电流、USB 电气/热/欠压/充电和首板验收仍待完成。新连接器不改变这些门槛。本轮未改固件、未操作串口、未下单，也没有进行物理插接测试。
