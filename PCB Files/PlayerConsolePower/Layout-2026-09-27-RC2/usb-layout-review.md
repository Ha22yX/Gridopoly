# RC2 USB 路径与地铜复核

2026-09-27。对象为 J1 → D1 → U7 → J2。检查依据为原生走线/焊盘/过孔数据、导出的 Gerber 铜层及原生严格 DRC。结论：修复了一处可避免的 D− 换层，缩短两处底层交叉，并补充局部地连接；PCB DRC 为 0，所有器件位置、电源走线和原有非 USB 网络保持不变。USB 的控阻和实板电气性能尚未验证。

TI 对 U7 的布局建议包括电源脚就近去耦、减少过孔和转角、成对匹配以及连续参考平面；其高速设计指导推荐四层。[TS3USB221A 数据手册，第 8.3–8.4 节](https://www.ti.com/lit/ds/symlink/ts3usb221a.pdf)。本板遵循用户优先双层的约束，不能声称已满足该四层参考设计的全部条件。

## 具体修改

J1 的 USB2.0 引脚横向顺序为 B7(D−)、A6(D+)、A7(D−)、B6(D+)。在固定 J1、ESD、U7 布局下，RC1 将两个 D− 分支都绕到底层，再在 D1 前回顶层。RC2 让 B7 直接在顶层接 D1.4；A7 保留两过孔的小跨线接回 B7。移除 D1 前的第三个 D− 过孔。D+ 路径和过孔数保持不变，没有为配平数量增加过孔。

U7 到 J2 的引脚上下顺序相反，J2 又必须保持用户确认的物理镜像映射。RC2 保留 D− 的局部换层，改为短直底层跨线，两个端点为 (12,57.9) 与 (12,56.35) mm，坐标 Y 向下。该调整缩短底层铜长，但 D− 总平面长度稍有增加。

| 项目 | RC1 | RC2 |
| --- | ---: | ---: |
| USB_HOST_D− 网络过孔数 | 3 | 2 |
| USB_HOST_D− 底层铜长 | 4.189 mm | 0.998 mm |
| SCREEN_D− 网络过孔数 | 2 | 2 |
| SCREEN_D− 底层铜长 | 2.776 mm | 1.550 mm |
| 新增地过孔 | — | 5 |

新增 GND 过孔坐标 (X,Y向下，mm)：(11.05,57.8)、(13,56.15)、(14.9,59)、(14.9,60.96)、(27.35,62.75)。全部标称盘 0.6 / 孔 0.3 mm，并请求双面盖油。

C16 到 U7 电源脚原本为约 1.85 mm 的顶层短连接，地端就近接地过孔，本版保留。充电、升压反馈/热回路、1 mm 屏幕电源通路和原有所有非 USB 过孔保持不变。首次尝试的过孔位置产生了 4 项间隙错误；在最终版本中调整位置后重新铺铜，严格 DRC 为 0。

## 实际导出铜层的回流检查

使用 gerbonara 解析 GTL/GBL，以 0.001 mm 圆弧近似误差进行 Shapely 布尔运算，按 CAD 地焊盘和过孔识别地铜。两层都未发现已知非地焊盘落入识别出的地铜。5 个新增 GND 过孔全部在两面连到地铜。

顶层地铜有两条可确认的连续短连接：

- (14.9,59) ↔ (14.9,60.96)，1.960 mm，跨越底层 5V_SCREEN 走线附近。
- 原有地过孔 (25.67515,62.67517) ↔ 新孔 (27.35,62.75)，1.677 mm，跨越底层 SCREEN_IO3V3 走线附近。

这两条连接的中心线没有未覆盖地铜区。其作用是提供局部跨层回流路径，但二维拓扑不能证明高频回流电感或屏蔽效果。

下表统计 USB 走线中心线投影到相反铜层时，未被地铜覆盖的总长度。它能定位中断，不能替代走线全宽、场分布或阻抗分析；含引脚扇出和自身交叉区域。

| 网络 | RC1 未覆盖长度 | RC2 未覆盖长度 |
| --- | ---: | ---: |
| USB_HOST_D+ | 1.799 mm | 1.799 mm |
| USB_HOST_D− | 8.564 mm | 5.077 mm |
| SCREEN_D+ | 5.229 mm | 5.207 mm |
| SCREEN_D− | 7.148 mm | 6.702 mm |

因此参考地情况有所改善，仍未达到全程连续的对面地平面。两层局部信号/电源交叉、J2 镜像引脚的交叉与过孔不对称仍是明确限制。不能以 USB 为全速或原生 DRC 为 0 推断必然可用；首板需测试 USB-C 正反插、线缆差异、上传、调试、断电隔离与恢复。若验证不满足要求，应继续调整布线或在用户允许时采用更合适叠层。
