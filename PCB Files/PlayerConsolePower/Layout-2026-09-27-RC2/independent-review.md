- HOST D− 底层铜长从 4.189 mm 降至 0.998 mm，网络过孔从 3 个降至 2 个；J1.B7 至 U7 的实际测量路径不再换层。SCREEN D− 底层铜长从 2.776 mm 降至 1.550 mm，其总平面长度略增加，不能写成全部路径均变短。
- 主任务查看了最终 Gerber 生成的顶底预览、修改区域和 RC2 丝印，并重新运行交付的 `verify-reference-copper.py`。原报告由同算法的临时脚本生成；本轮确认改为直接读取相邻 ZIP 的交付脚本也可运行。
- 铜层复算使用 Python 3.12.14、gerbonara 1.6.3、shapely 2.1.2。四份实际铜层输入哈希和完整结果与交付报告结构逐值相同：5 个新增地过孔均连接上下地，两条顶层短地通路均无中心线覆盖缺口。

上述复验复用了交付算法，不宣称为独立的场求解或实物测量。最初以序列化字符串比较 JSON 得到不相等，随后逐字段比较确认零内容差异；未修改原报告以掩盖差异。

## 仍未通过的项目

USB 仍有局部不成对走线、D− 换层和对面参考地中断，二维中心线覆盖与 DRC 空数组不能证明差分阻抗、回流电感或 USB 波形合格。本轮缩短可避免的跨线并补充局部地连接，没有声称解决全部信号完整性问题。最终使用前仍需基于实际叠层复核和首板 USB 正反插、上传、调试及恢复测试。

原理图保留 41 条警告汇总，明细待分类；FPC 尾端/接点、电池参数、QFN 工艺以及电源/温升/UART 首板测试继续按 README 和首板表执行。当前状态仍是 `routed-manufacturing-candidate-not-released`。
