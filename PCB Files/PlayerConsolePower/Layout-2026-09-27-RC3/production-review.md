- 最终制造包包含 10 个文件，92 个 PTH 孔槽对象、2 个 NPTH。82 个过孔逐个匹配，去除原生导出中重复的 via-only 钻孔文件。67 个装配位号、29 种料号，BOM/CPL 一致；J3 仅手工焊电池线。
- 已查看本版实际 Gerber 生成的顶底预览，确认上边 J3 极性、RC3 丝印与原位置连接器、按键。原生钻孔解析器提示 G90 位于文件头结束之后，坐标/孔径解析和逐孔匹配通过；未把这种语法提示改写成零提示。

USB 主机侧部分走线已由现场改为 0.6mm，**RC2 文档中的 1.15mm/0.20mm 不能当作当前全路径参数**。本版仍有局部不成对、D− 换层、不同线宽和参考地中断，尚未依据板厂叠层证明90Ω，也没有实板 USB 波形/上传/恢复测试。完整铜连通不能替代这些验证。

## 实际供电路径估算

按标称 35µm 铜、25µm 孔铜、1.6mm 板厚和20°C计算；选取导线/过孔路径，焊盘和横向搭接做理想化处理。**不包括电池导线/保护板、连接器、地回流、芯片压降、温升和瞬态电感**，不是载流或热认证。[计算与假设](../ProductionAudit-2026-09-27/power-path-resistance.json)

| 路径 | 一阶电阻约值 | 示范电流与铜路径压降 |
| --- | ---: | ---: |
| J3 BAT+ → U1 BAT | 69mΩ | 1A 时约69mV |
| U1 OUT → L1 | 6mΩ | 1A 时约6mV |
| U2 5V → J2.10 | 58mΩ | 500mA 时约29mV |
| J1 VBUS → U1 IN | 26mΩ | 0.9A 时约23mV |

据此没有发现仅由当前直流走线电阻导致的明显不可用问题；电池接近欠压时，线材/保护板/负载峰值仍可能导致提前关机，需要首板测量。不能把表中示范电流当作 J2 具有1A能力。

BQ24074 为线性充电器，5V输入、3.4V电池、500mA充电时，仅充电损耗约0.8W；运行负载还增加电源路径损耗。U1 四个 EP 散热孔及邻近地铜存在，但两层板、封闭底座的实际热阻未知，不能仅套用手册热阻声称满负载不发热。TPS61023 输入/输出电容、反馈与开关回路已经核对，启动、纹波、低电池负载瞬态仍需示波器和温升验证。

## 放行仍缺的证据

1. **J2 排线兼容与负载**：所选 C2856798 为下接点，要求尾端厚度0.30±0.03mm，供应商标称 **500mA/触点**。屏幕资料的320mA是典型值，推荐5V/1A电源也不是最大电流实测；尚不能证明峰值一直小于接口额定值。需实际排线厚度、插入方向/端到端通断和最大工作电流；若持续超过500mA，本连接方案必须调整后再投产。[立创接口规格](https://www.lcsc.com/product-detail/C2856798.html)
2. **电池规格**：需确认选购电池确实有保护板、适用4.2V充电且允许本版500mA充电和负载峰值。商品图不能代替这些参数。
3. **原理图警告**：当前重新执行仍为41条 `warn`，API只返回数量，尚无逐条明细，不能宣称 ERC 全清。243脚核对通过也不能取消未分类告警；需要原生DRC列表文字/导出或清晰展开截图。
4. **制造与首件**：标准型SMT选择已确定，无需再次确认。下单还需装配预览确认方向、QFN散热孔/钢网工艺、现货；首件按测试表验证充电/开关/欠压/温升/USB/串口电量。实际PCB尚未制作，不能在本次软件工具审查中完成。

因此当前状态为 **完整布线、静态复核通过的 RC3 制造候选，尚未放行**。没有向板厂下单或修改/烧录屏幕程序；共享Git索引由总指挥管理。
