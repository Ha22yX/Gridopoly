# 玩家供电 PCB：BAT 端批量低阻调查

日期：2026-10-14（America/New_York；现场采集 UTC 为 2026-10-15）。**实物故障未定位、未修复，当前批次停止通电验收。** 用户报告所有嘉立创代工板电池端持续约 0.2Ω。先前 DRC 0 或制造候选结论不能替代这一实物结果。

## 已知实测与范围

| 测量点 | 用户读数 | 当前判断 |
| --- | --- | --- |
| J3 BAT+／BAT− | 所有板约 0.2Ω／几十分之一欧 | 按电池输入硬短路处理；表笔自身阻值仍未提供 |
| 5V_SCREEN／GND | 几 MΩ | 本次没有测到输出端硬短路，不等于输出功能正常 |
| C3 SYS_RAW／GND | 约 18.92 kΩ | 本次没有测到 SYS_RAW 对地硬短路，优先排查 BAT 直接支路 |

测 C3 前明确要求断开电池、USB、屏幕，用户随后提供读数。这些是用户实测报告，代理没有接触实物。发现故障前是否曾上电、表笔交换后的读数、原始表笔电阻尚未确认。

BAT_PACK 直接连接 **J3、C2、C19、U1（BQ24074）和 U10（MAX17048）**。优先检查这五处及其连接铜箔、过孔、焊点；C2/C19 同网，在板直接重复测量通常不能区分哪颗短路。SYS_RAW 与 BAT 之间有充电器内部电源路径，不能把两者当成同一根铜线，也不能仅凭 C3 的阻值排除 U1 电池侧故障。屏幕、USB 数据线、后级升压不列为首轮拆件对象。

## 当前数字设计复核

- 读取现场 PCB1 `847ec1f4dfc5086a`、P1/P2：68 件、243 脚、536 线段、82 过孔；原理图网表、PCB 网表、现场焊盘的 243 脚网络完全一致，两份网表与 10 月 5 日归档一致。
- 现场严格 PCB DRC 返回空数组，详见 `pcb-drc-current.json`。原理图 API 返回 **43 条警告计数**，明细未取得，不能宣称 ERC 无问题。`rules-and-drc.json` 里的文档切换后立即检查没有返回 PCB 结果，因此以单独稳定在 PCB 文档后运行的 `pcb-drc-current.json` 为准。
- 对本次新导出 Gerber 独立计算 41 网铜层连通，未发现短路、断路、异常 NC 连通或缺失端点铜。**这不证明实际下单 Gerber 或实物相同。**
- 当前 BAT_PACK 至 GND 最小几何距离：顶层约 0.1601mm，底层约 0.2003mm。顶层最近位置为 U1.3 BAT 与接地的 U1.4 CE 焊盘。未发现一个当前钢网开口几何上跨接两个不同网络；这不能排除实际焊桥。
- U1 中央钢网开口面积与冻结 RC5 一样，约 2.1939mm²。当前 J3 实际钻孔导出为 0.9000mm，冻结 RC5 为 0.8000mm；两脚网络仍分别是 GND、BAT_PACK。不能把当前工程称为与 RC5 制造文件逐字节相同。
- 规则读取中未发现 BAT_PACK/GND 专用间距豁免。DRC 检查数字图元及规则，无法检测实板错料、焊桥、元件内部短路，也不能发现用户实际提交了另一份制造文件。
- 原理图仍含旧注释，如 J3/J4 线焊盘、J2 不进 PCB/BOM、NTC 待定，与现行网表不一致；`schematic-source-comparison.json` 保留差异。这是文档遗留，不能据此断言实际电路已回退或把它当成短路原因。
