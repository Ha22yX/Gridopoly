# R1 RC5 J3 极性复核

范围是用户翻转后的电池接口、对应走线/地铜及制造输出。RC4既有电路审查沿用，不把本轮静态结果视为所有功能重新实测。

| 核对项 | 结果 |
| --- | --- |
| 插座 | JST B2B-PH-K-S(LF)(SN)，C131337；PHR-2线端，向上插入 |
| 当前原理图/PCB | J3.1=GND，J3.2=BAT_PACK；全部243脚网络一致 |
| PCB位置/丝印 | (40,5)mm、180°；USB-C向下顶视，左BAT−、右BAT+ |
| 商品图 | EEMB LP103454，B08HQWXQ6Y；所示黑线在1脚、红线在2脚 |
| 防呆方向依据 | JST官方PH图第3页Housing；出线向上、插接端向下、保持窗口朝前时1脚在左。用户图顺时针转90°后黑左红右 |
| 封装编号依据 | 原生封装0°的1脚在x=+1mm、2脚在x=−1mm；与JST第1页顶插安装面孔图右侧1脚及1.7mm近边关系相符。安装180°后1脚在左 |
| 地铜修复 | 原有6项GND铜与新正极焊盘/孔间距错误；重铺铜后严格DRC 0 |
| 制造铜层 | 独立几何分析41网、243脚/82过孔/536线段，无短路、断路或意外NC连接 |
| 保持性 | 68件位置与82过孔不变；3段BAT_PACK末端走线由用户替换，其余走线原样 |
| 元件及注释 | 两页说明/器件描述中的旧J3极性已改正，板上版号RC5 |

检查产物：[34项布局核对](layout-verification.json)、[11项J3核对](j3-connector-verification.json)、[Gerber连通性](copper-connectivity-review.json)、[导出清单](manufacturing-export-audit.json)。J3采购库存引用RC4时间戳快照，未重新预留库存。

原生原理图API仍仅返回41条warning总数，明细未分类。FPC尾厚/触点方向/载流、电池规格实物核验、USB实际阻抗与参考地、充电温升/电源切换/欠压/烧录及UART遥测均保留首板验收。不得据DRC 0标记批量制造放行。
