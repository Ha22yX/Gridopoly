# 四角色棋子：单色建模参考 v2

根据用户要求，将四个角色统一为单色浅灰材质。使用内置 imagegen 编辑 v1 彩色原图，保留角色和道具轮廓；眼睛、鼻子、服装和底座也采用同色，靠凹凸表现细节。彩色 v1 文件继续保留。

- 01-fox-trader.png：狐狸交易员，尖耳、粗尾巴、终端。
- 02-beaver-builder.png：河狸建筑师，安全帽、门牙、方块。
- 03-owl-planner.png：猫头鹰规划师，面盘、短喙、卷地图。
- 04-turtle-gardener.png：乌龟园艺师，龟壳、短厚叶片。

每次向图片转 3D 工具上传一张图。可附加要求：单一材质、连体网格、五官和纹路为真实几何而非颜色贴图，道具贴紧主体。

底座底面目标直径仍为 **30 mm**，用于粘贴 tag。图像不具有毫米尺寸精度，需在生成模型后标定；底面保持平整，tag 凹槽暂不定尺寸。

这些是建模参考图，不是已验证的 STL。打印前检查网格封闭性、主体/道具/底座连接、最薄处和支撑需求。实际打印可使用任意单色材料，浅灰仅用于展示形体。

提示词与输入图片路径记录在 prompts.json。
