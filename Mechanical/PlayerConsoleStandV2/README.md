# 玩家屏幕模组底座 V2

**当前候选：2026-10-15 [R2 FPC60 分件打印版](revisions/R2_FPC60/README.md)。** 用户把排线长度更正为约60mm，并要求简化3D打印。R2改为平连接板、独立屏幕支架、电池仓和仓盖，电池厚度按新图10.3mm，四个PCB原安装孔保留。实际打印和60mm排线试装仍待确认。

以下为**R1历史记录**。其较高夹层结构不适合当前60mm排线，不要混用R1隔柱、M3×35螺丝或排线路径作为R2装配依据；R1文件和归档包保留。

## R1 归档说明

2026-10-15。新版采用底层供电 PCB、中层电池托盘、上层倾斜屏幕支架，通过 PCB 原有四孔连接成一组。已生成可编辑 Blender、独立 STL 和毫米单位 3MF。**这是待实物试装的首版；排线可用长度尚未确认，不应直接作为最终装配定版。**

用户已确认旧版 CW47.5 支架实际打印试装正常。本版保留其 35° 屏幕角度、CW47.5 定位销孔、圆环和排线槽，只修改外围底板上的四孔与接口缺口。屏幕仍采用旧版可拔出的重力定位，四颗螺丝固定的是支架、托盘与 PCB，不把屏幕本体锁死，不能提着屏幕搬整机。

## 尺寸与结构

PCB 采用 `PLAYER POWER R1 RC6-TP`（2026-10-15）机械来源：80×80mm、R5、名义厚1.6mm，四个Ø3.4mm安装孔，中心距70×70mm。所有68件实装元件在顶面，另有8个裸测试点。

以 PCB 中心为 XY 原点，USB-C 朝前（−Y），Z 从桌面向上：

| 项目 | 默认尺寸/位置 |
| --- | --- |
| 上支架与托盘外轮廓 | 94×82mm |
| 四固定孔中心 | `(−35,−35)、(−35,+35)、(+35,−35)、(+35,+35)` mm |
| 打印通孔 | Ø3.6mm，不改变PCB原孔径 |
| 绝缘底脚 | 8mm高，PCB底面Z=8mm |
| PCB顶面 | Z=9.6mm |
| 托盘底面 | Z=17.6mm，即PCB顶面上方8mm |
| 托盘底板/电池仓高度 | 2mm / 14mm，托盘总高16mm |
| 上支架底面 | Z=33.6mm，原底板厚4mm |
| 上支架单件高度 | 45.864471mm |
| 含屏幕参考外包络 | 约94×85.45×105.47mm；屏幕为尺寸包络，非完整扫描模型 |

四角与PCB接触的绝缘柱外径为6mm。源数据中最近其它焊盘距孔心约5.406mm，柱半径3mm保留约2.4mm平面余量。8mm元件层为本版设计净空；源数据不包含全部元件实装高度，因此仍需检查实际板上最高件与焊锡。

电池采用用户所选 **EEMB LP103454，3.7V、2000mAh**，不沿用早先淘宝103450尺寸。Amazon成品描述存在10.3/10.6mm厚度两种数值，本版使用较大的 **56×34.5×10.6mm**包络；原厂电芯规格不能替代成品包实测。

电池仓净空间 **60×38×14mm**，内边界X=−33..27、Y=−8..30mm。参考电池底部留0.5mm薄垫位置，顶部留2.9mm，软包不能靠拧紧上盖压住。后壁有开放出线口，可用薄的可移除固定材料限制晃动，但不可覆盖电池封边、挤压线根或把额外厚垫强塞进余量。

## 接口通道

- USB-C仍朝前，保持PCB前缘下方开放；拔插从前方进行。
- J2排线插座位于左侧。上下打印件均有敞口通道，从原屏幕槽引出后绕过左侧，接入J2；不把排线夹在板层间。
- POWER/RST在右侧、从顶部按压。两层均留14mm宽的开边操作缺口，可从右侧触及；试装需确认实际手指操作空间。
- J3是后方竖直插入的电池插头。托盘与上支架后缘留开放服务区，避开原厂8mm插合高度，并给导线转弯空间。
- 电池仓不包住充电器和升压电感所在前部区域；底层四周开放。温升仍需用实际装配测量，不能以空间模型代替热测试。

Blender橙色线是**走线路径示意**，中心线约82.73mm，不是可采购长度或已合格的排线模型。实际需量屏幕后部出线处至金手指末端的有效长度，考虑插入长度、宽度、弯曲和操作余量。如果原排线短，需降低结构或另行确定延长转接；不能强拉，也不能只凭“10针0.5mm”就选延长线，必须核对触点面和逐针映射。现阶段不要因此改PCB引脚。

## 紧固件和安装

默认8mm间隔柱方案：

| 零件 | 规格 | 数量 |
| --- | --- | --- |
| 上方螺丝 | M3×35mm，长度指头下长度 | 4 |
| 上方垫片 | M3、约0.5mm厚，位于塑料上支架表面 | 4 |
| 底脚 | 8mm长、外径6mm、M3贯通内螺纹绝缘间隔柱；优先尼龙成品 | 4 |
| PCB上方间隔柱 | 本套8mm打印件，Ø6外径、Ø3.6通孔 | 4 |

从上到下：螺丝头→垫片→上支架4mm→托盘16mm→8mm间隔柱→PCB1.6mm→8mm绝缘内螺纹底脚。贯穿尺寸30.1mm，M3×35在底脚中名义啮合4.9mm，尖端距桌面3.1mm。轻拧至贴合即可，不能弯曲PCB或压裂PLA。

**若改用12mm间隔柱，必须同时换M3×40mm螺丝。** 此时名义啮合5.9mm、尖端距桌面2.1mm；不能继续用35mm螺丝（仅剩0.9mm啮合）。底脚选贯通内螺纹，避免盲孔顶底。底脚型号和实际螺丝/垫片公差需试配。

安装顺序：

1. 所有电源断开，先单独试配四孔、绝缘底脚和8mm柱，确认PCB下针尾与桌面不接触。
2. 放上托盘，检查元件与托盘无接触，J3/USB/J2可插拔，右侧按键可按。
3. 量并试走排线，保持松弛；通过后再放入电池和薄垫、安排电池线。
4. 放上上支架，四颗螺丝均匀轻拧。电池应有余量，导线不能夹在接缝。
5. 按旧版方式装入屏幕，复查旋钮自由转动及接口操作。装配件拿底座搬动。

上述断电是机械装配操作要求。项目最新记录已说明用户当前使用的一块供电板修复后能经底板USB工作；不将旧版“全部未修复”的状态套用到这块板。本机械交付也不改变RC6-TP的电气首件验收状态。

## H2D 与 PLA 打印

上支架沿用之前成功打印CW47.5时的朝向和设置，94×82mm平底朝下。新增四孔与边缘槽不新增封闭悬空顶面；原屏幕接口斜面仍保留，不能将整个支架标成“必定完全无支撑”。

托盘平底朝下、电池仓开口朝上；间隔柱端面贴床、孔竖直。新托盘和间隔柱的离床向下表面检查为0，不需要靠一大片悬空顶板成形。建议先打印一根柱检查M3通孔与高度，再复制到四根；支架/托盘可按旧版PLA质量配置打印，最后在Bambu Studio逐层查看孔、壁和屏幕配合面。

模型已按毫米导出，保持100%比例。小柱的壁厚1.2mm，切片时应确认形成连续实体壁。打印与实物试装尚未执行，本套不附虚构的切片时间或耗材重量。

## 已验证与待确认

已完成：四个打印模型均单一闭合实体，非流形边、反向边和退化三角形均为0；独立3MF单位和几何回读通过。旧CW47.5在Z≥4.01mm区域的2004个顶点全部保留，双向各12051个表面采样点最大偏差约0.0000009mm。新增托盘及间隔柱无离床向下表面。

装配参考共检查489对几何关系，未发现超过0.001mm³的相交；四根隔柱实际位于PCB顶面和托盘底面之间。该检查使用源XY位置和示意元件高度，**不等于所有实物元件高度、真实排线或手指空间已验收**。

仍需确认：原排线有效长度和走线；电池成品外尺寸与线根；实际PCB元件/焊锡高度；底脚/螺丝试配；打印、安装及使用温升。旧屏幕接口实物试装通过是用户提供的证据，新整机试装仍未进行。
