# 玩家供电 PCB 机械接口（新版屏幕底座输入）

日期：2026-10-15。只读提取，没有操作嘉立创EDA、修改PCB或串口。文件范围仅本接口目录；未暂存或提交共享Git索引。

## 采用的版本与坐标

采用 `PCB Files/PlayerConsolePower/Testpoints-2026-10-15/` 的 **PLAYER POWER R1 RC6-TP**、PCB UUID `847ec1f4dfc5086a`。来源哈希已写入 `mechanical-interface.json`。该版保留原68件位置，新增8个裸通孔测试点；用户正在使用的已修复实板不一定与这一归档完全一致，因此实物版本和Z向尺寸不视为已测量。

顶视、元件面朝上、USB-C朝下。板框左上角为(0,0)，X向右、Y向下；Z=0取PCB顶面，Z正向上。原生坐标单位mil，转换为 `x=x_native×0.0254`、`y=−y_native×0.0254`。

板框 **80×80mm、四角R5**，名义板厚 **1.6mm**，两层，68个实装器件全在顶面。当前8段原生板框与用户原固定约束逐段相同。1.6mm是设计名义值，没有本次实测。

## Z向数据与电池减高候选

- 本版源码没有所有器件的装配高度表；**最大顶面高度、最大底面突出高度仍为null**。不能把棋盘板的8.1mm借用到此PCB。
- J3的本地JST官方PH规格书第1页明确顶插配合高度8mm；第3页本体6mm，针脚由安装面向下名义3.4mm，配1.6mm板则未剪脚时约伸出板底1.8mm，尚不含焊锡/装配误差。已渲染第3页供复核。J3上方还需导线转弯和拔出空间，本次建议局部15mm预留。
- L1 MWSA0402S有原厂数据1.8±0.2mm。J1厂家图壳面高度2.57±0.05mm。按键库封装名H1.5只作库提示，未独立确认实际批次。
- 可考虑电池托盘覆盖PCB坐标 **x10..70、y10..48** 的60×38mm外部包络；它避开J1/J2/J3、两按钮及L1的本体，但覆盖低矮阻容、Q1、U3/U4/U8/U10，**不是空白板区**。
- 对该候选，可研究隔板底在PCB顶面+4mm、隔板厚2mm，以减低整体高度；前提是实物下方全部器件/焊锡最高≤3mm，至少留1mm间隙。4mm是待试装的设计值，不是假装测得的上限。托盘实际内腔60×38再加壁厚时，应重算外包络。
- 北边J3不可被托盘北移遮住；导线弯曲留局部独立通道。Y=22.5测试点行会被托盘覆盖，需允许拆卸访问，不能用定位柱塞进这些孔。
- 已购EEMB LP103454原厂公开电芯尺寸上限 **56×34.5×10.3mm**；成品包保护板、封边、引线及实际膨胀余量尚未实测。旧淘宝103450的52×34×10mm不适用。不能让电池直接压在电子元件上。

## 文件与检查边界

- `mechanical-interface.json`：板框、孔、关键接口、本版全部76组件的XY，68件本体多边形，来源哈希与未知项。
- `mounting-holes.csv`、`interface-anchors.csv`：便于建模导入的表。
- `extract-mechanical.py`：只读提取与断言；原生板框不变、四孔与制造钻孔吻合、OD6接触圈的源图元距离检查。
- `jst-ph-p3-reference.png`：原厂PH第三页，解释本体高度与针尾。

本机械接口不改变现有电路审查状态，也不能作为充放电、USB、电池遥测或整机装配已验收的证据。下一步由根建模任务负责把接口导入底座、完成碰撞/可打印性分析；实物操作者确认电池成品包尺寸、软排线可用长度、插接方向和PCB最高焊点后闭合首次试装。
