# Gridopoly 16模块整体底板 · Full16 R1

本版把已实打印、由用户照片及反馈确认配合正常的三模块角落底板，扩展为 **4个角落＋12个长边模块**的外围环：每边含两个共享角落和三个长边，共5块PCB。四个大区块拼成一个固定位置的底板，不是16块独立小底座。中间保留开口。

当前状态：数字模型、孔位、导出网格及参考PCB干涉检查通过；**完整16模块尚未实际切片、打印和试装，拼接强度尚未实测**。原角落三模块成功不能代替全环验收。

## 尺寸与紧固件

| 项目 | 名义值 |
|---|---|
| PCB外围范围 | 358×358 mm |
| 普通底板主框 | 366×366 mm |
| 含外侧连接耳的最大外形 | **406×406 mm** |
| 中央开口 | 主框内约190×190 mm，内侧连接耳会局部占用，不可按完整190方孔塞入物体 |
| 平板厚度／PCB底面离桌面 | 3.5／16 mm |
| 已知最大板底突出 | 用户测得约8.1 mm，至平板顶面余量约4.4 mm |
| 板间主体直边间距 | 角—长12 mm；长—长15 mm |
| 相邻打印主件接缝 | 0.3 mm |

保留64根一体柱，每板两个对角孔锁紧，其余两个辅助承托和定位。按各PCB原器件面方向，角板锁左上／右下，长板锁右上／左下；板在底板上旋转后仍认本板对应孔。辅助柱上的定位销不装螺钉。

准备 **48颗塑料专用盘头自攻／螺纹成形螺钉**：公称外径3.0 mm、头下长10 mm、头径不超过6 mm。其中32颗固定PCB，16颗固定连接片。另需 **48片垫片**，内径约3.2 mm、外径不超过6 mm、厚1.0 mm；可用两片0.5 mm代替一片1 mm。

这不是“M3×10机螺钉”，不配螺母，也不用沉头压PCB。主柱和连接耳均为顶开盲孔，候选小孔径2.5 mm、顶部导向孔3.6 mm。PCB处扣除1.6 mm板厚和1 mm垫片，名义入柱7.4 mm，距盲孔底2.6 mm；连接片处扣除3 mm片厚和1 mm垫片，入耳6 mm，距盲孔底2 mm。尖端及实际牙型会影响有效啮合，以上不代表抗拔强度。

成功试装时的螺钉若符合上述尺寸，可继续使用同款与同种PLA。若更换牙型或材料，先用旧R2试孔片检查配合；不得靠大力拧入修正孔径，也不能整体缩放模型。

## H2D／PLA打印

平底贴床，柱子、连接耳向上；连接片平放。该方向按无需支撑设计，取消底部封闭槽和槽顶悬空。导入后保持毫米单位、100%比例，逐层查看，不把参考PCB一起切片。

以0.4 mm喷嘴为起点：层高0.20 mm、4道墙、顶底各5层、主件20–25%填充；连接耳及其根部建议用修改器局部实心，连接片建议100%填充。主件可加约5 mm外侧Brim（与首层贴合的防翘边边缘）。单件含Brim仍可平放于H2D单喷嘴325×320 mm范围（[Bambu官方规格](https://cdn1.bambulab.com/documentation/h2d/en/H2D_Laser_Full_Combo_20250305.pdf)）；实际摆放以Bambu Studio当前机型配置为准。

**建议先打印一个L主件。** 它保留已经成功的三模块关系，并新增一个长板位置，可先确认长—长接缝及四板共面。自然插好四块PCB后，应无需拉扯即可落到孔柱上；合适后再打印剩余三个L和八片连接片。冷却后检查大平面平整、柱根无裂纹，并清理孔口及接缝毛边。

## 装成一个完整底板

按顶视图，Q1右下、Q2右上、Q3左上、Q4左下。每块是一角三长，长短臂不能凭外观任意对调。

1. 在平桌上断电试装。先各自组好四板小组，再落到对应L主件；先不锁紧PCB，不用螺钉把歪板压到位。
2. 右侧Q1＋Q2先组成右U，左侧Q3＋Q4组成左U。保持PCB同一高度，沿各自连接器轴线直插；拼缝两侧的耳台和定位销应对应。
3. 最后让左右两U沿水平方向相向平移，上、下两处接口同步对接。出现偏斜或明显阻力即停止调整，不能掰PCB、斜插或强拉闭环。拼缝及所有板孔自然就位后，再轻锁每板两颗螺钉。
4. 最后放上八片连接片，使小销进入定位孔，大孔对准耳台盲孔；每片用两颗螺钉和两片垫片，交替轻拧至夹紧。内外两片都要安装，不能只靠PCB接头承受底板连接力。
5. 检查全盘不摇晃、板底元件不接触塑料、接口仍可操作，螺钉无顶底、柱裂或滑牙。移动时托住底板两侧，首次试装不要单拎一角检验强度。

## 检查范围

`layout-audit.json`已核对16板、64孔、原三板坐标保留、每边5模块及八片连接件的孔销对应。`parts-verification.json`确认两种STL均为闭合连通实体，无退化面；3MF毫米单位、单对象、几何与STL一致，按柱向上未检出床面以上的向下悬挑面。

`assembly-verification.json`复核保存后的四块主件、八片连接片及16块带孔PCB板材，未发现有效实体相交。该检查未包含全部元件和插头的精确三维外形，也未模拟打印收缩、螺纹夹紧或承载。全环配合、实际切片和拼接稳固程度仍以这次打印试装为准。

首件反馈宜分别记录长—长接头是否自然插到底、四块板是否同时落柱、底板是否翘曲以及连接片是否贴平。若某处不能配合，保留未锁紧状态，标出具体板号、偏差方向和大约距离；应改对应尺寸后重印，避免磨大全部孔或用接头弹性吸收误差。
