# 长边/角落底面装配避让核对（2026-10-15）

结论：两种当前设计都不是底面平板。长边有48个底面封装，角落46个；另外顶面连接器的穿板焊脚、USB外壳固定脚和焊锡也需要底面避让。不能以PCB板厚或底面铜盘代替装配后的厚度。

用户已确认自然对插时各PCB同一平面，两板最大底面突出都约8.1mm、板厚约1.6mm；均标为 `user_measured_approx`，各器件Z仍为空。拟PCB底面距桌14mm、底筋顶部距桌3.5mm，则名义剩余净空为14−8.1−3.5=2.4mm。该算式以PCB**底面**为高度基准，不能再次减去板厚；未包含板翘曲、制造误差、脚长变化、焊锡及用户测量误差的最坏组合。

## 来源与版本边界

采用主任务本轮只读导出的 `long-current` / `corner-current` 原生source、API组件焊盘快照和epro2库。全部引用和SHA256在JSON中。当前UUID分别为7840864f79449b47、6f97d7be5a40dd66。两板当前COMPONENT/ATTR/PAD/PAD_NET/FILL/LINE/ARC/POLY/REGION/VIA记录与2026-09-21 DesignAudit对应快照逐项相同、差异0。此结论只说明保存设计记录一致，不证明收到的各批次实物装配相同。

旧CornerModule/LayoutCandidate-2026-09-21属于已取消的218件PD候选（顶110/底108），不用于当前底座。DC24/SyncRepair是早于DesignAudit的修复阶段归档，不能替代本轮原生导出。底面实际料号、DNP装配、焊脚修剪以及焊锡高度仍需对照实物。

## 数据使用规则

- `bottom-clearance.json` 对每个底面封装给出库body outline（层48）、实际pad、二者并集bbox及建议外扩0.5mm的XY避让bbox。全部94个底面封装均成功匹配当前原生库body轮廓；不是仅由铜盘估计外形。
- 库body投影只代表库内名义XY，不等于厂家保证最大实体外形。实际pad中心用于验证旋转/镜像，若对称封装存在等价解则取body包络并集。没有从封装名称或3D模型标题推导高度。
- `*_local_mm` 为从板框包围盒左上归零的顶视投影，X向右、Y向下；组装到统一基准时不再镜像。若要显示从板底向上看的底视图，应单独变换视图，不回写成另一套装配坐标。同时保留EDA全局mm坐标（X右、Y上）。bbox顺序为xmin,ymin,xmax,ymax。
- 0.5mm仅是拟用于底座的平面设计余量，不是已测公差或厂家净空要求。C20、R15等BOM排除的封装仍保留避让，直到实际是否装料确定。
- 所有单件本体高度、通孔尾脚突出和焊锡高度均为null。8.1mm是整板约值，不应复制到每个器件。
- API snapshot的hole数组存在已知10倍比例问题，本报告不使用它输出孔径；穿板部件XY依据当前铜盘范围，实际孔径由Gerber DRL另行核验。

## 顶面器件的底面焊脚/焊锡区域

长边和角落共有J1 USB外壳4个固定脚、J3两脚、J4八脚、JIN1/JOUT1各六脚、JIN3/JOUT3各三脚：合计7个连接器、32个有孔焊盘。角落另有J301三个槽孔端子，共8个连接器、35个有孔焊盘。它们位于顶面，不代表底面没有突出。JSON按位号及每脚给出XY铜盘范围；真实尾脚/焊锡可超出铜盘，需实际检查。

U201另有一项有孔EP焊盘记录，单列为thermal_or_other_pad_hole，不能把它当作普通长引脚。长边还有独立裸板PAD图元；它们属于电气/热孔避让，不能凭PAD记录推定已焊有器件。

## 安装孔与支撑接触面边界

本报告只附安装孔中心和名义切孔直径供交叉索引；孔周铜、焊盘、过孔、支撑圆环/垫圈接触范围由布局审计负责。未给任何支撑环“安全放行”。底筋不得通过上述底面器件/焊脚避让区接触PCB；应使用已验证的绝缘支撑接触面。若使用金属螺丝/垫圈，应按最终外径和焊膜/铜实况单独检查，不能把GND铜或焊膜默认成承力绝缘面。

当前两板共面是用户已确认事实；仍需冻结的是下方净空和局部支撑/螺丝干涉。用户的8.1mm最大突出应确认覆盖实际焊脚与焊锡，而不只是某颗电容外壳。
