# Gridopoly 3D 设计文件保存约定

用户于 2026-10-15 明确要求：所有本项目的 3D 模型设计应包含在 `Z:/Files/我的项目/Gridopoly` 项目文件夹内。

- `Mechanical/` 是机械设计的正式保存位置。按棋盘底板、玩家屏幕底座、棋子及版本组织文件。
- 可编辑工程（如 `.blend`）、打印模型（`.3mf` / `.stl`）、原始模型输入、重建脚本、参数、必要参考图、检查报告及装配 PDF 均须保存到项目内。不能只交付 Downloads、桌面或临时目录的文件。
- 可以额外提供下载目录副本，但项目内文件和 README 链接必须先完整。历史外部绝对路径可作为溯源记录保留，不代表当前交付入口。
- 新修订使用独立版本目录。已经冻结的 `deliverables/` 文件、ZIP、清单和哈希不得直接覆盖；运行旧生成脚本前先为新修订调整输出目录。`.blend1` 和 `Working.blend` 是恢复/工作记录，不是优先打印入口。
- 更新分类 README 和 `Mechanical/README.md`，明确当前版、历史版、打印数量及验证边界。几何检查不等于实物打印、安装或承载验证。
- 本地归档不等于 Git 提交或云端备份。遵守项目根目录的共享 Git 协作要求，不擅自操作索引或提交；大型二进制文件的版本管理由项目总指挥统一安排。
