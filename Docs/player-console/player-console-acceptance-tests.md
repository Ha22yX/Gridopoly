# Gridopoly 玩家圆屏验收测试

状态：设计基线 1.0

更新日期：2026-08-02

## 1. 范围

本文定义 2.1 英寸 480×480 圆屏 Demo 的软硬件验收标准，并为未来树莓派主控联调
保留协议测试。首版不要求圆屏本地通过完整规则引擎测试。

## 2. 测试环境记录

每轮验收必须记录：

- 圆屏模块硬件版本和设备 ID
- 调试转接板版本
- ESP32-S3 固件 Git 提交
- 资源包与协议版本
- 树莓派或协议模拟器版本
- 供电方式
- 屏幕亮度
- 物理安装、机械 60°和固件 0°配置
- 测试日期与测试人员

## 11. 规则界面场景

以下场景只验证圆屏表现和协议结果，不证明本地存在规则引擎：

- 无主地产购买和放弃
- 拍卖
- 地租机会和付款
- 完整地区组与建设
- 抵押、赎回和筹款
- 双方交易
- 限制区三种离开方式
- Chance 和 Community Chest
- 玩家破产和最终胜利

每个场景必须满足[玩家圆屏 Demo 场景](player-console-demo-scenarios.md)定义的最终页面、
焦点和状态摘要。

### 11.1 拍卖同步屏障

| ID | 测试 | 故障/操作 | 通过标准 |
| --- | --- | --- | --- |
| AUC-READY-01 | 少一个真人未 Ready | 两真人参与，只让一屏发送 Ready | 1.8 秒后停留同一 Live 舞台并显示 Ready x/y；Bid/Pass 禁用，不能回到 Opening 欢迎页，bot 不推进 |
| AUC-READY-02 | 最后一个 Ready | 第二屏发送当前 asset+generation 的 Ready | 只启动一次首位竞价，所有屏幕收到一致的新版本 |
| AUC-READY-03 | 重复 Ready | 重发完全相同 ActionRequest | 返回幂等结果，不增加版本、不重复启动 |
| AUC-READY-04 | 旧代次污染 | 新拍卖中发送上一 generation 或 asset | 请求被拒绝，ready mask 不变化 |
| AUC-READY-05 | Opening 中重连 | 已进入介绍页的屏幕断线并全量 resync | 若自身位仍缺失则重发 Ready，并正常解除屏障 |
| AUC-READY-06 | 多端一致 | Web、真人屏和 bot 混合参与 | required/ready mask、当前竞拍者、价格和结算版本一致 |
| AUC-LIFE-01 | 同 key 重同步 | Intro 或 Live 中连续接收同 room+generation+asset 的 State/Auth resync | Intro 总计只出现一次；Live 不回退 |
| AUC-LIFE-02 | Intro 中途重同步 | Intro 开始 900 ms 时收到同 key resync | 仍保持 Intro，到本地 1800 ms 截止后才进入 Live |
| AUC-LIFE-03 | 同房间低版本 | Live v12 时收到带 resync 的 TurnEnd v11 | 整个投影被忽略；phase、generation、asset 和 Live 页面均不变 |
| AUC-LIFE-04 | 已完成 key 迟到 | 结算后收到相同 generation+asset 的 active Authority | 写状态前拒绝；不重复 Result，不回滚 phase 或拍卖字段 |
| AUC-LIFE-05 | 新房间恢复 | 当前版本较高时收到新 room 的 v1 快照 | 允许版本回退、清除旧拍卖历史，并只为新 generation 展示一次 Intro |
| AUC-LIFE-06 | 统一视觉骨架 | 依次观察 Intro、Live waiting、Live bidding、Result | 标的图片、名称、主价格和余额保持同一位置与尺寸，仅底部状态区变化 |

## 13. 素材验收

- 22 幅地产缩小到 128 px 后仍可彼此区分。
- 五名角色在 96 px 下可通过轮廓和图标识别。
- 图片中没有伪文字、现实品牌或受保护桌游视觉。
- 图片不包含需要动态替换的名称和金额。
- 资产包、字体和元数据总目标不超过 4.5MB。
- 每个资源在清单中有稳定 ID、源文件、设备文件、尺寸、色深和版本。
- 地产与角色均为统一的平面 2D 欧美桌游卡通风格，不混入 3D 或日系动漫比例。

## 14. 发布判定

以下任何一项失败都阻止 Demo 发布：

- 方向或触摸逆变换错误
- 关键文字或按钮遮挡
- 危险操作能够单击提交
- 重复付款、交易或掷骰
- 现金不足时出现负余额
- Demo 数据进入正式房间
- 两小时测试出现重启或持续内存泄漏
- 协议日志泄露热点口令或完整会话令牌

验收完成后保存测试记录、串口日志、关键页面照片和固件二进制校验值。
