# Gridopoly 玩家圆屏 Demo Lab 场景规范

状态：设计基线 1.0

更新日期：2026-08-02

## 1. 目的

圆屏首版是可交互 UI 测试 Demo，不在 ESP32-S3 本地实现完整游戏规则。Demo 场景
适配器生成与正式 `PlayerConsoleTransport` 相同的状态快照、增量消息和操作结果，从而验证
真实渲染与输入而不复制规则引擎。

## 2. 运行模式

| 模式 | 行为 | 用途 |
| --- | --- | --- |
| 自动演示 | 按固定时间轴推进五名虚拟玩家 | 展示和老化测试 |
| 手动步进 | 每次短按推进一个脚本事件 | 页面检查和拍照 |
| Demo Lab | 直接选择任意场景 | 开发和回归测试 |

自动演示支持 1×和 2×速度。规则倒计时默认保持真实 20 秒和 10 秒；测试菜单可单独
开启加速计时，但界面必须显示 `DEMO 2×` 标记。

## 3. 入口与退出

- 首页持续按住旋钮 3 秒进入 Demo Lab。
- 任意子页面持续按住 3 秒返回首页。
- Demo Lab 中旋转选择场景，短按运行，800ms 长按返回分类。
- 正式构建可通过编译配置隐藏 Demo Lab 入口。
- Demo 场景不得连接或修改正式房间。

## 5. 场景消息原则

- 适配器通过 `DemoTransport` 实现与 Wi-Fi/UDP 正式传输相同的 `PlayerConsoleTransport` 接口。
- UI 只订阅标准快照、事件和命令结果。
- 场景不得直接调用页面内部函数或修改控件。
- 每个场景拥有固定随机种子、初始快照和期望事件序列。
- 用户操作不符合当前步骤时返回标准协议错误，而不是静默跳过。

## 11. 硬件诊断场景

### 11.1 显示方向

- 显示十二点箭头、水平文字、机械 60°和固件 0°数值。
- 实物底座上的十二点箭头应指向玩家正前方。
- 固件不提供任意角微调；若方向不正，修正结构件或装配基准。

### 11.2 九点触摸

- 依次显示中心、上下左右和四个对角目标。
- 同时输出原始坐标、归一化坐标和逆旋转后坐标。
- 记录平均误差和最大误差。

### 11.3 旋钮与按压

- 显示旋转方向、步数、速度等级和累计值。
- 实时显示按压时长。
- 分别标记短按、800ms 返回、1.2 秒确认和 3 秒首页手势。

### 11.4 性能

- 显示 FPS、帧耗时、空闲堆、PSRAM、最大连续块和网络往返时间。
- 支持两小时自动循环全部场景。
- 诊断数据通过 USB 串口同步输出。

## 12. 场景完成条件

每个场景记录：

- 场景 ID 和版本
- 起始状态版本
- 用户输入序列
- 收到的标准消息序列
- 最终页面 ID
- 最终焦点 ID
- 最终余额、位置和资产摘要
- 是否出现协议、内存或布局错误

手动场景完成后显示通过、失败或未完成；自动演示只记录结果，不中断展示，除非出现
致命内存或协议错误。
