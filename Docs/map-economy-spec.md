# Gridopoly 可变地图与经济规范

状态：设计基线 1.0

更新日期：2026-08-02

## 1. 目标

地图和经济必须完全数据驱动。主控规则引擎不因地图从 16 格切换到 40 格而修改
代码，只加载不同地图包、产权表和卡组配置。

首个完整平衡基线是 28 格网格都市地图。其他规模遵循相同模式和校验规则，并在
正式发布前分别运行平衡模拟。

## 2. 支持的地图规模

| 格数 | 角落 | 地产 | 交通 | 基础设施 | 卡片格 | 服务费 | 主要用途 |

| 16 | 4 | 7 | 1 | 1 | 2 | 1 | 快速教学与小规模硬件测试 |

主控枚举物理模块后，只显示模块数量和地图包均满足要求的选项。选择较小地图时，
未参与游戏的物理模块必须进入明确的停用或装饰状态，不能继续报告有效落点。

## 3. 地图包结构

建议的逻辑结构如下。字段名称是协议和未来实现基线，不要求首版圆屏 Demo 解析
完整地图包。

```json
{
  "schema_version": 1,
  "map_id": "grid-city-28-v1",
  "display_name": "网格都市 28",
  "tile_count": 28,
  "corner_indices": [0, 7, 14, 21],
  "normal_economy": "grid-city-28-economy-v1",
  "card_decks": ["city-event-v1", "civic-fund-v1"],
  "tiles": [],
  "groups": [],
  "building_supply": 32,
  "landmark_supply": 12
}
```

### 3.1 格子类型

| 类型 | 必需数据 |
| --- | --- |
| `START` | 起点奖励策略 |
| `PROPERTY` | 资产 ID、地区组、产权表、插画 ID |
| `TRANSIT` | 资产 ID、价格、租金阶梯、插画 ID |
| `UTILITY` | 资产 ID、价格、骰子倍率、插画 ID |
| `CARD` | 卡组 ID |
| `FEE` | 费用 ID、基础金额 |
| `HOLD` | 限制区和访客状态 |
| `REST` | 无额外效果的自由中庭 |
| `GOTO_HOLD` | 立即进入限制区 |

### 3.2 语义标签

卡片和规则不得依赖显示名称或写死某一地图的索引。地图包应为目标格提供标签：

- `START`
- `CORE_DESTINATION`
- `HIGH_VALUE_ENTRY`
- `TRANSIT`
- `UTILITY`
- `HOLD`

存在多个匹配格时，`NEAREST` 操作按当前移动方向寻找下一格并允许跨越起点。

## 7. 节奏换算

| 参数 | 快节奏 | 正常 | 慢节奏 |
| --- | ---: | ---: | ---: |
| 初始现金 | $1,200 | $1,500 | $1,800 |
| 经过起点 | $150 | $200 | $250 |
| 地产、交通、设施价格 | ×0.90 | ×1.00 | ×1.10 |
| 建设成本 | ×0.80 | ×1.00 | ×1.15 |
| 租金 | ×1.25 | ×1.00 | ×0.85 |
| 系统支出给玩家 | ×0.80 | ×1.00 | ×1.20 |
| 玩家支付系统 | ×1.20 | ×1.00 | ×0.80 |

### 7.1 取整顺序

1. 从地图包读取正常模式原始值。
2. 应用节奏倍率。
3. 购买价和建设成本四舍五入到最近的 $10。
4. 租金、卡片和服务费四舍五入到最近的 $1。
5. 抵押值从调整后的购买价计算。
6. 赎回费用从抵押值计算并向上取整到 $1。

乘骰子点数的基础设施先计算骰子倍率，再应用租金节奏倍率。按玩家数量计算的卡片
先计算总额，再应用对应收支倍率。

## 8. 开局冻结与展示

- 主控在房间锁定时生成一份 `ResolvedEconomy`。
- 所有圆屏、地产模块和回放系统使用同一份解析后金额。
- 房间摘要必须显示地图、节奏、初始现金、起点奖励和预计时长。
- 开局后不允许修改节奏或经济表版本。
- 存档必须保存解析后金额，不能只保存倍率并依赖未来版本重新计算。

## 9. 地图校验

主控加载地图包时必须验证：

- `tile_count` 与格子数组长度一致。
- 恰好有一个起点、一个限制区、一个自由中庭和一个进入限制区格。
- 四个角落均匀分布在 `0`、`N/4`、`N/2`、`3N/4`。
- 每个资产 ID 唯一，产权表字段完整且金额非负。
- 每个地区组至少包含 2 块地产。
- 地图中的所有卡组、图片和语义目标均存在。
- 交通与基础设施租金规则和实际数量相容。
- 建筑和地标库存不小于地图声明的最小值。
- 不存在无法到达、重复索引或指向未启用格子的卡片目标。

校验失败的地图不得出现在开局列表中。

## 10. 平衡验证指标

每个地图和节奏组合至少运行 10,000 次自动模拟，记录：

- 首个完整地区组形成回合数。
- 首次建设和首次破产回合数。
- 游戏总时长与回合数分布。
- 每种资产类型的购买率、平均收益和投资回收时间。
- 起始座位胜率与先手优势。
- 玩家现金为零附近停留的时间。
- 拍卖成交率和平均折价。
- 不同策略下交通、设施和地产组的相对强度。

五人 28 格目标时长：快节奏 25–40 分钟，正常 35–60 分钟，慢节奏 60–90
分钟。若模拟偏离目标，优先调整地图基础表，不修改核心规则。
