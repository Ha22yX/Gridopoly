## 显示规则

| 状态 | 图标 |
| --- | --- |
| 51–100% | 绿色，内部填充随实际百分比变化 |
| 16–50% | 黄色，内部填充随实际百分比变化 |
| 0–15% | 红色填充；真实0%保持空心并显示0% |
| 电量无效或过期 | 灰色空心，内部显示 `--`，不沿用旧填充 |
| 新鲜的有效外部输入＋充电指示 | 电池内部增加闪电；不因此强制显示100% |
| 充电/供电指示异常候选 | 内部增加黄色 `!`，不把候选直接当作硬件确诊 |

电池内部保留整数百分比。充电指示不可用或未激活时不显示闪电；无闪电不等于断开外部电源。原来的 `POWER -- / EXT / NO EXT` 字样退出常驻界面，原始供电状态仍保留在采样数据与诊断中。

- 外壳和内部填充与主圆环共用屏幕中心 `(240,240)`，整体位于底部圆环外侧，带右侧电池凸点。
- 范围为 `(196,447,96,25)`，四角均在238px安全圆内；不覆盖页面内容、按钮或手写画布。

- 独立顶层对象不加入焦点、不接收触摸，不重建游戏页；显示值不变时不主动失效重绘。无闪烁/呼吸动画。

## 充电显示防抖

底层GPIO原有约75ms去抖，仍可能将较长的瞬态传到页面。本次增加独立显示滤波，不修改原始GPIO、底层故障检测、充电电路或电池百分比：

- 正常充电/不充电和供电组合异常，须有持续 **1500ms** 的新鲜一致读数才改变图标。只有不同GPIO采样时间才能推进确认，重复绘制同一快照不算新证据。
- 正常状态候选遇到不同信号、未知状态或超过350ms采样间隙时重新计时。
- 临时GPIO未知/过期可保留原图标，但距最后有效样本**最多1000ms**，随后清除；这只是显示宽限，不将底层过期状态重新标有效。
- 桥接通信明确失效时立即清除旧充电图标。底层已经观察至少2秒、确认约2Hz节律的故障候选立即显示 `!`；恢复正常须再稳定1500ms，不把故障闪烁平滑成正常充电。
- 此功能抑制显示跳变，不证明现场供电已经稳定，也不能修复持续数秒的真实充电停止。
