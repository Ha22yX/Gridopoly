# 长边／角落板间接口核查（2026-09-21）

结论：**当前两种 PCB 的互连针序和二维拼接方向兼容，名义位置可以围成矩形周边；不能把这等同于现状全部插成闭环后，机械和通信均已可靠验收。**本次只读检查，没有移动锁定接口或修改电路。

## 针序与方向

|接口|器件|信号|
|---|---|---|
|JIN1|HX PZ2.54-1x6P WZ / C32713265，弯公针|1/2/3=24V_BUS，4=ORDER_IN，5=BUS_A，6=BUS_B|
|JOUT1|LAIL-PM2.54-6P-W / C54973819，弯母座|1/2/3=24V_BUS，4=ORDER_OUT，5=BUS_A，6=BUS_B|
|JIN3|PZ254R-11-03P / C492411，弯公针|三个针均为 GND|
|JOUT3|LAIL-PM2.54-3P-W / C54973822，弯母座|三个针均为 GND|

两板输入公针同位置、同方向。长边左公右母；角落左公上母。装配时保持器件面朝同一面，角落依次旋转 90°，连接每板的 OUT 母座与下一板 IN 公针，无须翻到背面。

核对了长边→长边、长边→角落、角落→长边、角落→角落四种组合，共 36 个针位；沿针排方向偏差为 0（API 分辨率内）。6Pin 按编号 1→1 至 6→6 对应；3Pin 的外侧两个编号在对插时反向，但它们全是 GND，不构成错接。

针距 2.54mm，6Pin 与 3Pin 组中心沿接口边距离 13.462mm。没有发现旋转后 24V 对地、A/B 互换或 ORDER 接到电源的错误。

## 位置与机械边界

|位置|6Pin 中心（mil）|3Pin 中心（mil）|角度|
|---|---|---|---|
|两板 JIN|(-25,-1770)|(-25,-1240)|6Pin +90°；3Pin -90°|
|长边 JOUT|(1920,-1770)|(1925,-1240)|均 +90°|
|角落 JOUT|(1652.0467,-94.5779)|(1122.0467,-94.5779)|均 180°|

**长边 JOUT3 比 JOUT1 沿插入方向前移 5mil=0.127mm。**这不是沿针排方向错位，不会因此让 24V 接到邻针；但是两组母座的焊盘排不共线，插合深度不能直接当作完全一致。角落的两组输出焊盘排共线。

本轮读取并查看四个器件的厂家机械图：2.54mm 针距、单排结构相符；两种公针名义配合针长度为 6mm，但图示 4.30mm 与 4.4mm 的弯折尺寸并不相同；母座图示 8.50mm 壳体深度。公针来自韩下、兴飞，母座来自莱联，资料没有给出这套跨厂家组合的对插容差保证。不能仅凭封装中心共线，承诺贴板装配后两个插头同时插到底。

这些弯针、母座会占用板间空间，**当前接口不是板边零间隙拼接结构**。最终接缝宽度、插入深度、接触高度和最后一处刚性闭环的装配方式，需要实物对插或明确的组合机械尺寸确认。没有在本轮擅自将 0.127mm 偏差改掉，也没有凭库丝印发布外壳尺寸。

## 能围成什么棋盘

采用 4 个相同角落，各旋转 90°，相对两边放相同数量的长边模块，名义几何可以闭合。例：4 个角落 + 28 个长边，每边 7 个长边，共 32 块；计算闭合误差约 1e-13mm，为浮点误差。此结果依赖相同接缝采用相同的名义插入间距，不包括加工及装配公差。

一般周边矩形计数为 `N=4+2a+2b`，a、b 分别为一条横边、一条竖边的长边模块数量（不含角落）。这代表周边棋盘，并非把二维矩阵全部铺满。实际板框中角落为 80×80mm；长边主体约 48×80mm，两侧连接器位置各凸出约 3mm，最大宽约 54mm。

## 全部闭合后的电气问题

当前 JIN/JOUT 的 BUS_A、BUS_B 在每板直接贯通。如果最后一板也全部接回第一板，A/B 会构成闭合环。TI 的 RS485 设计指南推荐线形菊花链，环形网络可能产生反射，不能以直流导通证明通信稳定。两板 U6 为 SN65HVD75DR；本轮实时网表中两板 R15=120Ω 均设为不加入 BOM，即默认没有装终端。没有断点、指定两端和终端配置的完整闭环，不能按可靠 RS485 总线放行。

来源：[TI RS485 设计指南](https://www.ti.com/lit/an/slla272d/slla272d.pdf)、[TI 拓扑培训（含 Ring network avoid）](https://e2e.ti.com/cfs-file/__key/telligent-evolution-components-attachments/13-143-00-00-00-26-49-53/IIF_2D00_Training_5F00_RS485_2D00_Design-Guidelines.pdf)。

ORDER 同样要明确链首。仓库当前 `Server/RaspberryPi/src/TileOrderTopology.h:172` 在所有节点都有上游、找不到链首时将拓扑标为 `conflict/cycle`。这是当前源代码行为，不是对设备已部署版本的断言。物理最后一段把 ORDER_OUT 接回第一板 ORDER_IN 并形成完整已识别环，会与这个排序逻辑冲突。

建议的最小方案是：**棋盘机械外形闭合，最后一处连接仅让 24V/GND 贯通，断开 ORDER 和 A/B，让数据链保留首尾；在数据链两端配置与总线匹配的终端，其余板 R15 不装。**可以用专用闭合转接件实现，不应通过松插、错位插或弯断针脚实现。该转接件目前只是建议，现有 PCB 中没有为此新增器件或断线。

因此，接口方向和针序不用推倒重来；待解决的是机械对插余量、闭合处数据断点及终端，以及实际装配。此次核查不等于整盘电源、PCB 布线或通信固件已经全面验收。
