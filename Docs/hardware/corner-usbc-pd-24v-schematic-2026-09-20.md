## 电路与额定目标

USB1 → STUSB4500 协商与两级 P-MOS 输入开关 → TPS55340 升压 → TPS26600 输出限流/防倒灌 → 24V_BUS。

按 24 个模块、每个 1W，预计母线负载约 24W/1A；电源连续输出设计目标 24V/1.5A。使用明确支持单口 20V/3A 的 60W 或 65W PD 电源和合格 3A C-C 线。其他负载、模块启动峰值及每格降压损耗需另核算。

本电路从 Type-C 初始 5V 独立启动 PD，不依赖尚未上电的 ESP32。USB1 的数据线和 SBU 不连接。新口原始电源不接原调试 USB 的 VBUS 或 5V_IN。

| 功能 | 器件与设置 |
| --- | --- |
| PD | U101 STUSB4500QTR；CC1/CC2 与对应 dead-battery 脚相连；ADDR0/1 接地 |
| 输入资格 | Q101 受 VBUS_EN_SNK 控制；Q102 受 POWER_OK2 控制；需要两者同时有效，避免 POWER_OK2 拔线后的保持状态误启动 |
| 输入保护 | U104 TVS2200；D104 ESDA25W；两个 MOS 的栅源分别用 12V 齐纳保护 |
| 升压 | U102 TPS55340RTER，非同步拓扑，L101 10µH，D101 SS54；R110=95.3kΩ，约 500kHz |
| 输出设定 | R112=187kΩ、R113=10kΩ，升压节点约 24.21V；经过 eFuse 导通压降，母线约 24V |
| 环路初值 | R111=2.55kΩ、C115=100nF、C116=100pF；需按实际电容偏压衰减与负载验证 |
| 输出保护 | U103 TPS26600PWPR；欠压约 22.37V，过压约 26.18V，限流标称约 1.68A |
| 输出启动 | C117=220nF，计算输出斜坡约 42.6ms；MODE 经 402kΩ 接 RTN，为限流后锁存故障模式 |

TPS26600 内置背靠背 MOS，负责输出反向阻断和 ORing；不另叠加此前规划中的 LM74700。**PD_RTN 与系统 GND 是不同网络**，U103 的裸露焊盘、编程电阻和 dV/dt 电容按手册接 RTN。SHDN# 利用内部上拉，故障后断开该入口电源复位；未将 SHDN# 错接到 24V。

正常按一个角落接电源使用。多个入口的防倒灌设计不代表保证均流、功率叠加或无缝切换。无效/不足的 PD 合同不应启动母线。

## 必须执行：STUSB4500 NVM 配置

U101 不能按未经核对的出厂默认值直接投产。配置要求已写在原理图框内：

| 配置项 | 要求 |
| --- | --- |
| PDO1 | 5V / 0.5A，仅控制电路启动 |
| PDO2 | 20V / 3A |
| PDO count | 2；禁用第三 PDO |
| POWER_ONLY_ABOVE_5V | 1 |
| POWER_OK_CFG | 2（二进制 10，配置 2） |
| REQ_SRC_CURRENT | 0，使用配置的受电电流要求 |
| I²C 地址 | 0x28 |

J101 从 1 至 5：GND、外部编程器 3.3V、SCL、SDA、RESET。3.3V 仅供 I²C 上拉；写入时 USB 电源必须给 U101 的 VDD 供电。按 ST 官方工具/流程生成配置、写入、读回并重新插拔验证。本次没有生成或烧录经硬件验证的 NVM 字节镜像。

## 制板与样机仍需验证

连续 1.5A 和效率是设计目标，未做样机实测。PCB 阶段需实现升压开关回路、电感/二极管/输入输出电容邻近放置、IC 散热裸露焊盘与足够铜面积。10µF 陶瓷电容按 20–24V 直流偏压核算有效容量；补偿参数需环路/负载阶跃确认。TPS55340 的 5A 开关能力不能直接当作 24V 输出 5A。

上电验证依次覆盖：NVM 读回、插头正反插、仅 5/9/15V 或 20V 电流不足的源不能启动、20V/3A 成功启动、24 个模块实际并联电容与负载启动、额定负载温升/纹波、短路锁存复位、拔线与重协商、母线已经带电时插入第二个入口的反向电流。软件 DRC 和网表一致性不能替代这些电源验证。
