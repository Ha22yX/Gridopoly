另外：

- U23 从 LMR16030PDDAR/C90665 替换为 LMR16030SDDAR/C136648，使用原有芯片位置，新增外接 SS 电容。两者同属 TI DDA 封装，但库封装记录有区别，PCB 同步时仍须核对散热焊盘。
- 复用 C53/C344180（100nF、100V）作为 eFuse 输入旁路，移到 HP_RAW。不是再增加一个旁路电容。保护后的本地电容仍有 C52/C55 两颗 2.2µF 和 C54 47µF。
- 保留原有 U24 PTC 和 D6 TVS；D6 位于 PTC 后、eFuse 前。
- 删除初版额外的 C201、R203、R207、R208、R209；最终位号跳号是有意的。
- SHDN 按 TI 官方支持说明保持开路，并设置 NC 标记。UVLO、OVP 必须连接，不得悬空。
- EN 支持最高 60V 工作，因此 R206 可直接上拉到受保护的本地输入，不需要额外下拉电阻；FLT 有效时拉低 EN。

新增本体面积约 20.4 mm²（只算芯片与阻容外形）。这不是布局占地，不能据此承诺 PCB 已放得下；焊盘、间距、RTN 热铜和走线要单独评估。没有扩大板框或移动板间接口，也没有改动 PCB。

## 电源路径

`板间 24V_BUS 直接贯通 → U24 PTC → HP_RAW → U201 eFuse → 24V_BUCK_IN → U23 → 5V_FROM_24`

电气上各模块从 24V 母线并联取电。U201 只保护本模块，不串入所有下游模块的总供电路径。原有 TPS2121 电源选择及其后电路保留。

角落模块的 USB-PD/LM5176/LM74700 入口保持原有连接。入口仍要求单口 20V/5A 的 100W PD 电源及 5A 带电子标记线缆，STUSB4500 NVM 仍需编程和读回验证。60W 定义为 24V 母线总取电，包括模块降压损耗和保护器件耗电；不是另有 60W 终端负载再叠加所有损耗。

## 参数与启动顺序

1. 共用分压链为 `HP_RAW—220k—HP_UV—4.7k—HP_OV—10k—HP_RTN`。
2. UVLO 上升标称 19.16V，OVP 上升标称 28.16V。含门限规格、1% 电阻初始容差及输入漏电，计算区间分别约 18.45–20.05V、27.13–29.47V；尚未包含电阻温漂。
3. eFuse 首先给约 51.4µF 本地输入电容缓慢充电，24V 时标称约 0.49s。FLT 在充电过程保持有效，随后按内部 PGOOD/去毛刺规则释放。
4. FLT 释放后 U23 才启动，SS 标称约 0.55s。芯片只给出了 SS 充电电流典型值，因此不能把这个时间当作保证的最短时间。
5. 本地支路限流标称 152mA，连同限流电阻初始容差估算约 144–161mA。适用于用户给定的每模块约 1W 负载；不再代表这一路可持续提供芯片名义上的 5V/3A。
6. HP_RTN 与 GND 必须分开。U201 散热焊盘接 HP_RTN，UVLO、OVP、ILIM、dVdT 的参考端接 HP_RTN；系统 GND 接第 6 脚。不得用整块 GND 覆铜误短接 RTN。

计算见 `PCB Files/ModulePower/Hotplug/hotplug-envelope.py` 与 JSON。按所列电容容差估算，单模块预充电电流约 2.5mA 典型，上界示例约 4.76mA；40 个模块同时预充电约 0.19A，计入控制器和分压支路约 0.234A。该模型不包括 100nF 输入旁路的最初尖峰、连接器弹跳、线缆电感、5V 侧启动负载和环路动态，不能作为实测证明。

此设计解决原接收端在低母线电压就提前启动、输入大电容直接接入的问题。它不检测模块数量，也不需要先计数再供电；输出电流由负载决定。热插拔期间的接触顺序、误短接、整段断环以及超过 60W 总预算仍需另外验证。

## 已做验证与当前限制

- 两块原理图均已保存。精简后长边模块 423 个、角落模块 691 个已连接引脚的网表核对无不符；所有新增电源器件的预期连接及 SHDN NC 均匹配。
- 原有连接的有意变化仅为 U24-2、D6-1 转 HP_RAW，C53-2 转 HP_RAW，U23-3 转 HP_RUN，以及原悬空 U23-6 接 HP_SS。
- 角落原 PD 区域连接保留。电源修改范围外的图元与精简前最新源文件比较一致；期间观察到其他区域的排版变化，按最新源文件保留，没有用最初快照覆盖。
- 最终 DRC API 汇总：长边 2 条警告、角落 4 条警告，未返回错误分类。API 未提供警告明细，本次没有豁免或声称清零；这些警告应在 EDA 中逐项审核后再放行打板。
- 这不是完整 PCB 交付，也不是热插拔认证。PCB 尚未同步和布线；未验证高温、满载短路、冷启动、负载阶跃、USB 协商和环路相位裕量。

## 下一阶段的具体布局约束

1. 先在长边板现有电源区安排 U201 和 7 个阻容，确认实际占地后再同步角落板；优先复用 C53 的器件和局部位置，不扩大接口结构。
2. C53 靠近 U201 IN/GND，U201 OUT 后才放 C52/C55/C54 和 U23 VIN。大电容不能重新挂回未限流的 24V_BUS。
3. U201 支持阻容靠近引脚，RTN 使用独立小铜区，EP 与 RTN 相连，保持与 GND 的间隔；限流及 dVdT 走线短。
4. U23 原高频功率回路尽量保留，SS 电容贴近第 6 脚与 GND。仅替换芯片不能实现本次方案。
5. 保留 D6、PTC 和总线贯通路径；复核保护前后的网络及测试点 TP5 仍在受保护侧。
6. 实物按单模块、16/24/32/40 模块、0–60W 负载、插入与拔出、掉电恢复、故障支路测试。应记录母线跌落、5V 电压、浪涌、电源重试和器件温升，确认后才可声称稳定热插拔。
