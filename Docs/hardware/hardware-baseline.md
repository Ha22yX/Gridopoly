## 设计源

工程为 Gridopoly，本地工作工程为 `PCB Files/Gridopoly.eprj2`。两种板的 UUID、接口、机械约束与导出优先级见[两种 PCB 设计](pcb-variants.md)。`Gridopoly-current.epro2` 及日期备份不保证与编辑中工程一致。

旧 2026-07-31 的 144 器件/136 BOM 数量只描述当时单板快照，已不能代表两种当前板。最终采购数量必须从各自下单快照导出；不要将原理图图元数、连接引脚数与 BOM 元件数混用。

| 子系统 | 当前原理图基线 |
| --- | --- |
| MCU | U3 ESP32-S3-WROOM-1-N16R8 / C2913202 |
| LCD | ST7789，240×320，只写 SPI；J4 DS1023-2*4SF11 / C92271 |
| RFID | U1 HTRC11001T/03EE,11 / C501317；外部 4MHz 有源振荡器；线圈需装配调谐 |
| RGB | U12～U21，10 × WS2812B-B-V6 / C52941391 |
| RS485 | U6 SN65HVD75DR / C57928，硬件预留；当前 Tile V0.32 未启用传输 |
| ORDER | GPIO9 输入、GPIO10 经 Q1 开漏输出；当前物理信标 + HTTP 上报 |
| 支路保护 | U201 TPS26621DRCR / C1848341，新增 7 个配套阻容 |
| 24V→5V | U23 LMR16030SDDAR / C136648，外接 SS；替代旧 PDDAR |
| 本地电源选择 | U9 TPS2121RUXR / C485916 |
| 本地电量 | U10 INA226AIDGSR / C49851；R31 10mΩ 2W 1% / C346923 |
| 3.3V | U25 TPS62160DGKR |

板间接口为每侧 9 触点（3 正极、3 地、A/B/ORDER 各 1），详见[互连定义](module-interconnect-5wire.md)。J1 是本地 USB 5V/调试口；角落 J301 为直接24V入口。

## 当前供电路径

```text
角落 J301 → F301保险丝 → D301反接/回灌阻断 → 24V_BUS（D302 TVS及C301/C302对地）
                                                                          │
板间 24V_BUS 直通 ── 本板 U24 → HP_RAW → U201 → 24V_BUCK_IN → U23 → 5V_FROM_24
                                                              5V_FROM_24 → U8 → TPS2121 IN1
本板 J1 USB_VBUS → U7 ────────────────────────────────────────────────────────→ TPS2121 IN2
TPS2121 OUT → 5V_SELECTED → R31 → 5V_IN → TPS62160 → 3V3_SYS
                                      └→ FB1 → 5V_RFID
```

U201 只保护本地支路，不串在下游总线中；HP_RTN/EP 不是 GND。INA226 只测本板 5V 侧，不能直接测整盘 24V 总功率。PWRMUX_STATUS 未接 MCU；RFID 振荡器 OE 硬件上拉，不能虚构软件关断 GPIO。

## 电源能力及边界

- 当前入口是稳压24V直流电源，选型建议24V/5A（120W），5.5×2.1mm中心正极；额定电源功率不等于板端允许负载；单板或16–40模块、总负载60W为设计目标。
- 母座5.5×2.1mm中心正极。总线电压随输入及D301/线缆压降变化，不再有PD或24V升压闭环。
- PD NVM、GPIO13复位与旧67.13W计算取消。INA226仍仅测本板5V功率。
- 保留本地U201限流/软启动及U23降压；约1W模块的原限制仍适用，全白LED与外设功率需重新预算。
- 新入口原理图和PCB网络已更新；PCB布局布线、散热、全板DRC、40板同时启动与热插拔验证未完成。不得宣称已稳定投产。
- 当前设计默认一个直流注入点，不承诺多适配器均流。详情见[直接24V入口](corner-dc24-input-2026-09-21.md)。

## 板层与发布门槛

现有 PCB 沿用 Top、Inner1～Inner4、Bottom 共 6 铜层。用户指定1.6mm六层板、外层1oz；具体介质、内层铜厚与 USB 90Ω 阻抗表仍需板厂确认；板厂叠层变化需重新算线宽与回流。

保留 C19/C20 RFID 调谐及 R15 终端 DNP 意图，并从最终 BOM 再核对。测试点不采购。剩余器件属性匹配类原理图警告按用户要求暂不修；这不豁免电气、封装、焊接方向、网络和 PCB DRC。
