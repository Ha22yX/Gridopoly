## 5. 当前电源边界

```text
24V_BUS -> U24 PTC -> 24V_BUCK_IN -> U23 -> 5V_FROM_24
5V_FROM_24 -> U8 PTC -> TPS2121 IN1
USB_VBUS -> U7 PTC -> TPS2121 IN2
TPS2121 OUT -> 5V_SELECTED -> R31 10mΩ -> 5V_IN
5V_IN -> U2 -> 3V3_SYS
5V_IN -> FB1 -> 5V_RFID
```

- `24V_BUS` 在模块之间直通；U24 只保护本模块降压支路。
- INA226 只测量本模块 `5V_IN` 电流，不测量整条 `24V_BUS`。
- USB 是第二路供电输入，但当前没有 Type-C 电流宣告检测。接普通电脑 USB
  时必须使用低功耗固件配置，不能默认允许 LED 全白和高背光。
- `PWRMUX_STATUS` 参与 TPS2121 的硬件优先级/迟滞网络，但没有连接 ESP32
  GPIO；固件不能直接读取当前由 USB 还是 24V 支路供电。
- INA226 的 ALERT 引脚未连接，固件只能轮询电压、电流和功率。
- RFID 4MHz 振荡器 OE 由 10kΩ上拉到 `5V_RFID`，没有软件关断 GPIO。
- 24V 母线扩展到大量模块时必须分段注入，不能只靠第一个模块串行承载全部电流。

## 6. 尚未通过的产品级验证

当前设计是“可用于继续开发和打样验证的硬件基线”，不是已经完成量产验证：

1. 最终 Gerber 的零未布线、零短路和完整 DRC 尚需在下单快照上确认。
2. 6 层板厂叠层、USB 90Ω差分阻抗和铜厚尚需随订单冻结。
3. 24V、5V 主电流路径、过孔阵列、触点温升和最远端压降需要实测。
4. LMR16030 与 TPS62160 的 SW 回路、热设计和纹波需要首板验证。
5. RFID 线圈必须在屏幕和结构件装配后调谐，4.22nF 只是起始值。
6. 多模块 RS485 的终端、电容负载和最高波特率必须通过示波器验证。
7. 125kHz EM4100/TK4100 方案没有防冲突能力，多个标签同时进入同一线圈区域
   时不能保证读取任意一个或全部标签。

## 7. 变更规则

以下变化属于硬件接口不兼容变化，提交时必须同步修改文档和固件板级配置：

- ESP32 GPIO、连接器针序或连接器公母型号变化。
- `24V_BUS`、`5V_IN`、`3V3_SYS` 或电源选择逻辑变化。
- INA226 分流电阻、电流方向或 I2C 地址变化。
- LED 数量、级联顺序或逻辑电平转换变化。
- RS485 收发器、A/B 定义、终端方式或 ORDER 有效电平变化。
- RFID 线圈、电容组、时钟或数字接口变化。

每次变更后应重新通过 API读取 PCB 焊盘网络，并在文档顶部更新日期。
