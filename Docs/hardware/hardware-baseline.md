## 当前供电路径

```text
角落 USB1 → STUSB4500 合同门控 → TPS26632 → LM5176 → LM74700/Q107 → 24V_BUS
                                                                          │
板间 24V_BUS 直通 ── 本板 U24 → HP_RAW → U201 → 24V_BUCK_IN → U23 → 5V_FROM_24
                                                              5V_FROM_24 → U8 → TPS2121 IN1
本板 J1 USB_VBUS → U7 ────────────────────────────────────────────────────────→ TPS2121 IN2
TPS2121 OUT → 5V_SELECTED → R31 → 5V_IN → TPS62160 → 3V3_SYS
                                      └→ FB1 → 5V_RFID
```

U201 只保护本地支路，不串在下游总线中；HP_RTN/EP 不是 GND。INA226 只测本板 5V 侧，不能直接测整盘 24V 总功率。PWRMUX_STATUS 未接 MCU；RFID 振荡器 OE 硬件上拉，不能虚构软件关断 GPIO。

## 电源能力及边界

- 目标：一个角落接 USB，为单板或 16–40 个约 1W 模块供电。电气为并联负载，物理可以围成棋盘。
- 入口要求单口 20V/5A 的 100W PD 电源和 5A e-marker 线；配置正确后自主协商。小负载也不意味着任意 5V 充电器兼容。
- 60W 是 24V 源出口预算，包含下游损耗。72W 是应力计算点，不是额定连续保证。约 67.13W 的容差估算仍依赖最低 18V/效率 90% 等假设，不能写成实测冗余。
- 反馈标称 24.32V；元件容差、输出开关及连线导致各节点电压不同。负载变化由恒压电源调节电流，不需软件数模块来调电压；0W 外部负载时源板仍耗电。
- 本地限流约 144–161mA，适用约 1W 模块；5V 大功率外设和全白 LED 必须重新预算，不能按 U23 的 3A 芯片名义输出使用。
- 计算要求每连接段热态正负回路合计 ≤40mΩ、每板 5V 有效电容 ≤1mF、当地降压效率 ≥85%。这些尚须 PCB/实物核验。
- 默认一个 USB1 注入点。输出防反灌不等于多角落电源均流，未验证多充电器并联功率叠加。

详见[理论复核](unified-power-theory-review-2026-09-21.md)和[供电验收](power-system-acceptance.md)。闭环电源、ORDER 顺序链和 RS485 拓扑是三个独立问题。

## 板层与发布门槛

现有 PCB 沿用 Top、Inner1～Inner4、Bottom 共 6 铜层。最终介质、板厚、铜厚与 USB 90Ω 阻抗表未冻结；板厂叠层变化需重新算线宽与回流。

保留 C19/C20 RFID 调谐及 R15 终端 DNP 意图，并从最终 BOM 再核对。测试点不采购。剩余器件属性匹配类原理图警告按用户要求暂不修；这不豁免电气、封装、焊接方向、网络和 PCB DRC。

当前尚缺：PCB 同步与布线、PD NVM 固件/镜像、真实协商、整盘启动、轻满载环路/纹波、触点温升与压降、插拔/短路瞬态、RFID/射频及机械对插验证。
每次接口变化同时更新原理图、PCB、板级配置及文档；允许明确记录“原理图已改、PCB 待同步”，禁止把两个阶段写成一个已完成状态。
