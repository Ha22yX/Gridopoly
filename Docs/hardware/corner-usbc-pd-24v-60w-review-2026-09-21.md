# 角落模块 USB-C → 24V：0–60W 入口设计复核

日期：2026-09-21（UTC）。**状态：原理图工程样机方案，尚未完成 PCB、环路仿真和实物带载验证；不能据此宣称“完美供电”或直接签核量产。**

## 当前需求与工作范围

- 单独一个角落模块可以作为轻载场景；扩展到 16–40 个模块，总负载按 60W 预算。
- 24V 恒压，负载自行取电。模块数量变化不需要改变母线设定电压；“动态调整”指实际电流随负载变化，不是软件计数后切换电压。
- “0W”指没有外接负载，角落模块及电源自身仍有功耗。本方案未设置依赖最小外部负载的使能条件。
- 入口规格：单口能够提供 **20V/5A 的 100W PD 电源**，配 **5A 带电子标记的 C-C 线**。即使只接一个模块，当前固定 PD 策略仍要求这项合同；不兼容任意普通手机充电器。多口充电器总标称 100W 不等于当前端口始终提供 100W。
- 只修改角落模块原理图指定矩形。没有修改接收端 24V→5V、电路框外、长边模块或 PCB。允许的 USB1 型号更换已包含在内。

## 已写入嘉立创EDA的电路

`USB1 → STUSB4500 协商与双开关资格判断 → TPS26632 输入保护 → LM5176 四开关升降压 → LM74700 + MOS 防反灌 → 24V_BUS`

| 部分 | 当前器件 / 设置 | 作用 |
| --- | --- | --- |
| USB1 | HX TYPE-C 16P 3MD 5A / C5178540 | 厂家图纸标 20V、5A；两对 VBUS 与两对 GND 在焊尾合并，按图纸接全部电源焊尾 |
| U101、Q101/Q102 | STUSB4500QTR、AO4407A | 由 USB 自主供电；同时检查连接状态和目标合同，防止未协商就带起总线 |
| U105 | TPS26632RGER / C1850278 | 输入限流约 4.5A；UVLO 和 PGTH 标称 16.8V，PGOOD 控制转换器使能 |
| U102 | LM5176PWPR / C442493 | 同步四开关升降压；启动时能够从低输出电压逐渐升至目标 |
| Q103–Q106、L101 | CSD18540Q5B；4.7µH TMPC1707HP-4R7MG-D | 电感厂家额定 25A 温升电流，41A 对应电感量下降 20%，不能把 50A 说成不下降的额定电流 |
| D107/D108 | SS14 / C2480 | 补齐两路高侧自举电容的充电通路，阴极接 BOOT，阳极接 VCC |
| R123 | 4mΩ、2W / C337225 | 开关周期电流检测；必须 Kelvin 布线 |
| C120/C121 | 2.2µF、50V X7R / C125847 | 软启动和补偿；替换已缺货的 C19110 |
| U103、Q107 | LM74700QDBVRQ1、CSD18540Q5B | 输出防反灌；不代表多路均流或功率叠加 |
| R121/R122 | 294k/10k，均 0.1% | 反馈目标 24.32V，给输出开关及布线留少量压降空间 |

输出为 **24V 标称母线**，不是所有节点任何时刻都精确 24.000V。输入保护放在转换器之前，避免原低电压母线串联限流器过早限制冷启动电流。没有改动其他模块的启动门槛。

## 计算结果及边界

以下为参数检查与简化模型，不是硬件实测。可重复计算见 `PCB Files/CornerModule/PD24/power-envelope.py`，结果见同目录 `power-envelope.json`。

### 稳态、轻载与余量

60W / 24V = 2.5A。功率级按 72W / 3A 作为设计目标，相比 60W 留 20% 标称余量。

按 90% 效率估算，20V 输入时 60W 输出约取 3.33A。输入 eFuse 电流限值叠加电阻容差约 4.14–4.86A；在 18V、90% 效率和最低限值的组合下，仅约有 **67.1W** 输出预算，再减环路损耗。因此 **72W 不是所有输入公差下的连续输出保证**，效率也尚未测量。

反馈初始容差估算约 23.91–24.74V，尚未含电阻温漂、动态偏差和输出开关压降。输出 47k 泄放电阻约耗 12.6mW，此外还有控制器、驱动和角落模块功耗；不应把空载输入功率写为 0W。

补偿初值：6.8k + 2.2µF，另并 1nF；补偿零点约 10.6Hz、高频极点约 23.4kHz。以本地有效电容 160µF 至整环约 2.68mF、18–21V 输入作简化估算，增益交越约 0.64–12.6kHz。这是典型参数下的渐近估算，**没有得出经过验证的相位裕量**，没有包含线缆谐振、各降压器的负增量阻抗、器件温漂及输出防反灌切换。空载与单模块要独立测试，不能从 60W 工作点推导它们一定稳定。

### 冷启动尚未闭环

C120 对应标称约 352ms 软启动；加入所选电容初始容差、X7R 温度变化和充电电流范围，示例最短约 209ms。40 个现有模块加入口输出电容的上界估计约 2.72mF，爬升充电电流约 0.32A。

现有接收端可能从约 4V 起开始取电。假设母线 3.8V 时已经有 60W 恒功率负载，则输出需求约 `60/3.8 + 0.32 = 16.11A`；这已接近简化的最低周期限流估算 16.34A，尚未计检测偏置、斜坡、温漂与线损。**这不是启动通过的证据**。真实 5V 降压负载在该电压下通常不会表现为完整的 60W 恒功率，但必须测量，不能凭推测消除风险。

如果实测启动不能通过，需要进一步设计入口储能/负载接通时序或与用户讨论接收端时序；当前没有越界修改接收端。数安培以上的启动脉冲也需检查板间连接器、铜箔与 MOS 的脉冲承受能力。

### 整环压降

环形连接是 24V 电源并联分配，模块不是电气上的串联负载。以下简化模型将 60W 均匀分布到远离供电点的 39 个节点，供电点取约 23.89V；每段电阻包含正向铜线、回流铜线与连接器。

| 每段正负回路合计电阻 | 40 节点、60W 最远节点 | 整环线损 |
| --- | --- | --- |
| 0.05Ω | 23.23V | 1.16W |
| 0.075Ω | 22.89V | 1.78W |
| 0.10Ω | 22.54V | 2.43W |

若采用 24V ±5%（22.8–25.2V）作为设计验收目标，0.075Ω 的例子几乎没有额外余量，不能据此认定实际 PCB 已合格。负载不均、断环、连接器老化和温升会改变结果。PCB 尚未修改，也没有测得其真实分段电阻。

## PD 编程及上电要求

STUSB4500 必须预先烧录并读回 NVM；画图不会自动完成芯片编程：

- PDO1：5V / 0.5A；PDO2：20V / 5A；PDO 数量 2。
- `POWER_ONLY_ABOVE_5V=1`，`POWER_OK_CFG=2`，`REQ_SRC_CURRENT=0`。
- 20V 监测窗口拟使用 `SHIFT_LL2=5`、`SHIFT_HL2=1`，即标称 -10% / +6%；监测精度及切换行为需纳入实测。
- 保留 ATTACH/VBUS_EN 与 POWER_OK2 的组合控制，不能只依赖拔线后可能保持状态的 POWER_OK2。
- 本次未实际烧录 NVM、未连接 PD 分析仪，也未证明充电器已协商成功。

## 已完成的验证

- 从运行中的嘉立创EDA导出 74 个器件、287 个引脚，逐一比对期望网络，0 不符；24 个脚有意不连接。
- 0 重复位号；框内不同网络线段 0 相交/重叠；图面已导出检查。
- 框外图元与基线逐项比较无变化，框外引脚网络亦无变化。
- 最新 DRC 汇总仍为 3 条警告，没有返回错误分类；当前 API 没有给出警告明细，不能称 DRC 已完全清零。
- 35 个实际型号在 2026-09-21 UTC 的 LCSC 页面库存均 ≥100，最低 360；库存不是锁定数量。详见 BOM 与库存快照。
- 目标原理图已保存；本次没有把这些新元件同步或布局到 PCB。

## 样机验收还需完成

1. 先用限流实验电源验证电源级，再接满足规格的 PD 充电器；核查正反插、协商失败关断、拔线、防反灌。
2. 测空载、单角落模块、16/24/32/40 模块冷启动，记录总线与输入电流、各 5V 电压，不得出现循环重启。
3. 测 0↔1W、1↔60W 和中间负载阶跃、模块热插拔；确认过冲、跌落、纹波和环路相位裕量。
4. 在实际 PCB、线材、连接器、机壳和最高设计环境温度下测 60W 连续温升、远端电压及保护恢复。24V±5%、相位裕量≥45°可作为初始验收目标，最终纹波与瞬态要求由接收端需求确定。

在这些验证前，正确结论是：**原理图已按单模块至 60W 的目标升级并完成结构检查；实物是否稳定仍待验证。**
