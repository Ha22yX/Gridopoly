# Gridopoly 单格模块首板调试清单

> **2026-10-15 状态补充：** 16块（12长边＋4角落）已完成V0.34写验并接入24V；用户将线圈略抬高于LCD后确认16板均可识别Tag，服务端也取得16个reader stable证据。USB热点已实证16格＋4屏共20台关联/注册，唯一16节点ORDER环ready、0～15及四角0/4/8/12自动分配通过；Pi软件重启后自动恢复原房间，按实际开启的16格＋3屏完成121.18秒观察。来源：[USB部署与启动验收](../firmware/usb-ap-deployment-2026-10-15.md)、[线圈装配反馈](../firmware/tile-rfid-screen-coupling-2026-10-15.md)、[16格试玩记录](../firmware/trial16-release-2026-10-15.md)。

> 本清单保留为逐板/逐版本执行模板，未勾框不否定上述单独记录的功能结果。量化电压、纹波、温升、启动浪涌与保护、最终结构射频及完整实体对局仍待验；软件重启不代替完全断电且无家庭网络的冷上电。13板灯效已有用户确认，COM16/17/18仍待单独目视；原故障COM19继续隔离，替换COM10正常不等于原板修好。

本清单用于首块 PCB 和每次重大硬件版本变更后的上电验证。所有测量值、波形、
环境温度和固件提交号都应保存到测试记录，不要只记录“能亮”。

本清单只覆盖长边PCB2_1和角落PCB2_5，两种板分别执行；不套用于独立玩家电池底板。当前已只读复核棋盘机械/布局来源，用户确认自然插合同面共面；实物批次与制造文件仍待绑定，直接24V及接收端保护仍需同版电气验证。完整范围另见[统一供电验收](power-system-acceptance.md)，玩家板另见[玩家底板](player-usbc-battery-base-2026-09-27.md)。

固定结构按[三模块首件R2](../../Mechanical/BoardBase/README.md)及[整盘Full16 R1](../../Mechanical/BoardBase/Full16_R1/README.md)检查孔位、无应力对插和底面净空。R2打印件配合已获用户确认；Full16新增长边—长边接缝、全环闭合、紧固强度及拼接承载仍待验。旧14mm架高/滑移建议仅留历史。

## 1. 上电前

- [ ] 确认测试对象为长边PCB2_1或角落PCB2_5，记录PCB revision及是否已包含最新供电变更。
- [ ] BOM、贴片坐标和 Gerber 来自同一快照。
- [ ] DRC 无短路、开路、未布线和板外器件。
- [ ] 核对 U23、U25、U9、U10、D3、D6、C32、C54、U22 的方向。
- [ ] 核对 J4、JIN/JOUT 的 Pin 1、公母和镜像方向。
- [ ] 确认 ESP32 天线禁布区没有铜、器件和金属紧贴。
- [ ] 确认 C19、C20、R15 默认不装；TP1～TP5 无需贴片。
- [ ] 万用表测量 `24V_BUS-GND`、`5V_IN-GND`、`3V3_SYS-GND` 无明显短路。

## 2. 24V 支路首次上电

使用实验室电源，不连接 USB、屏幕、RFID 线圈和其他模块：

1. 电源设为 24.0V，初始限流 0.5A。
2. 先观察是否立即限流、冒烟、异味或异常发热。
3. 同时观察HP_RAW、U201输出TP5及HP_RUN：保护后电容受控充电、FLT释放后U23才启动；稳态接近24V。
4. 测量 `5V_FROM_24`，目标 5.0V，允许首轮判定范围 4.75～5.25V。
5. 测量 `5V_SELECTED` 和 TP1 `5V_IN`，应接近 5V。
6. 测量 TP2 `3V3_SYS`，目标 3.3V，允许首轮判定范围 3.20～3.40V。
7. 测量 TP4 `5V_RFID`，应接近 `5V_IN`，仅有磁珠和走线压降。
8. 示波器检查 `5V_FROM_24` 和 `3V3_SYS` 纹波，按单板预算逐步加负载；U201约0.15A限制24V本地支路，不能强行提高电源限流绕过。
9. 红外测温或热电偶检查 U23、L2、D3、U25、L1、U9 和 R31。

任何电压越界或器件快速升温时立即断电，不要继续用固件“试试看”。

## 3. 保留的 J1 USB 5V 调试支路

1. 断开 24V。
2. 首次使用带电流显示或限流的 5V USB 电源，不先接电脑 USB。
3. 确认 `USB_VBUS -> USB_5V_FUSED -> TPS2121 -> 5V_IN` 能供电。
4. 同时接入 24V 和 USB，确认没有反灌，电源选择符合预期。
5. 接电脑 USB 时须先准备并验证低功耗维护模式（待实现），LED关闭、背光低、限制RFID活动；不能把SAFE_USB名称当作现有已实现模式。

J1没有Type-C电流宣告检测，不得据插头外形推定可取3A。旧USB1 PD入口已删除；当前无需NVM编程和PD合同验收。

## 4. 烧录和最小固件

- [ ] Windows 能看到 ESP32-S3 USB Serial/JTAG 端口。
- [ ] 按Firmware/TileModule的PlatformIO构建/刷写流程成功，保存app SHA与日志。
- [ ] 自动下载失败时，按住 BOOT，点击 RESET，释放 RESET 后再释放 BOOT。
- [ ] 启动日志包含固件版本、MAC、复位原因和硬件版本。
- [ ] GPIO14 为低，RS485 不主动驱动总线。
- [ ] GPIO10 为低，ORDER_OUT 释放。
- [ ] 背光关闭，WS2812 首帧为全黑。
- [ ] 运行 10 分钟无异常复位、欠压或看门狗。

## 5. INA226

- [ ] I2C 扫描在 `0x40` 找到器件。
- [ ] 写入 Calibration `0x1400`（10mΩ、100µA/bit 基线）。
- [ ] 用独立5V侧仪表对照；24V输入仪表含转换效率，不能直接比较电流数值。
- [ ] 使用已知5V负载在实际支路能力内做多点校准；不从限流后的24V支路强拉5V/1A。
- [ ] 电流方向为正：`5V_SELECTED -> R31 -> 5V_IN`。
- [ ] 核对 Kelvin 采样没有被主电流铜皮压降污染。

## 6. 屏幕

- [ ] 再次核对 J4 镜像针序后再插屏。
- [ ] 先用默认8MHz SPI 显示纯红、纯绿、纯蓝、黑、白测试图。
- [ ] 确认方向、宽高、颜色字节序和 DC/CS/RST。
- [ ] 背光 PWM 从低占空比逐渐提高，并记录整板电流。
- [ ] 40MHz仅在指定板验证并按设备身份启用，不推广到其他板或更高频率。
- [ ] 连续刷新 30 分钟无花屏、复位和明显温升。

## 7. WS2812

- [ ] 依次只点亮 U12 到 U21，确认物理顺序与文档一致。
- [ ] 分别显示纯红、纯绿、纯蓝，确认 GRB/RGB 顺序。
- [ ] 亮度 10%、25%、50% 分档测量 5V 电流。
- [ ] 全白测试仅在台式电源、温升和电流限制允许时短时执行。
- [ ] 复位、失联和异常时 LED 能回到全黑或规定故障色。

## 8. RS485（未来传输启用后的独立验收）

先连接 2 块模块：

- [ ] A 对 A、B 对 B、GND 连通，无镜像错误。
- [ ] 两端安装 120Ω，中间节点不装 R15。
- [ ] 从 115200bps 开始双向收发和 CRC 校验。
- [ ] 验证发送完成后 GPIO14 能及时回到低。
- [ ] 再测试 921600bps，并用示波器观察最远端差分波形。
- [ ] 2Mbps/5Mbps 只在终端、支线和波形均通过后测试。
- [ ] 逐步增加模块，记录错误率、重试率和总线空闲电平。

## 9. ORDER V1物理信标

当前16板唯一环、自动分配及四角位置已有实物记录；下列完整项目还包括未完成的实体断环/复接、锚点重派及异常场景，不能以正常闭环代签全部检查。

- [ ] 无上游GPIO9为高；GPIO10低释放，高经Q1拉低下游。
- [ ] 独立6秒信标、CRC、序号与HTTP上报对应，不用注册顺序猜邻居。
- [ ] 卡低、缺帧、旧序号、调度异常使证据失效；复位后新bootId生效。
- [ ] 人工锚点前后派生正确，多个人工锚点保留，冲突暂停。
- [ ] 拔线/复接、模块掉电/重启后租约与显示恢复，不重复游戏结算。
- [ ] 使用V0.34正确long/corner profile：当前16格实体环为12长边＋4角落、四角0/4/8/12；全部在线格子恰好组成同一环，数量及实际角落类型与地图匹配，唯一邻接和新鲜租约成立；断环撤销派生、重接恢复、锚点改派均留实物证据。服务端支持目录16/24/32/40环，其余规模与单板/开链分别验收，不由软件回归推定实体通过。

## 10. RFID

当前已确认线圈略高于LCD时16板基础识别正常，并有服务端16个reader stable记录；具体抬高尺寸尚未量化。以下最终结构调谐、读距和多标签/邻格测试继续保留，不将早期USB或同平面围屏Fault写成当前16板统一状态。

- [ ] 不接线圈时先验证 4MHz 时钟和 HTRC110 数字通信。
- [ ] 测量实际线圈 L、DCR 和 Q，记录测量频率。
- [ ] 从 C14～C18 的 4.22nF 标称值开始调谐。
- [ ] 在屏幕、外壳、磁铁和最终安装距离都存在时调到 125kHz 附近。
- [ ] 使用合适探头检查天线电压与电流，不用普通低耐压探头直接碰高压谐振点。
- [ ] 按当前HITAG S256驱动验证单标签UID及协议完整性，不套用旧EM4100奇偶校验流程。
- [ ] 测量中心、边缘、不同高度的识别距离和离开去抖。
- [ ] 验证当前HITAG S256多标签防碰撞集合；两个及更多标签、叠放、移动、边缘和相邻线圈分别测试，不把历史两标签通过当全场景通过。

## 11. 多模块电源

- [ ] 从 2～3 块开始，不直接连接 40 块。
- [ ] 在电源端和最远端同时测量 `24V_BUS`。
- [ ] 测量每个连接面的压降和温升。
- [ ] 验证任一模块本地 U24 动作不会切断下游 24V 直通。
- [ ] 按单角落源方案校核最坏累积电流与断环压降；未经多源验证不要自行增加并联24V适配器注入点。
- [ ] 高负载保持至少 30 分钟，记录环境温度、触点温度和最远端电压。

## 12. 进入下一阶段的门槛

只有同时满足以下条件，才能把该版本标记为“硬件验证通过”：

- 制造快照 DRC、未布线和网络短路检查全部通过。
- 24V、5V、3.3V、USB 双路供电和过流行为符合预期。
- 单模块所有外设连续运行无复位和异常温升。
- INA226 与外部仪表校准误差达到项目要求。
- 两块及以上模块完成当前HTTP/ORDER链路；未来RS485若启用需单独通过物理总线验收。
- RFID 在最终结构中完成调谐和识别距离测试。
- 已知限制、测试结果和对应固件提交号写入仓库。
