# Gridopoly 单格模块首板调试清单

更新日期：2026-07-31

本清单用于首块 PCB 和每次重大硬件版本变更后的上电验证。所有测量值、波形、
环境温度和固件提交号都应保存到测试记录，不要只记录“能亮”。

## 1. 上电前

- [ ] 确认测试对象为 `Board1/PCB2_1` 对应的制造文件。
- [ ] BOM、贴片坐标和 Gerber 来自同一快照。
- [ ] DRC 无短路、开路、未布线和板外器件。
- [ ] 核对 U23、U2、U9、U10、D3、D6、C32、C54、U22 的方向。
- [ ] 核对 J4、JIN/JOUT 的 Pin 1、公母和镜像方向。
- [ ] 确认 ESP32 天线禁布区没有铜、器件和金属紧贴。
- [ ] 确认 C19、C20、R15 默认不装；TP1～TP5 无需贴片。
- [ ] 万用表测量 `24V_BUS-GND`、`5V_IN-GND`、`3V3_SYS-GND` 无明显短路。

## 2. 24V 支路首次上电

使用实验室电源，不连接 USB、屏幕、RFID 线圈和其他模块：

1. 电源设为 24.0V，初始限流 0.5A。
2. 先观察是否立即限流、冒烟、异味或异常发热。
3. 测量 TP5 `24V_BUCK_IN`，应接近输入 24V。
4. 测量 `5V_FROM_24`，目标 5.0V，允许首轮判定范围 4.75～5.25V。
5. 测量 `5V_SELECTED` 和 TP1 `5V_IN`，应接近 5V。
6. 测量 TP2 `3V3_SYS`，目标 3.3V，允许首轮判定范围 3.20～3.40V。
7. 测量 TP4 `5V_RFID`，应接近 `5V_IN`，仅有磁珠和走线压降。
8. 示波器检查 `5V_FROM_24` 和 `3V3_SYS` 纹波，再逐步把限流提高到 1A。
9. 红外测温或热电偶检查 U23、L2、D3、U2、L1、U9 和 R31。

任何电压越界或器件快速升温时立即断电，不要继续用固件“试试看”。

## 3. USB 支路

1. 断开 24V。
2. 首次使用带电流显示或限流的 5V USB 电源，不先接电脑 USB。
3. 确认 `USB_VBUS -> USB_5V_FUSED -> TPS2121 -> 5V_IN` 能供电。
4. 同时接入 24V 和 USB，确认没有反灌，电源选择符合预期。
5. 接普通电脑 USB 时使用 `SAFE_USB` 固件：LED 全黑/低亮、背光低、RFID
   间歇运行。

当前硬件没有 Type-C 电流宣告检测，USB 满负载不是默认合格项。

## 4. 烧录和最小固件

- [ ] Windows 能看到 ESP32-S3 USB Serial/JTAG 端口。
- [ ] `idf.py flash monitor` 成功。
- [ ] 自动下载失败时，按住 BOOT，点击 RESET，释放 RESET 后再释放 BOOT。
- [ ] 启动日志包含固件版本、MAC、复位原因和硬件版本。
- [ ] GPIO14 为低，RS485 不主动驱动总线。
- [ ] GPIO10 为低，ORDER_OUT 释放。
- [ ] 背光关闭，WS2812 首帧为全黑。
- [ ] 运行 10 分钟无异常复位、欠压或看门狗。

## 5. INA226

- [ ] I2C 扫描在 `0x40` 找到器件。
- [ ] 写入 Calibration `0x1400`（10mΩ、100µA/bit 基线）。
- [ ] 空载电流接近台式电源读数。
- [ ] 使用已知电子负载做至少 0.1A、0.5A、1.0A 三点校准。
- [ ] 电流方向为正：`5V_SELECTED -> R31 -> 5V_IN`。
- [ ] 核对 Kelvin 采样没有被主电流铜皮压降污染。

## 6. 屏幕

- [ ] 再次核对 J4 镜像针序后再插屏。
- [ ] 先用 20MHz SPI 显示纯红、纯绿、纯蓝、黑、白测试图。
- [ ] 确认方向、宽高、颜色字节序和 DC/CS/RST。
- [ ] 背光 PWM 从低占空比逐渐提高，并记录整板电流。
- [ ] 40MHz 稳定运行后再评估更高频率。
- [ ] 连续刷新 30 分钟无花屏、复位和明显温升。

## 7. WS2812

- [ ] 依次只点亮 U12 到 U21，确认物理顺序与文档一致。
- [ ] 分别显示纯红、纯绿、纯蓝，确认 GRB/RGB 顺序。
- [ ] 亮度 10%、25%、50% 分档测量 5V 电流。
- [ ] 全白测试仅在台式电源、温升和电流限制允许时短时执行。
- [ ] 复位、失联和异常时 LED 能回到全黑或规定故障色。

## 8. RS485

先连接 2 块模块：

- [ ] A 对 A、B 对 B、GND 连通，无镜像错误。
- [ ] 两端安装 120Ω，中间节点不装 R15。
- [ ] 从 115200bps 开始双向收发和 CRC 校验。
- [ ] 验证发送完成后 GPIO14 能及时回到低。
- [ ] 再测试 921600bps，并用示波器观察最远端差分波形。
- [ ] 2Mbps/5Mbps 只在终端、支线和波形均通过后测试。
- [ ] 逐步增加模块，记录错误率、重试率和总线空闲电平。

## 9. ORDER 枚举

- [ ] 无上游令牌时 GPIO9 为高。
- [ ] 上游 Q1 拉低后，GPIO9 稳定识别为低。
- [ ] 当前模块未获得授权时不驱动 ORDER_OUT。
- [ ] `PASS_TOKEN` 后 GPIO10 置高，下一级收到低电平令牌。
- [ ] 超时、复位和异常时 GPIO10 回低并释放链路。
- [ ] 改变模块物理顺序后，`order_index` 随链路变化，MAC 保持不变。

## 10. RFID

- [ ] 不接线圈时先验证 4MHz 时钟和 HTRC110 数字通信。
- [ ] 测量实际线圈 L、DCR 和 Q，记录测量频率。
- [ ] 从 C14～C18 的 4.22nF 标称值开始调谐。
- [ ] 在屏幕、外壳、磁铁和最终安装距离都存在时调到 125kHz 附近。
- [ ] 使用合适探头检查天线电压与电流，不用普通低耐压探头直接碰高压谐振点。
- [ ] 单标签连续读取并通过 Manchester 与奇偶校验。
- [ ] 测量中心、边缘、不同高度的识别距离和离开去抖。
- [ ] 两个标签同时放置时记录为碰撞/无效场景，不把随机 ID 当作有效结果。

## 11. 多模块电源

- [ ] 从 2～3 块开始，不直接连接 40 块。
- [ ] 在电源端和最远端同时测量 `24V_BUS`。
- [ ] 测量每个连接面的压降和温升。
- [ ] 验证任一模块本地 U24 动作不会切断下游 24V 直通。
- [ ] 按分区增加 24V 注入点和保险，禁止让首块模块承担全部累计电流。
- [ ] 高负载保持至少 30 分钟，记录环境温度、触点温度和最远端电压。

## 12. 进入下一阶段的门槛

只有同时满足以下条件，才能把该版本标记为“硬件验证通过”：

- 制造快照 DRC、未布线和网络短路检查全部通过。
- 24V、5V、3.3V、USB 双路供电和过流行为符合预期。
- 单模块所有外设连续运行无复位和异常温升。
- INA226 与外部仪表校准误差达到项目要求。
- 两块及以上模块完成 RS485 与 ORDER 枚举。
- RFID 在最终结构中完成调谐和识别距离测试。
- 已知限制、测试结果和对应固件提交号写入仓库。
