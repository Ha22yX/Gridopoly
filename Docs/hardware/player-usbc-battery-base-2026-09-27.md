## 3. 电路架构

```text
USB-C VBUS → 输入保护/输入限流 → 带电源路径的充电管理 → SYS_RAW
                                      ↕ BAT             │
                              B+ / B− 两线电池           ├→ 5V升压 → 5V_SCREEN → 排线VCC
                                                        │       ↑ EN
                                                        └→ 欠压检测 → 开关锁存控制
USB-C D+/D− → 低电容ESD → USB数据开关 → 排线D+/D−
USB-C CC1/CC2 → Type-C电流能力识别 → 充电管理输入限流选择
排线 RX/TX ↔ SC18IM704 ↔ I²C ↔ MAX17048（BAT_PACK 常供电）
                   ↑ GPIO0/1
             BQ24074 CHG/PGOOD
5V_SCREEN → 现有 U8 3.3V → USB数据开关＋SC18IM704
```

`5V_SCREEN` 不连接 USB VBUS。USB 供电与电池供电由电源路径管理，防止电池经升压输出向电脑供电。充电管理位于屏幕开关之前，因此关闭屏幕后仍可充电。

### 欠压与开关的具体控制关系

TPS3808G01 的低有效开漏 RESET 经上拉和反相后接 MAX16054 的高有效 `CLEAR`；按键接 `IN` 与 GND；`OUT` 控制升压 `EN`。两个控制芯片由开关前的 `SYS_RAW` 供电。升压 EN 设默认下拉，防止控制电源上升/下降过程误启动。不能将低有效 RESET 直接接 CLEAR，否则控制极性相反。

欠压发生时 CLEAR 清除开机锁存；电压回升只是解除关机强制条件，不重新置位锁存。恢复充电后，用户按键开机。插入 USB 默认仅进入可充电状态，不自动点亮已经关闭的屏幕。USB 供电充足时，低电量电池可以继续充电，屏幕可由外部电源支撑。[MAX16054 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX16054.pdf)

阈值采用上臂 715kΩ、下臂 100kΩ，`0.405×(1+715/100)=3.30075V`；当前C5=10nF、R6=100k分别实现滤波与典型300ms恢复延时；按参考±2%、电阻各±1%和SENSE漏电估算，下降阈值约3.16–3.44V。该候选不再声称具有旧草案的独立 3.5V 恢复阈值。监测点为 SYS_RAW，电池端还包含电源路径与导线压降；不能写成精确电量百分比。最终需验证电阻/检测器公差、抗扰、上电复位和保持按键时的清零优先级。[TPS3808 数据手册](https://www.ti.com/lit/ds/symlink/tps3808.pdf)

## 4. 使用状态约定

| 状态 | 屏幕 | 电池/USB 行为 |
| --- | --- | --- |
| 仅电池、按键开机、电量正常 | 电池经升压供电 | USB 数据通道断开 |
| 再按一次关机 | 硬件关闭 5V_SCREEN | 无 USB 时只保留低功耗管理电路 |
| 插 USB、屏幕保持关闭 | 关闭 | 给电池充电；不会枚举或上传屏幕程序 |
| 插 USB、按键开机 | 外部电源优先，必要时电池补充 | 有数据能力的线缆及主机可上传、串口日志和调试 |
| 运行中欠压 | 硬件关断并锁存 | 电压反弹不会自动重启 |
| 欠压后接充电器 | 默认保持关闭 | 先恢复供电/充电条件，再按键启动 |
| 无电池、USB 来源能力充足 | 目标是允许启动 | 必须实测启动浪涌，不承诺任意电脑端口均可 |
| USB 来源能力不足 | 降低充电电流；可由电池补足负载 | 不保证一边运行一边净充电；电池耗尽时仍会关机 |

硬件自动关机表示停止屏幕供电，不等于固件已经实现保存进度/关机动画。欠压保护不依赖玩家固件或游戏网络在线。

## 5. USB 输入电流与上传边界

不能因 USB-C 外形而固定从所有电脑端口索取 1A。拟用 CC 电流识别控制限流；没有确认足够供电能力时采用保守输入限制。有源 CC 控制器已提供 Rd 时不得再并联一组 5.1kΩ。[TUSB320LAI 数据手册](https://www.ti.com/lit/ds/symlink/tusb320lai.pdf)

当前接线：未获得高电流许可时使用 BQ24074 的 100mA 输入模式；确认 Type-C 来源声明至少 1.5A 后，切换到 R2=1.8kΩ 设置的约 0.9A 输入模式。Q2 使用 PNP MMBT3906，使 CC 电源未建立或输出高阻时默认不给高电流许可。TUSB320 的 VBUS 检测支路用三颗 300kΩ 串联得到 900kΩ（1% 时 891–909kΩ），替代缺货的 887kΩ 候选。传统 A-to-C 电脑接口提升到 500mA 所需的枚举、描述符和暂停处理尚未完成，因此本草案**不承诺传统电脑口无电池运行、运行时净充电或完整 USB 电源合规**。

原生 USB 上传复用现有 HWCDC/USB Serial-JTAG。屏幕关闭时不能上传，需要先开机。应用程序禁用 USB 等异常情况下，需验证按住屏幕旋钮（GPIO0）并按本板复位进入 ROM 下载的恢复流程；不能保证所有损坏固件都能自动进入下载模式。

USB 数据隔离拟采用：开关的局部 3.3V 由 5V_SCREEN 产生；无 VBUS 时 OE 保持关闭，屏幕掉电时依靠开关断电隔离。必须核对电源未建立时控制脚与数据脚的漏电，避免 USB 数据经保护结构给关机屏幕回灌。[TS3USB221A 数据手册](https://www.ti.com/lit/ds/symlink/ts3usb221a.pdf)

## 6. 电池、功耗与充电

选用普通 **1S、标称 3.7V、充满 4.2V** 的受保护锂电池。用户候选 2000mAh 尚需确认实际容量、保护板、最大充电电流、连续/峰值放电电流和温度范围；“耐高温80℃”不等于允许80℃充电，“输入4.2–5.0V”也不是可直接给电芯施加5V的依据。

建议核实电池可持续输出至少 2A，并留启动峰值余量。该值来自设计储备：5W 输出、3.3V 输入、85% 假设效率时约需 1.78A，实际以器件、排线和实测负载为准。J3改为PH2.0-2P直插座C131337，1脚GND/BAT−、2脚BAT_PACK/BAT+；电池端配PHR-2兼容插头，保留线材应力释放。连接器有方向性不等于反接保护，必须核对电池插头针序。

在 3.7V×2Ah=7.4Wh、屏幕 5V×0.32A=1.6W、转换效率假设85–90%下，理想估算约3.9–4.2小时。考虑提前欠压关机、电池容量误差、Wi-Fi与亮度变化，前述“约3–4小时”仅是选型估计，不是续航验收结果。

充电目标约500mA，R1=1.78kΩ（2000mAh 的约0.25C），最终上限不得超过电池数据手册。TMR 接 R20=68kΩ，快速充电安全定时约9小时典型；不是承诺9小时充满，低输入能力、热调节和系统分流均会影响充电。线性充电器需检查低电池电压、运行负载与封闭底座内的发热；不得以芯片热调节功能替代热设计。

2026-10-05补充：EEMB官网LP103454电芯手册写充电限制电压4.200±0.020V；BQ24074保证范围为4.16–4.23V，尚未证明全公差匹配。需要确认用户购买的成品包规范并核验终止电压；保护板不是正常充电稳压器，R1也不能调整终止电压。这个问题及已下单板的处理边界见[新复核](../../PCB%20Files/PlayerConsolePower/ProductionAudit-2026-10-05/README.md)。

用户明确不安装温度探头，已删除 J4，改为 R21=10kΩ 将 BQ24074 TS 接地，这是芯片规定的不使用 TS 监测时的接法。电池仍只有 B+/B− 两根线，不会因缺少外接探头而禁止充电。**本板没有电芯温度检测；芯片自身热调节不等同于电池温度保护。** 充电仍须符合所选电池的电流和环境温度范围。[BQ24074 TS 接法，10.2.2.3](https://www.ti.com/lit/ds/symlink/bq24074.pdf)

欠压关机后仍有微小静态电流，不能保证长期搁置绝不继续放电；电池包本身仍需要过充、过放、过流/短路保护。

## 7. 当前80×80 mm布局与布线

用户固定的下边中心为USB-C、左边为J2、右边为POWER/RST。USB与ESD沿左下区域连接J2；充电/升压位于右下，MAX17048在其上方；桥接和屏幕局部稳压靠近J2；欠压与锁存在POWER附近。RC5保留J3 PH2.0-2P插座并按用户修改翻转极性，中心仍在上方(40,5) mm，PCB顶视图左负右正，实际孔距2.0 mm、孔径0.8 mm；用户改接3段末端BAT走线，本轮重铺GND铜。全部68个封装位于顶层，包络检查无相互重叠；板框、四孔、J1/J2与两个按钮的位置不变。详见[RC5交付目录](../../PCB%20Files/PlayerConsolePower/Layout-2026-09-27-RC5/README.md)。

当前为536段走线、82个过孔、上下GND铺铜，原生PCB严格DRC为0项，34项静态核对及11项J3极性检查通过。额外独立解析最终Gerber，41个电气网络、243脚、82过孔、536段线未发现短路、断路或意外NC连接。本轮核对用户已翻转的J3与原理图，修复6项旧地铜间距错误并更新说明；相对RC4只有J3两脚网络互换及3段BAT_PACK末端走线替换，68件位置及82个过孔保持。Gerber/BOM/CPL重新导出；RC1、RC2、RC3、RC4及原投产审查目录保持冻结。

## 8. 固件后续与验收

本轮未烧录现场玩家设备。已完成 UART 电量/充电状态查询的原理图接线，并单独给出[固件接口约定](player-battery-telemetry-interface-2026-09-27.md)。底板没有可编程主控，屏幕固件负责 9600/8N1 查询、解析及显示；厂家触摸版资料已交叉对应TX43/RX44，见[GPIO原图证据](player-screen-uart-gpio-evidence-2026-09-27.md)。玩家端源码和主机回归已接入，构建结果见[固件接入记录](../firmware/player-battery-telemetry-progress-2026-09-27.md)；实物版本、实际复用和首板通信仍须验证。USB 上传与调试继续使用原生 USB，不占用这条查询 UART。

U9 随屏幕断电，I²C 和充电状态上拉均接 `SCREEN_IO3V3`；U10 保留电池供电。GPIO6 上电拉高、VREFP 接 VDD；U10 CTG/QSTRT/EP 接地。电量计保持 EnSleep=0，允许正常休眠估算但不进入停止跟踪的 sleep。避免屏幕关机充电后仍显示旧电量，也避免每次屏幕启动都重置电量计。[SC18IM704](https://www.nxp.com/docs/en/data-sheet/SC18IM704.pdf)、[MAX17048](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX17048-MAX17049.pdf)

CHG 低有效，但不是电池电流测量；CHG 高可能表示充满、再充电、禁用或无有效输入，不能强制显示100%。PGOOD 用于判断有效外部输入，CHG 约2Hz闪烁需作为定时故障候选处理。MAX17048 SOC 是估算值，不替代硬件欠压关机。

制造前及首板验收至少覆盖：

1. 实物排线端到端通断、Pin1、正反插方向、接触电流与电池极性。
2. USB 正反插、C-to-C 与 A-to-C；输入限流、空电池、无电池、插拔及启动瞬态。
3. 满亮度+Wi-Fi 负载下 5V 纹波、压降和热；关闭屏幕后 5V 放电与待机电流。
4. 用限流可调源模拟电池逐渐下降，核对实际欠压阈值、恢复阈值、保持按键、反复插拔和关断锁存；不通过过放真实电芯进行测试。
5. 关机充电、运行充电、充电终止、器件温升、向 USB VBUS/屏幕数据脚回灌电流。
6. 正常固件上传、串口日志、USB 调试和 ROM 恢复；电池供电与 USB 供电切换时不丢失必要状态。
7. UART 查询电压、SOC 与万用表/已知负载比较；开关机、USB插拔、关机充电后的SOC连续性；CHG/PGOOD极性、再充电与定时故障解释。
8. 最终 ERC、引脚/封装交叉检查、PCB DRC、BOM与装配方向检查；通过不替代上述实物验收。

## 11. J3电池插头采购方向（RC5）

用户已购EEMB LP103454 3.7V/2000mAh（Amazon B08HQWXQ6Y），并将原理图和PCB的J3两脚互换。当前J3为JST B2B-PH-K-S(LF)(SN)/C131337，配PH2.0两针PHR-2线端。**1脚接GND/BAT−（黑），2脚接BAT_PACK/BAT+（红）。**

这里的“2.0mm”指相邻触点的中心间距。本板要求的是 **JST PH系列、2针、2.0mm间距**，线端插壳为PHR-2兼容件，板端为B2B-PH-K-S(LF)(SN)。仅标“JST 2.0”或外观相近不能证明可配合；采购应同时核对系列、针数、插壳结构和线序。

线端插壳侧面能看到金属的孔是端子保持窗口，不是FPC排线的单面金手指；“一面露金属、一面不露”不能定义连接器规格，也不能判断正负极。JST脚号规定触点位置，电池线束的红黑接法需另行核对。

| 固定观察方向 | 左侧／第1脚 | 右侧／第2脚 |
| --- | --- | --- |
| PCB元件面朝向观察者，USB-C在下 | J3.1：GND，BAT−，黑线 | J3.2：BAT_PACK，BAT+，红线 |
| 线端保持窗口朝向观察者，出线向上、插接端向下 | 插壳1脚：黑线、负极 | 插壳2脚：红线、正极 |

以上是RC5与所示EEMB商品图的对应关系；其他角度必须先转换观察方向，不能直接照抄左右位置。

- PCB元件面、USB-C朝下观察：J3左负右正。插座位置和180°旋转不变。
- Amazon商品图：金属端子保持窗口朝观察者、出线在左、插接端在右，红线上、黑线下。顺时针转90°后，出线朝上、插接端朝下；按JST图纸1脚在左，对应黑负，2脚红正，与RC5相符。
- 若商家图采用此前“出线朝下、插接端朝上、保持窗口朝前”的方向，本版对应左红右黑，即该图的“2.0红黑”。这只是特定图片方向的称呼，订购应明确PHR-2兼容、黑1红2。
- 原RC4为红1黑2，制造包与本版相反，保留为历史；若订单资料曾上传RC4，也需换成同版RC5并由工厂确认，不能只改EDA界面。
- 本轮发现翻转后的旧地铜接触新正极焊盘，6项间距错误已通过重铺铜修复；严格DRC 0及最终Gerber41网无短路/断路已复核。
- 尚未测量所购实物。到货后先在电池与板断开状态下用万用表核对插头实际极性，再接入；本板无电池反接保护。
