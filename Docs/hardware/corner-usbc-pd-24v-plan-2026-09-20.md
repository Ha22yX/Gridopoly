# 角落模块 USB-C PD → 24V_BUS 电源规划

日期：2026-09-20。状态：历史架构候选。后续已经完成框内原理图，最终采用 STUSB4500 + TPS55340 + TPS26600；以下候选器件不再是当前 BOM。以 [原理图设计与验证记录](corner-usbc-pd-24v-schematic-2026-09-20.md) 为准。PCB 布局和样机热设计验证尚未完成。

## 1. 目标和第一版边界

四个角落采用同一种电源输入电路。任意一个角落连接合格的 USB-C 充电器后，可向共同的 24V_BUS 注入电源。是否能带动全部格子，取决于实测总负载、线束与板间连接器载流能力；本规划不把“有 100W 充电器”当作整盘供电验证。

用户补充：先做 4×6，共 24 个模块，每个模块最多 1W。因此第一版按模块合计 24W 规划，采用 SPR 20V/3A 合同，24V/1.5A（36W）连续输出设计目标。保留 12W、约 50% 的输出预算余量用于损耗与瞬态，但这不是已经验证的峰值能力。

采用单口明确支持 20V/3A 的 60W 或 65W 充电器及合格 3A C-to-C 线，无需为本版强制选用 100W 充电器和 5A E-Marker 线。多口充电器铭牌总功率不能代替该端口的实际合同。65W 适配器即使支持 20V/3.25A，本版也只需取得 20V/3A。

这里暂按用户的 1W 是单模块最大持续功耗估计。需确认测量点：若为 24V 母线输入，24 个模块约 1A；若为降压后的负载功耗，需补算每格降压损耗。还需确认 1W 是否包含屏幕、LED 和 RFID，以及启动峰值。额外玩家屏/树莓派若也接此母线，须另计；若独立供电则不计入。几何上的 4×6 不改变总功耗计算，电气链路长度由实际串联走向确定。

功率不足的适配器第一版只显示状态，不启动整盘母线。日后可增加经过验证的限功率模式；不能简单允许 5V/9V/15V 输入后仍维持 36W 输出。

正常使用约定一个适配器。每个入口具备反向阻断以容忍多个入口带电，但不保证电源均流、功率相加或无缝切换。

## 2. 电源结构和网络

```text
J_PD: USB-C 受电母座，CC1/CC2 连接 PD 控制器
  |
USB_PD_VBUS_RAW (连接初期为 5V，协商后为 20V)
  | 端口 ESD/浪涌保护、保险及 PD 管理的输入开关
PD_20V_IN
  | 同步升压：控制器、外部 MOSFET、电感、电流采样、输入输出电容
PD_24V_RAW
  | 输出 eFuse：真正切断正向供电、欠压/过压截止、限流、软启动
PD_24V_PROTECTED
  | 理想二极管控制器 + MOSFET：防母线向本入口倒灌
24V_BUS
  | 保留现有 U24 → 24V_BUCK_IN → U23 → 本模块 5V 的支路
  + 经板间连接器向其他模块供电
```

所有电源共 GND；这不是隔离电源。PD_20V_IN 不接现有 USB_VBUS 或 5V_IN。保留原 J1 作为调试/本地 5V USB 入口；新口标注“PD IN 20V/3A”，为 Sink-only，不向手机或电脑反向供电。新口的数据脚按所选接口方案处理，不连接原 USB 数据线。

新增的总线注入路径接 U24 之前的 24V_BUS。U24 仅保护本模块降压支路，不能用作整盘入口保险。

## 3. 功能级器件候选

以下是技术候选，不是已核实库存的采购 BOM。最终完整订货号、封装、元件库焊盘与至少 100 件商城/EDA 库存均需在正式选型时核对。

| 功能 | 候选方向 | 设计注意 |
| --- | --- | --- |
| USB-C 母座 | 额定满足至少 20V/3A、CC1/CC2 完整引出的板载母座 | 优先带穿孔外壳固定脚；电源触点全部按手册连接，不能仅凭“Type-C”名称认定载流能力 |
| PD 受电 | TPS25730D | 电阻配置、独立协商、集成输入开关；D 与 S 版本的电源路径不同，不能混用封装/参考图 [1] |
| 20V → 24V 同步升压 | LM5122 + 外部功率器件，或按 36W 重新筛选的小型方案 | LM5122 有 24V 输出 EVM 可参考，但对本版可能偏大，尚不锁定为最终器件；EVM 能力不能直接作为角落板能力 [2][3] |
| 输出切断/限流 | TPS2663x 的过压截止型号，按数据手册确定后缀 | 选择截止而非 35V/39V 钳位行为；限流公差、短路、SOA、启动热耗散需要计算 [4] |
| 输出防倒灌 | LM74700-Q1 + 外部 N-MOSFET | 用于低损耗 ORing；EN 关闭并不切断体二极管的正向供电，因此不能替代上一级输出开关 [5] |
| 启动和状态监督 | 输入侧辅助 3.3V + 小型监督 MCU/逻辑 | 自身从 Type-C 初始 5V 启动，控制功率开关；最终实现需确认 PD 合同读取与故障信号时序 |

LM5122、PD 控制器自身可以独立工作，监督逻辑用于核实实际合同和电源顺序。不能依赖由 24V_BUS 供电的原 ESP32 来首次开启自己的电源。原 ESP32 可以在启动后读取状态，但跨电源域信号必须避免未上电引脚反向供电。

TPS25730 的 SINK_EN 仅指受电开关状态，不代表已取得所需的 20V/3A。CAP_MIS 是能力不匹配的翻转信号，不能当作静态“电源良好”电平直接驱动升压 EN。按配置和手册验证实际合同及其变化；默认关断，在明确确认足够合同前禁止母线供电。[1]

不采用 TPS55288 作为本方案的直接 24V 输出器件：其标称输出调节范围上限为 21.26V，不能把“36V 输入”误认为“36V 输出”。[6]

## 4. 功率、启动和保护目标

以端到端效率 90% 作为预算假设：24W 母线输出约需 26.7W 输入，20V 侧约 1.33A，入口电路总损耗约 2.7W；36W 输出目标约需 40W 输入，20V 侧约 2A，总损耗约 4W。上述均为预算计算，不是实测效率和发热。60W 合同给输入留有余量，但额定输出仍取决于角落板布局、热设计与验证，不能把 60W 全部当作输出功率。

连续输出 1.5A 是目标；eFuse 限流阈值必须高于所需正常电流下限，并在器差最坏情况下仍低于 PD 输入预算及功率器件能力。不能直接把标称限流设为 1.5A 后保证全部样品可持续输出 1.5A。低输入电压、线缆损耗和 DC/DC 效率最差点都要计入。24W 预计负载对应 1A；本轮不把连接器、铜皮的可承载电流认定为已经验证。

启动顺序：

1. 插线，初始 5V 仅启动 PD 与监督电路；升压和母线开关保持关闭。
2. 协商并核实 20V/3A 合同，检查输入电压窗口、线缆能力和故障状态。
3. 启动升压，使 PD_24V_RAW 达到规定窗口。
4. 输出 eFuse 以受控斜率给整盘电容充电，完成后标记 BUS_READY。
5. 运行时持续监督掉电、PD 重协商、过流、过温和输出异常。合同失效立即取消本入口供电资格，不等待服务器响应。
6. 故障关断本入口；短路采用锁存或有界重试策略，避免整盘循环闪烁启动。

升压 EN 关闭可能仍有输入到输出的直通路径，必须有独立输出开关。预充电电流满足 I=C×dV/dt；需统计全部模块接入电容及负载提前启动行为，再确定斜率、限流和启动能量，不能任意填一个固定延时。

24V 输出精度目标暂定 ±2%（额定负载下本入口处）。UVLO/OVLO 最终按现有全部负载额定值、误差和瞬态确定。TVS 的钳位电压而非仅标称电压必须落入被保护器件的承受范围；不能拿钳位电压过高的通用 TVS 保护 22V 工作范围的 PD 芯片。

## 5. 四角共享母线

每一角都有自己的 PD、转换、输出开关和理想二极管支路，最后才并入 24V_BUS。不能在保护之前短接四角原始 VBUS 或升压输出。

第二个适配器插入时，独立协商并建立自己的 24V；理想二极管阻止高电压一路向低电压一路充电。哪一路供电取决于输出电压与线路压降，可能存在不均匀分担，不视为额定均流。所有入口都须验证母线已被外部供电时的启动、停机与拔线过程。

如果需要多适配器叠加功率，后续独立设计均流或电源分区。若要求严格“只有一路供电”，则增加供电仲裁与开关控制；本版不能把普通二极管 ORing 描述为优先选择器。

单个角落给整盘供电时，应核算实际闭环/开链拓扑、每段铜皮/连接器的累计电流。本版为 24 格、约 1A 预计母线负载，先验证单点供电，无需预先增加多个适配器。最远端压降与接点温升仍要测量；若不合格，可从同一适配器的受保护 24V 输出经独立线束向远端注入。这与多个独立适配器并联是不同问题。

## 6. 机械与布局规划

新 USB-C 放在不占用左侧/上侧串联接口的可操作外侧边缘，具体落位需结合角落 PCB 和外壳检查。80×80mm 板框、J4、LED 和安装孔作为现有约束；在未完成摆件和热评估前，不保证所有新增器件都能原位容纳。

优先把 PD 和大功率转换电路做成可重复验证的功能区。先用电源样板验证，再集成四块角落板；若空间或散热不够，使用有机械固定的电源子板，不通过挤压天线净空来容纳。

USB-C 壳体支撑、ESD 回流靠近入口；CC 远离 SW 节点。MOSFET、输入/输出旁路、电感和采样构成紧凑功率回路，采样与反馈采用 Kelvin 接法。功率线接宽铜皮和充分的层间连接，不经过细颈和单个信号级过孔。地平面保持连续，控制噪声回流，不能随意割地。

升压电感及 SW 区域远离 ESP32 天线、RFID 模拟链路、线圈接口、晶振及 J4。开关频率和谐波需要结合 125kHz RFID、4MHz 时钟实测干扰，不仅靠目视距离判断。

新增测试点：PD_VBUS_RAW、PD_20V_IN、PD_24V_RAW、24V_BUS、GND，以及合同合格、BUS_READY、FAULT 状态；测试点用于测量，不作为大电流夹线入口。

## 7. 落地顺序与验收

1. 测量单格满亮 LED、屏幕、RFID 工作/启动功耗，统计整盘最坏同时负载、额外总线负载、接入电容；现有 INA226 的本地 5V 数据不是整条母线功率。
2. 确认 24 格是否在 36W 输出预算内；本版不需要 EPR。若未来模块数量或负载明显增加，再重新评估功率等级。EPR 28V 输入需要换为 EPR 控制器与线材，不能让 TPS25730D 接收 28V。[7]
3. 将候选落实成完整 BOM，逐项验证商城/EDA 实际库存 ≥100、封装、额定值、可采购性，再完成原理图、计算和补偿仿真。
4. 样板验证 20V/3A 合同、正反插、非 PD/低功率充电器、合格 3A 线、PD 重协商、启动、负载阶跃、短路、预偏置、两个入口同时带电和拔线。
5. 电子负载验证 24V/1.5A 连续运行、效率、纹波、最热元件与外壳温升；再接 2–3 个格子，最后接满 24 格核对远端电压、连接器温升、RFID 与无线稳定性。
6. 验收通过后定输出额定值并集成角落 PCB，完成 DRC 与装配复核。本规划本身不代表上述检查已经通过。
