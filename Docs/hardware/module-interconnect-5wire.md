型号及机械位置见[两种 PCB](pcb-variants.md)。上游 JOUT 对下游 JIN，实物须逐脚测通并检查面向、Pin1 与镜像；旧 JIN1.1/JOUT1.3 的 ORDER 映射已废止。

长边公母在相对边，角落公母在相邻边；从公针边俯视顺时针转90°为母座边。用户已自然插合确认本批PCB同面共面；插入行程、精确板间距及固定后的装配受力仍需首件确认，不能只比较商品塑高。长边JOUT3相对JOUT1的0.127mm偏差位于插入轴方向，不是高度台阶。

## 电源与数据分开判断

24V_BUS/GND 在板间贯通，每块板通过自己的 U24/U201/U23 并联取电，不是把 32 个负载电气串联。保护路径见[硬件基线](hardware-baseline.md)。一个角落 J301 接入外部稳压24V，经F301/D301进入母线；总线60W设计目标及约1W本地负载边界见[直接24V供电复核](power-schematic-audit-2026-09-21.md)。每侧现在只有三个正极、三个地触点，载流和每段 ≤40mΩ 必须用实际连接器与铜验证。

**电源、ORDER与RS485分别验收。** 当前服务端支持目录16/24/32/40格ORDER完整有向环：全部在线格子必须恰好组成一个有效环，节点数等于当前地图，实际角落类型与位置匹配后，才沿OUT→IN自动分配；默认稳定moduleId最小的角落为START。16格对应12 long＋4 corner、四角0/4/8/12；32格的28 long＋4 corner、四角0/8/16/24仍是另一受支持规模。额外孤岛、第二个环、分叉、重复身份、未知角色或错误地图数量不能忽略。物理波形仍V1；软件实现、回归和服务部署完成，完整实体环另验。RS485 A/B仍未启用，不因此获准闭环。详见[全在线闭环报告](../firmware/server-all-online-ring-progress-2026-10-15.md)及[跨端契约](../firmware/ring-onboarding-contract-2026-09-26.md)。

## 当前 ORDER 实现

GPIO9 经 R16/上拉/电容接收，GPIO10 驱动 Q1。GPIO10 低释放、高拉低下游。每板独立每 6 秒发 bootId/seq/CRC 信标，1ms 状态机采样，调度空隙超过 6ms 放弃帧，持续低 150ms 撤销邻居，新完整帧 15 秒过期；重复序号不续命。

模块通过 HTTP 心跳上报自己的真实上游，服务器按物理证据构图。人工指定任一格为锚点后，前后模块按地图索引派生；新的人工锚点重启该段基准，人工分配优先。无效拓扑/冲突暂停派生，不按 Wi-Fi 注册顺序猜线序。离线锚点意图目前保存在内存，换房间/服务器重启清除。

完整 wire 和字段以 [ORDER V1](../firmware/tile-order-protocol.md)、[分配契约](../firmware/tile-module-debug-assignment.md)为准。旧 ENUM_NEXT/PASS_TOKEN + RS485 令牌方案是历史提案，不是当前 V0.34 运行路径。

历史双板邻接与锚点前后派生已有验证，10/15分批四板开放链也有实机证据；目录16/24/32/40环已实现，但不能将软件支持、16板分批联网或四屏在线扩展为完整实体环已通过。正常24V下的16环、断环/重接与RFID仍待验；其余尺寸实体另验。详见[16格试玩记录](../firmware/trial16-release-2026-10-15.md)。

## RS485 预留硬件

SN65HVD75DR：TX GPIO43、RX GPIO44、DE 与 /RE GPIO14；默认低接收。R15 120Ω 默认 DNP，D4 SM712 靠近连接器。当前 Tile V0.34 数据经 Wi-Fi/HTTP，RS485 未启用，不能用已有 A/B 走线证明协议已部署。

2026-09-21实读确认两板R15均DNP。旧“末端同时断开ORDER/A/B”转接件未实施，ORDER部分已被现行ORDER环方案替代；A/B未来启用仍须线型断点与两个终端。当前RS485禁用，不能把闭合A/B视作通信通过。四种连接组合36针的二维方向/针序核对通过；长边JOUT3有0.127mm插入轴偏差。用户已确认自然插合共面，精确插入行程、固定后的闭环公差和受力仍待验证，见[接口审查](interconnect-audit-2026-09-21.md)。

未来启用前须冻结线型拓扑与两个物理端点、终端及偏置、电缆/支线长度、速率和时序；电源环不能直接当可用 RS485 环。先小规模验证再提高速率，不把 5Mbps 当既定能力。

## 当前固定底板与接缝边界

[R2首件](../../Mechanical/BoardBase/README.md)固定一角落和相邻两长边，为151×151mm连续L形底板；每板两颗对角螺丝，孔周接触环Ø6/Ø3.6，PCB底面离桌16mm。用户提供近似板厚1.6mm、底面突出8.1mm；平板厚3.5mm时名义净空4.4mm。3.0×10mm塑料专用螺钉与候选Ø2.5mm盲孔需先用2.4/2.5/2.6mm试孔片验证，尚未实际切片/打印/试拧。

用户约12mm角落—长边和15mm长边—长边间隙，若量自主体直边，扣除长边每侧3mm凸出后才得到候选g=9mm。测量边界未确认，不能把该值视为已测精密间距；自然插好后三板必须自由落入固定孔柱，不靠螺丝拉扯接口。冻结[机械接口包](../../Mechanical/BoardBase/interfaces/pcb-interface-2026-10-15/mechanical-interface.json)保持原样，其中旧14mm架高/可调滑移建议已由当前R2固定整体底板覆盖。

## PCB 与装配检查

- 正负母线分别宽铜汇流；保护支路之外仍须校核总线短路与累积电流。
- A/B 成对、连续参考地、短支线；ORDER 避开 SW、RFID 和 LED 噪声。
- 保证先后接触和误插不会把 24V 加到 A/B/ORDER；现有普通排针不能默认具有先接地特性。
- PCB 上明确 IN/OUT、Pin1、正负与板型；不移动 J4/LED 来掩盖机械不兼容。
- 电源受控充电、软件邻接恢复和游戏状态恢复分别验收；保护动作可能使故障模块重启，不能承诺任意插拔无扰动。
