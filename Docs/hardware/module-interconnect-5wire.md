# Gridopoly 模块互连方案

更新日期：2026-07-31

当前方案包含 5 个电气网络，但每侧使用 15 个物理触点。24V 和 GND 分别使用
6 个并联触点，RS485 A/B 与 ORDER 各使用 1 个触点。

## 1. 设计目标

1. 格子模块可以按游戏地图随机改变排列顺序。
2. 模块连接成物理链路后，树莓派能够识别实际排列顺序。
3. RS485 负责数据，ORDER 负责物理顺序，二者互不替代。
4. 采用 24V 分布、本模块本地降压，降低长链路电流和压降。
5. 40 模块版本仍需分段注入电源，不能让首块模块承担全部累计电流。

## 2. 电气网络与物理触点

| 电气网络 | 每侧触点数 | 方向 | 用途 |
| --- | ---: | --- | --- |
| `24V_BUS` | 6 | 输入/直通 | 模块电源母线 |
| `GND` | 6 | 输入/直通 | 公共地和电源回路 |
| `BUS_A` | 1 | 双向 | RS485 A |
| `BUS_B` | 1 | 双向 | RS485 B |
| `ORDER` | 1 | 逐级单向 | 自动枚举物理顺序 |

物理上每侧由 5 个 3Pin 磁吸连接器组成。

## 3. 连接器

输入侧：

- JIN1～JIN5：`YZ10515055F-03025-01`
- LCSC：`C54799715`

输出侧：

- JOUT1～JOUT5：`YZ126715035T-03025-01`
- LCSC：`C54799683`

### 3.1 输入侧针序

| 连接器 | Pin 1 | Pin 2 | Pin 3 |
| --- | --- | --- | --- |
| JIN1 | `ORDER_IN` | `BUS_A` | `BUS_B` |
| JIN2 | `24V_BUS` | `24V_BUS` | `24V_BUS` |
| JIN3 | `GND` | `GND` | `GND` |
| JIN4 | `24V_BUS` | `24V_BUS` | `24V_BUS` |
| JIN5 | `GND` | `GND` | `GND` |

### 3.2 输出侧针序

| 连接器 | Pin 1 | Pin 2 | Pin 3 |
| --- | --- | --- | --- |
| JOUT1 | `BUS_B` | `BUS_A` | `ORDER_OUT` |
| JOUT2 | `24V_BUS` | `24V_BUS` | `24V_BUS` |
| JOUT3 | `GND` | `GND` | `GND` |
| JOUT4 | `24V_BUS` | `24V_BUS` | `24V_BUS` |
| JOUT5 | `GND` | `GND` | `GND` |

JOUT1 的数字针序是 JIN1 的镜像。面对面插合后的逻辑对应关系为：

```text
JIN1.1 ORDER_IN <-> JOUT1.3 ORDER_OUT
JIN1.2 BUS_A    <-> JOUT1.2 BUS_A
JIN1.3 BUS_B    <-> JOUT1.1 BUS_B
```

机械结构必须保证 IN 只能连接上一模块的 OUT，不能 180° 反接。

## 4. 本模块供电支路

```text
24V_BUS
   |
  U24 2920L150/60GR
   |
24V_BUCK_IN
   |
  U23 LMR16030PDDAR
   |
  L2 8.2uH
   |
5V_FROM_24
   |
  U8 2016L300/16MR
   |
5V_FROM_24_FUSED -> TPS2121 IN1
```

USB VBUS 经 U7 进入 TPS2121 IN2，作为本模块备用或调试电源。两路电源不能在
TPS2121 之前直接并联。

U24 只保护本模块降压支路。`24V_BUS` 在 JIN2/JIN4 与 JOUT2/JOUT4 之间
直通，因此单个模块的 U24 动作不会切断下游母线。

24V 保护器件 D6 为 `SMBJ30A`：

```text
D6 Pin 1 -> 24V_BUCK_IN
D6 Pin 2 -> GND
```

## 5. ORDER 硬件

输入：

```text
ORDER_IN -> R16 1kΩ -> GPIO9 / ESP_ORDER_IN
                          |
                          +-> R17 10kΩ -> 3V3_SYS
                          +-> C24 100nF -> GND
```

输出：

```text
GPIO10 / ESP_ORDER_OUT -> R18 1kΩ -> Q1 Gate
                                      |
                                      +-> R19 100kΩ -> GND

Q1 Source -> GND
Q1 Drain  -> ORDER_OUT
```

Q1 为 2N7002 开漏输出。下一级提供上拉，避免相邻模块 3.3V 电源直接并联。

## 6. 自动枚举流程

1. 树莓派初始化 RS485 总线。
2. 所有模块进入未分配状态，ORDER 输出保持释放。
3. 链路起点产生第一个 ORDER 令牌。
4. 树莓派广播 `ENUM_NEXT`。
5. 只有检测到令牌的未分配模块允许回应。
6. 模块上报 ESP32-S3 MAC 地址或烧录的唯一 ID。
7. 树莓派分配运行地址和 `order_index`。
8. 树莓派发送 `PASS_TOKEN`。
9. 当前模块驱动 `ORDER_OUT`，令牌进入下一模块。
10. 超时没有新模块回应时枚举结束。

## 7. RS485

| 信号 | ESP32-S3 |
| --- | --- |
| TX | GPIO43 |
| RX | GPIO44 |
| DE 与 /RE | GPIO14 |

当前收发器为 `SN65HVD75DR`：

- A -> `BUS_A`
- B -> `BUS_B`
- 3.3V 供电
- R14 10kΩ使上电默认接收
- R15 120Ω终端电阻默认 DNP
- D4 SM712 提供总线瞬态保护

终端电阻只在线路两个物理端点安装，中间模块不能全部装 120Ω。

## 8. 协议建议

当前固件实现应使用[固件开发指南](../firmware/firmware-development-guide.md)中定义的
RS485 协议 V0。
下面的命令名称是功能摘要，不代表可以省略帧头、地址、序号、长度和 CRC。

```text
MAGIC | CMD | SEQ | TARGET | LENGTH | PAYLOAD | CRC16
```

| 命令 | 用途 |
| --- | --- |
| `ENUM_NEXT` | 请求当前令牌模块认领顺序 |
| `CLAIM` | 模块上报唯一 ID |
| `ASSIGN_ADDR` | 分配通信地址和顺序号 |
| `PASS_TOKEN` | 传递 ORDER 令牌 |
| `ENUM_DONE` | 枚举结束 |
| `PING` | 在线检测 |
| `SET_LED` | 设置 LED 状态 |
| `SET_IMAGE` | 发送图片或图片索引 |
| `RFID_EVENT` | 上报标签 ID 和模块地址 |

帧应带 CRC16。枚举、地址分配和图像传输命令应带 ACK、超时和重试。

## 9. 数据速率

| 阶段 | 推荐速率 |
| --- | ---: |
| 初版调试 | 115200bps |
| V1.0 原型 | 921600bps |
| 优化版本 | 2Mbps |
| 压力测试 | 5Mbps |

5Mbps 需要短总线、正确终端、低支线电容和示波器验证，不作为第一版硬指标。

默认固件从 115200bps 启动，完成 2～3 模块验证后使用 921600bps。波特率变更
必须由主控广播并在确认后统一切换，不能让单个模块自行改变速率。

## 10. 40 模块供电边界

6 个 24V 触点并联只能降低单个连接面的接触电阻，不能消除链式供电的累计电流。
并联触点受机械压力、污染和接触电阻差异影响，电流不会理想均分。

正式版本至少采用一种措施：

1. 每若干模块设置一个 24V 供电注入点。
2. 使用底板、铜排或独立线束并联供电。
3. 将棋盘分成多个带独立保险丝的电源分区。
4. 主电源具备软启动、过流、短路、过压和温度保护。
5. 在最远端测量 24V 压降，不只测电源输出端。

不要使用“单触点额定值 × 6”作为长期连续载流能力。

## 11. PCB 要求

1. 6 个 24V 触点使用宽铜皮汇流，6 个 GND 触点使用完整地平面/宽铜汇流。
2. `BUS_A/B` 成对走线，保持连续参考地，避免长支线。
3. D4 靠近信号触点，TVS 泄放回路短接地。
4. ORDER 远离 `BUCK24_SW`、RFID 天线和 LED 数据。
5. U24、D6 和 U23 输入电容靠近 24V 取电点。
6. 连接器的 Pin 1、IN/OUT、正反面和镜像关系必须在丝印中明确。

## 12. V1.0 验证

1. 先连接 2～3 个模块。
2. 验证 24V 直通和每模块本地 5V/3.3V。
3. 验证 RS485 广播、地址分配和双向通信。
4. 验证 ORDER 按物理连接顺序逐级传递。
5. 每模块显示不同顺序号或点亮不同颜色。
6. 放置 125kHz 标签并上报 `RFID_EVENT`。
7. 逐步增加模块数量并记录母线压降、触点温升和总线波形。
