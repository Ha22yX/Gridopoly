## 电源与数据分开判断

24V_BUS/GND 在板间贯通，每块板通过自己的 U24/U201/U23 并联取电，不是把 32 个负载电气串联。保护路径见[硬件基线](hardware-baseline.md)。一个角落 J301 接入外部稳压24V，经F301/D301进入母线；总线60W设计目标及约1W本地负载边界见[直接24V供电复核](power-schematic-audit-2026-09-21.md)。每侧现在只有三个正极、三个地触点，载流和每段 ≤40mΩ 必须用实际连接器与铜验证。

**电源、ORDER与RS485分别验收。** 当前服务端支持目录16/24/32/40格ORDER完整有向环：全部在线格子必须恰好组成一个有效环，节点数等于当前地图，实际角落类型与位置匹配后，才沿OUT→IN自动分配；默认稳定moduleId最小的角落为START。16格对应12 long＋4 corner、四角0/4/8/12；32格的28 long＋4 corner、四角0/8/16/24仍是另一受支持规模。额外孤岛、第二个环、分叉、重复身份、未知角色或错误地图数量不能忽略。物理波形仍V1；16实体环及自动分配已在USB热点现场通过，24/32/40仅为另行受支持规模，不能扩大为其实体验收。RS485 A/B仍未启用，不因此获准闭环。详见[全在线闭环报告](../firmware/server-all-online-ring-progress-2026-10-15.md)及[跨端契约](../firmware/ring-onboarding-contract-2026-09-26.md)。

## 当前 ORDER 实现

GPIO9 经 R16/上拉/电容接收，GPIO10 驱动 Q1。GPIO10 低释放、高拉低下游。每板独立每 6 秒发 bootId/seq/CRC 信标，1ms 状态机采样，调度空隙超过 6ms 放弃帧，持续低 150ms 撤销邻居，新完整帧 15 秒过期；重复序号不续命。

模块通过 HTTP 心跳上报自己的真实上游，服务器按物理证据构图。人工指定任一格为锚点后，前后模块按地图索引派生；新的人工锚点重启该段基准，人工分配优先。无效拓扑/冲突暂停派生，不按 Wi-Fi 注册顺序猜线序。离线锚点意图目前保存在内存，换房间/服务器重启清除。

完整 wire 和字段以 [ORDER V1](../firmware/tile-order-protocol.md)、[分配契约](../firmware/tile-module-debug-assignment.md)为准。旧 ENUM_NEXT/PASS_TOKEN + RS485 令牌方案是历史提案，不是当前 V0.34 运行路径。

历史双板邻接、锚点前后派生和10/15分批四板开放链证据保留。最新22:06 UTC后现场记录已确认全部16计划模块恰好构成一个ready环，全部source=order、0～15唯一映射、四角0/4/8/12；16个reader stable，结合用户线圈抬高后的16板识别反馈，关闭本轮“16环/基础读卡未验”的旧状态。22:29～22:34 UTC用户重开局的后续复测映射正常，但最初等待格子症状根因未定，不称已修复。人工锚点改派、实体断环/重接、完整配对/到达与一局、其他规模仍分别待验。见[USB现场验收](../firmware/usb-ap-deployment-2026-10-15.md)、[重开局观察](../firmware/newgame16-assignment-observation-2026-10-15.md)及[RFID装配记录](../firmware/tile-rfid-screen-coupling-2026-10-15.md)。

## RS485 预留硬件

SN65HVD75DR：TX GPIO43、RX GPIO44、DE 与 /RE GPIO14；默认低接收。R15 120Ω 默认 DNP，D4 SM712 靠近连接器。当前 Tile V0.34 数据经 Wi-Fi/HTTP，RS485 未启用，不能用已有 A/B 走线证明协议已部署。

2026-09-21实读确认两板R15均DNP。旧“末端同时断开ORDER/A/B”转接件未实施，ORDER部分已被现行ORDER环方案替代；A/B未来启用仍须线型断点与两个终端。当前RS485禁用，不能把闭合A/B视作通信通过。四种连接组合36针的二维方向/针序核对通过；长边JOUT3有0.127mm插入轴偏差。用户已确认自然插合共面，精确插入行程、固定后的闭环公差和受力仍待验证，见[接口审查](interconnect-audit-2026-09-21.md)。

未来启用前须冻结线型拓扑与两个物理端点、终端及偏置、电缆/支线长度、速率和时序；电源环不能直接当可用 RS485 环。先小规模验证再提高速率，不把 5Mbps 当既定能力。

## 当前固定底板与接缝边界

当前[Full16 R1](../../Mechanical/BoardBase/Full16_R1/README.md)以四个相同L主件组成完整固定底板，每件一角三长，四处拼缝各用内外两片连接片，共八片。主框366×366mm、含耳最大406×406mm；每板两颗对角螺丝，接触环Ø6/Ø3.6，PCB底面离桌16mm、平板厚3.5mm。按用户近似板厚1.6mm、底面突出8.1mm，名义底部净空4.4mm。3.0×10mm塑料专用盘头螺钉配候选Ø2.5mm盲孔及1mm垫片；若换螺钉牙型或打印材料，先用原R2试孔片核对。

原[三模块R2](../../Mechanical/BoardBase/README.md)已由用户照片及反馈确认配合正常；Full16数字布局、网格/3MF及参考板干涉检查通过，新增长—长接缝、完整切片打印和拼接承载仍待实装。当前模型主体直边间距为角—长12mm、长—长15mm；扣除长边每侧3mm凸出后的g=9mm仍是接口推算，不能当成精密实测。先打印一个L确认四板自然落柱，再拼整盘；不用螺丝拉扯接口，也不让板间连接器承担底板结构连接力。冻结[机械接口包](../../Mechanical/BoardBase/interfaces/pcb-interface-2026-10-15/mechanical-interface.json)及旧14mm/滑移记录保持原样，现行装配说明以Full16为准。

## PCB 与装配检查

- 正负母线分别宽铜汇流；保护支路之外仍须校核总线短路与累积电流。
- A/B 成对、连续参考地、短支线；ORDER 避开 SW、RFID 和 LED 噪声。
- 保证先后接触和误插不会把 24V 加到 A/B/ORDER；现有普通排针不能默认具有先接地特性。
- PCB 上明确 IN/OUT、Pin1、正负与板型；不移动 J4/LED 来掩盖机械不兼容。
- 电源受控充电、软件邻接恢复和游戏状态恢复分别验收；保护动作可能使故障模块重启，不能承诺任意插拔无扰动。
