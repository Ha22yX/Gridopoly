## 已了解的接口

- 格子模块文档基线：ESP32-S3-WROOM-1-N16R8；24V 母线经本地降压形成 5V，与 USB 5V 经 TPS2121 选择；INA226 测本模块分流电阻后的负载，TPS62160 产生 3.3V。
- 格子屏为 240×320 ST7789，另有 HTRC110 RFID、10 颗 WS2812 和 RS485 硬件。GPIO 表以[引脚文档](esp32-s3-pin-map.md)及 `Firmware/TileModule/include/board_config.h`交叉核对。
- ORDER 使用 GPIO9 输入、GPIO10 驱动 2N7002 栅极；GPIO10 高表示下游线路被拉低，低表示释放。当前 V1 为独立物理信标加 HTTP 上报，见 [ORDER 协议](../firmware/tile-order-protocol.md)。
- 玩家屏是独立的 Viewe `UEDX48480021-MD80ET` 2.1 英寸 480×480 模组，不能套用格子板的引脚表。
