# 直接24V统一供电验证与制造放行

更新：2026-10-15。状态：**16板功能联调已有实物证据，量化电气验收与制造放行仍未完成**。本轮仅整合既有记录，未执行新测试。只覆盖角落PCB2_5、长边PCB2_1；独立玩家USB-C电池板另见[玩家底板](player-usbc-battery-base-2026-09-27.md)。9/21曾只审核新增供电原理图，该历史范围不能代替当前整板及整盘验收要求；PCB、屏幕、线圈、机械和实际供电仍须按各自证据判断。

当前16板（12长边＋4角落）均已完成V0.34写验，用户已接入24V供电。线圈略抬高于LCD后，用户确认16板均可识别Tag；服务端随后记录16个reader全部stable。ALFA USB热点已取得16格＋4屏共20台同时关联/注册证据；唯一16节点ORDER环ready、0～15自动分配及四角0/4/8/12通过，Pi软件重启后自动启动并恢复原房间。重启后按用户实际开启的16格＋3屏连续观察121.18秒；20台记录不等于36台容量或长期稳定性保证。来源：[USB部署与启动验收](../firmware/usb-ap-deployment-2026-10-15.md)、[线圈装配反馈](../firmware/tile-rfid-screen-coupling-2026-10-15.md)、[试玩记录](../firmware/trial16-release-2026-10-15.md)。

13板灯效已有用户确认，COM16/17/18仍待单独目视；原故障COM19继续隔离。以上功能结果不关闭下方量化电压、纹波、温升、启动浪涌、插拔与保护验收，也不代表最终结构的完整射频验收或实体整局通过。Pi软件重启与完全断电、家庭网络不可用的冷上电分别验收。

## 当前证据与能力边界

9/21[新增供电原理图复核](power-schematic-audit-2026-09-21.md)核对角落35件/97引脚、长边29件/84引脚，181项断言及公共参数检查通过，未发现U201 TPS26621、U23 LMR16030SDDAR控制、反馈、软启动和供电方向的确定错误。此为该次静态检查范围，不是整板器件数量或实测结果。10/15机械只读复核为当前长边141件/底面48件、角落152件/底面46件，相关机械/布局图元与9/21归档一致；实物批次制造哈希仍待绑定。

旧USB-PD/LM5176/R120的4448工况相位裕量与48工况小信号计算仅属于已取消方案，**不能作为当前直流入口的稳定性证据**。当前U201欠压启动标称19.16V、过压关断28.16V、限流约152mA；受控充电与U23软启动均为约半秒的典型估算，不能当生产上下限。

建议24V/5A稳压适配器，5.5×2.1mm中心正极、单点注入。60W是整盘母线取电目标，约1W是每板预算，120W电源铭牌不提高板端额定值；16块板也不能强行均摊满60W。D301串联压降会使24V_BUS低于电源输出；按0.7V、约2.6A估算有约1.8W发热，尚待PCB散热与实测。

## 必须冻结的条件

记录两板PCB revision、同版BOM/Gerber/坐标、固件Git/app SHA、适配器型号与实测输出、插头极性/尺寸、线缆、模块数、ORDER环/开链连接方式、A/B线型断点及端点终端、每段正负回路电阻、环境温度、仪器带宽和测点。没有PD NVM或20V5A协商验收项。

板层使用用户指定1.6mm六层、外层1oz；内层铜和介质以板厂最终叠层为准。40mΩ/段仅是曾用压降模型假设，必须由实际触点、铜及电流分配验证或重算，不能直接签为板厂指标。

用户已确认自然插合的PCB同面共面、实测板厚约1.6mm和最大底面突出约8.1mm。[三模块首件R2](../../Mechanical/BoardBase/README.md)已获用户打印件配合正常的反馈；整盘现采用[Full16 R1](../../Mechanical/BoardBase/Full16_R1/README.md)四个相同L主件＋八片连接片，保持16mm板底高度。三模块反馈不覆盖新增长边—长边接缝、全环闭合、螺纹抗拔及拼接承载；这些仍须实装验收。旧14mm/滑移提案不作为现行安装要求。

- 使用当前最终BOM；旧PD的USB1、J101、STUSB4500、LM5176、C128、R120等不再采购。角落新入口为J301/F301/D301/D302/C301/C302。
- R26/R30 C165751库存0为9/21用户截图，当时替代料未入设计；本次未查库存，不把历史记录当实时缺料。下单重查规格与贴片库存，原13张匹配提示见[BOM核查](bom-review-2026-09-21.md)。
- 屏幕、RFID线圈未包含在9/21新增供电原理图审核范围。10/15抬高线圈后的用户识别反馈与16个reader stable是新增功能证据；最终壳体下的谐振/损耗、读距、边缘/多Tag/相邻线圈及完整显示仍须分别验收，不将基础识别等同全部射频项目通过。
- 每项保存原始测量和失败，不只写通过。PCB、电源样机、机械与整盘实测均完成后，才可发布稳定运行的产品能力。
