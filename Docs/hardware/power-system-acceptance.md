# 统一供电验证与制造放行清单

更新：2026-09-21。状态：验收计划；除明确引用的理论结果外，下表均未实测签核。覆盖单个角落、16/24/32/40 模块，源出口 0–60W，真实每模块约 1W。

## 已有理论证据

[电源理论记录](unified-power-theory-review-2026-09-21.md)及其 Python/JSON 包含 4448 个近似环路工况：最低相位裕量约 52.8°、增益裕量约 14.4dB；48 个简化网络小信号工况未见右半平面极点。不是官方开关 SPICE，也没有全器差、布局寄生及连接器弹跳实测。

R120 已由 6.8k 改 5.6k。主软启动、支路 dV/dt、5V SS 的时序估算支持分阶段启动，但 SS 电流部分只有典型值；不能当作量产最短/最长时间保证。

40 板、60W 末端净负载是超出正常“出口 60W”定义的压力比较：假设每段回路 40mΩ、源23.89V，闭环最远约23.38V/线损0.87W；开链最远约21.77V/线损3.75W。75mΩ 开链最远约19.56V，低于最高估算欠压重启门限20.05V。数值依赖模型，不能据此跳过触点实测。

## 必须冻结的测试条件

记录 PCB revision/制造包、两板 BOM、固件 Git/app SHA、PD NVM 镜像、源型号/单口合同、5A 线、模块数、拓扑与 ORDER 断点、每段线/触点电阻、温度、探头位置/带宽、负载与脚本版本。采购库存是查询时快照，测前/下单前重查。

正常能力按源出口60W，72W仅工程应力点；不在未完成热设计和保护验证时把它作为常规使用规格。默认单个角落注入，多个 PD 电源同时接入另做资格审查与测试。

## 验收矩阵

| 阶段 | 测量/操作 | 放行条件 |
| --- | --- | --- |
| 无电核对 | 两板网表/PCB/BOM、Pin1、极性、USB1焊尾、HP_RTN/EP、反馈和 Kelvin | 无误连，保护前后储能正确；接口逐针验证 |
| 单板低压调试 | 经 J1 启动与维护，检查5V/3.3V/I²C | 电压在各负载器件范围，无超 J1 预算；不假称已验证 PD |
| PD 首次配置 | 写 NVM、读回、重载、拔掉J1 | 配置有记录；仅USB1可重复协商20V5A并正常升压 |
| 错误电源 | 不提供20V5A、换线、拔插源 | 门控正确；不能让低合同被当作60W电源；无器件超额定 |
| 轻载/空外载 | 单角落、0外接负载、反复上电 | 无异常抖动、持续重试或过压；测自身损耗 |
| 逐级负载 | 1→16→24→32→40 板及源出口分级至60W | 记录源/最远端24V、各板5V/3.3V、纹波、输入合同、电流、效率及温升 |
| 同时启动 | 所有板完全放电后插USB1，冷/热态复测 | 不进入持续打嗝循环；最远端足够跨过最坏UVLO，5V/3.3V正常启动 |
| 负载阶跃 | 单板局部增减负载、源侧/远端最坏变化 | 无持续振荡；过冲低于器件工作上限，跌落不越过需要连续运行板的欠压/复位边界 |
| 模块插拔 | 近源/远端、断环/复接、真实排针接触与弹跳 | 受控充电生效，无误短接/反灌；记录相邻板是否复位，不预先承诺无扰动 |
| 故障支路 | 本板输出短路、过载及恢复 | 局部保护按设计动作；健康支路行为可解释、温升安全；不把PTC当快速浪涌器 |
| 热/压降 | 满负载热稳定后测每段含正负回路 | 符合≤40mΩ模型条件，否则重算并改设计；电感/MOS/连接器均满足降额 |
| 真实环路 | 合适方法测补偿裕量、纹波及瞬态 | 与理论假设一致或修正模型后仍有可接受裕量；线性外推图不可替代 |
| 联动恢复 | 断电/插回后ORDER、HTTP、RFID、移动gate | 正确恢复模块身份/分配；不重复到达/结算；闭环策略先实现再验 |

电压瞬态上限须由实际最低耐压器件及工作范围制定，不能把 SMBJ30A 的“30V”当实际钳位值。主储能电容在防反灌器件前，不能假设吸收所有母线侧回灌能量。

## 制造与采购放行

- 两种 PCB 分别零未布线/短路，核对原理图更改、层叠、阻抗、热铜、过孔、装配与结构干涉。
- 新增 8 件的本体面积不是所需布局面积；长边必须实际放下并完成走线后签核。
- BOM 以同次导出为准：旧 J101/R108/R109 不再采购，新增 C128，R120=5.6k，U23=S 型。
- 已知旧电路 R26/R30 的 C165751 在此前检查时库存0；C22912仅为23.7k候选，尚未实际替换。采购前重新确认型号、封装、精度、功率与库存。
- 每项保存原始波形/测量表和失败结果，不只写 PASS。原理图属性警告可按用户选择保留，但封装、耐压、网络和器件真伪不随之免检。

只有 PCB、配置固件和以上实际供电验收完成，才可把统一电源从“有条件理论可行”改为已验证产品规格。
