# 直接24V统一供电验证与制造放行

更新：2026-09-22。状态：验收计划，以下未打勾项目不代表实测通过。覆盖角落PCB2_5、长边PCB2_1；用户最近的审查仅限新增供电原理图，不包含PCB、屏幕或线圈。本文保留后续产品验收要求，不冒称本轮执行。

## 当前证据与能力边界

[新增供电原理图复核](power-schematic-audit-2026-09-21.md)核对角落35件/97引脚、长边29件/84引脚，181项断言及公共参数检查通过。两板U201 TPS26621、U23 LMR16030SDDAR的控制、反馈、软启动和供电方向没有发现确定错误。

旧USB-PD/LM5176/R120的4448工况相位裕量与48工况小信号计算仅属于已取消方案，**不能作为当前直流入口的稳定性证据**。当前U201欠压启动标称19.16V、过压关断28.16V、限流约152mA；受控充电与U23软启动均为约半秒的典型估算，不能当生产上下限。

建议24V/5A稳压适配器，5.5×2.1mm中心正极、单点注入。60W是整盘母线取电目标，约1W是每板预算，120W电源铭牌不提高板端额定值；16块板也不能强行均摊满60W。D301串联压降会使24V_BUS低于电源输出；按0.7V、约2.6A估算有约1.8W发热，尚待PCB散热与实测。

## 必须冻结的条件

记录两板PCB revision、同版BOM/Gerber/坐标、固件Git/app SHA、适配器型号与实测输出、插头极性/尺寸、线缆、模块数、ORDER及A/B断点、端点终端、每段正负回路电阻、环境温度、仪器带宽和测点。没有PD NVM或20V5A协商验收项。

板层使用用户指定1.6mm六层、外层1oz；内层铜和介质以板厂最终叠层为准。40mΩ/段仅是曾用压降模型假设，必须由实际触点、铜及电流分配验证或重算，不能直接签为板厂指标。

## 验收矩阵

| 阶段 | 操作与留证 | 放行条件 |
| --- | --- | --- |
| 无电核查 | 当前两板网表、BOM、PCB，J301中心/外套/开关脚，F301/D301/D302极性，HP_RTN/EP及Kelvin | 无误接，接口逐针导通正确，原生同步无重复件 |
| PCB制造 | 全板DRC、未布线、板外器件、散热铜、过孔和天线净空 | 同一制造包无未处理的关键违规，不能用历史候选PASS替代 |
| USB维护 | J1单独供电，LED关闭/低背光，检查5V/3.3V | 不超来源电流预算；不依赖不存在的PD配置 |
| 单板24V | 限流实验室电源，观察HP_RAW、HP_RUN、24V_BUCK_IN、5V及3.3V | 先充电再启动，电压满足所有负载工作范围，无打嗝或快速升温 |
| 输入选择 | USB与24V分别供电及切换 | 无反灌、非预期掉电，记录切换波形 |
| 空载/轻载 | 单角落、无其他模块，反复开关 | 无持续重试或超压，记录静态功耗 |
| 逐级扩容 | 2～3块起步，再16/24/32/40块，负载在单板与全盘预算内 | 电源端/最远端电压、各路纹波、温升和功能均满足冻结限值 |
| 同时启动 | 全部放电后接J301，冷/热态和适配器限流模式测试 | 无持续打嗝；最远端跨过最坏UVLO；不把输入预充模型当整个冷启动峰值 |
| 负载阶跃 | 单板与全盘实际最坏灯效/显示/RFID组合 | 无持续振荡；电压过冲/跌落不越过器件和业务连续运行限值 |
| 温升/压降 | 热稳定后测D301、F301、插座、每段触点、转换器 | 额定及降额要求满足；实际回路电阻超假设时重新计算 |
| 插拔/断环 | 近源/远端逐个接入、断开和复接 | 记录接触弹跳、健康节点复位与恢复；不预先承诺任意热插拔零扰动 |
| 故障恢复 | 受控、限流条件下检查短路/过载与恢复 | 局部保护动作可解释，元件不过额定；F301不按精密限流器使用 |
| 拓扑/机械 | 逐针对插、两组中心高度/行程、末端闭合方式与终端 | 消除装配干涉；ORDER/A/B保持合格线型拓扑，不能全部直接闭环 |
| 业务恢复 | 掉电/复接后身份、ORDER、HTTP、Tag与移动gate | 不重复到达/结算；原始日志、失败及固件身份完整 |

D302为SMBJ26A（角落母线入口），D6为SMBJ30A（本地HP_RAW），两者位置和额定不同；型号数字不是精密钳位电压。错误高电压、反接、短路等测试须按冻结的元件能力与限能方法执行，不直接对未验证样机施加无界故障。

## 采购与放行

- 使用当前最终BOM；旧PD的USB1、J101、STUSB4500、LM5176、C128、R120等不再采购。角落新入口为J301/F301/D301/D302/C301/C302。
- R26/R30 C165751在用户截图中库存0，替代料尚未入设计；下单重查规格与贴片库存。13张匹配提示见[BOM核查](bom-review-2026-09-21.md)。
- 屏幕、RFID线圈不在本次用户指定供电审查内；其兼容/实测状态不能因此标PASS。
- 每项保存原始测量和失败，不只写通过。PCB、电源样机、机械与整盘实测均完成后，才可发布稳定运行的产品能力。
