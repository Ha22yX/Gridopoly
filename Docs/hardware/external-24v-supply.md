# 外接24V电源采购与使用边界

更新：2026-09-22。适用于直接24V版角落J301，依据用户已确定的5.5×2.1mm、中心正极规格及[供电复核](power-schematic-audit-2026-09-21.md)。

| 项目 | 要求 |
| --- | --- |
| 输出 | 稳压直流24V，带过流/短路保护；不是恒流LED驱动器 |
| 额定能力 | 建议连续24V/5A，即120W；实际启动/限流表现须测试 |
| DC插头 | 外径5.5mm、内径2.1mm、中心正、外圈负；插入长度按J301厂家配合图核实 |
| 交流侧 | 适合所在地市电、提供对应交流电源线，核对铭牌及认证资料 |
| 实物确认 | 核对具体型号、全新/拆机状态、输出极性、空载电压及负载表现；店铺标题不能代替测量 |

此前24V/3A（72W）是60W母线目标的起步选择；现建议5A等级留启动与输入损耗余量。额定5A是电源可提供的能力，不会强制向负载灌入5A；也不意味着现有PCB、保险丝、串联二极管和连接器能长期承受120W。F301为4A保险丝，不是精密4A限流器；每板U201约0.152A限制本地24V支路。60W是总线取电目标，含本地降压损耗，不是每块角落的本地输出能力。

默认一个角落注入24V，其余J301不再并接适配器。D301具反灌阻断不代表多电源可均流。初次上电先做[首板清单](bring-up-checklist.md)，再做整盘同时启动、最远端压降和温升验证。

## 用户截图中的商品

页面标称惠普24V/5A/120W，选中的是**5.5×2.5mm**版本，另一个选项为6.5×4.3mm带针，均不是已确定的5.5×2.1mm配合规格。极性和实际质量无法从该截图确认，不能直接放行采购。应让卖家提供正确的5.5×2.1mm中心正极版本、实物铭牌、连续输出与成色说明；本次没有购买或更换插座。

2.1mm和2.5mm是不同的中心配合尺寸，见[连接器厂家规格](https://www.sameskydevices.com/panel-mount-dc-power-jacks)。即使偶尔能插入，也不作为可靠配合证据。

给卖家的确认文字：

> 需要DC24V稳压、额定连续输出5A，插头外径5.5mm、内径2.1mm，中心正极、外圈负极，含交流电源线。请确认具体型号、是否全新，并提供实际输出铭牌和插头尺寸。
