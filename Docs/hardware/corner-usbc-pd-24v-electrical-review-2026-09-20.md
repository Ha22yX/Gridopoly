# 角落 PD24 电气复核

2026-09-20。结论：已完成原理图层面复核及可确认问题的框内修正；**不能确认整盘 24 个模块在所有启动条件下正常工作，也不能直接签核打样后的功能或量产可靠性。** 下述计算是设计检查，不是硬件实测或晶体管级仿真。

## 已确认并修正的问题

### 1. 原 USB1 只有 5V 额定值

SHOUHAN `TYPE-C 16PIN 2MD(073)` / C2765186 的厂家承认书第 3 页明确写 DC 5V/3A。不能因为它是 Type-C 外形就认定可用于 20V PD。[原厂家图纸](https://datasheet.lcsc.com/datasheet/pdf/2d53d8d8199c9dd6666d9bc9ac7c3a1e.pdf?productCode=C2765186)

用户明确允许后，在框内换为 JXTCONN `TYPE-C-2MD-16P` / C42418793。商城和器件库均标 20V/3A，查询库存 3765。实际库器件/封装已替换，四个外壳固定脚均接 GND，全部电源触点已接，CC1/CC2 各自对应；未用的数据/SBU 脚标明确不连接。PCB 未修改，后续必须采用新封装核对尺寸。[新器件参数](https://item.szlcsc.com/44427944.html)

### 2. 欠压启动阈值的最坏公差与正常输出重叠

按 TPS55340 反馈基准全温度范围 1.204…1.254V、两个分压电阻各 ±1%，以及输入偏流的保守估计，原 187k/10k 设定的升压输出范围约 **23.27…25.18V**，不能只按标称 24.21V 推断。

原 TPS26600 的 178k/10k 欠压分压，计入比较器阈值与电阻公差后，开启阈值最高约 **23.49V**，高于升压输出最小值。该组合可能不能打开输出。

R115 改为 **169kΩ / C137791**：欠压开启标称 21.30V，初始公差下最高约 22.36V，与升压最低输出之间约有 0.91V 静态余量。

### 3. 原过压阈值距正常输出上界过近

原 210k/10k 过压阈值最低约 25.23V，升压输出最高约 25.18V，余量只有约 **51mV**，无法合理容纳纹波、温漂与瞬态。

R117 改为 **220kΩ / C22961**：过压标称 27.37V，初始公差下最低约 26.38V，距正常输出上界约 1.20V。最高过压阈值可能约 28.74V，**它不是精确 27.37V 钳位器**。核对现有母线后级：LMR16030 工作上限 60V，电解 63V，输入陶瓷 100V，本次选定电容 50V；这些器件可容纳该静态阈值范围。

另计算 ±100ppm/℃、相对 25℃ 最大 65℃ 温差的敏感性：升压约 22.98…25.49V，欠压开启约 20.37…22.64V，过压约 26.05…29.10V。温漂后余量进一步缩小，需在实际器件温度和纹波下检查，不能当作全板所有环境的保证。

## 功能逻辑复核

| 项目 | 结论 |
| --- | --- |
| PD 独立启动 | U101 VDD 来自新 USB 输入，不依赖原 ESP32 或 24V 总线，启动无供电循环依赖 |
| USB 正反插 | CC1/CC2 与对应 dead-battery 脚连接，内部 Rd 负责受电识别；未另外并联 5.1kΩ |
| 不足功率的源 | 在指定 NVM 配置下，只接受 PDO2 20V/3A；不能匹配时保持 5V，负载电源路径不应打开 |
| 输入开关资格 | Q101 由 VBUS_EN_SNK 控制，Q102 由 POWER_OK2 控制；避免只用会在拔线后保持状态的 POWER_OK2 |
| MOS 与二极管 | AO4407A 的 S/G/D 引脚与库匹配，源接上游；齐纳 K 接源、A 接栅；D101 A 接 SW、K 接升压输出 |
| 升压 | TPS55340 采用允许的非同步升压连接；EN 的额定范围允许接 20V；SYNC、AGND、PGND、EP 及手册建议的 NC 接地 |
| eFuse | IN/OUT、RTN、GND、EP 与手册相符；RTN 没有误短接系统 GND；SHDN 内部上拉允许浮空 |
| 多角入口 | TPS26600 的背靠背 FET 用于反向阻断/ORing；不能据此宣称均流、功率叠加或无缝切换 |
| 过载恢复 | 402kΩ MODE 设置为限流后过温锁存；不是一超限就立即锁存，也不是自动重试。需切断该入口输入或拉低 SHDN 复位 |

NVM 必须写入并读回：PDO1=5V/0.5A，PDO2=20V/3A，PDO 数量=2，POWER_ONLY_ABOVE_5V=1，POWER_OK_CFG=2，REQ_SRC_CURRENT=0。没有实际 NVM 烧录/读回或 PD 分析仪抓包，不能把预期协商行为说成已经实测成功。[STUSB4500 数据手册](https://www.st.com/resource/en/datasheet/stusb4500.pdf)

## 尚未闭环的工作条件

### A. 整盘冷启动是主要风险

现有每个模块的 24V 输入有 47µF 电解、2×2.2µF 陶瓷和 0.1µF 电容。若 24 个模块一致，总标称约 **1236µF**；计容差上界约 1472µF，未包括新增布线/其他负载电容，也未扣陶瓷偏压衰减。

220nF 的输出软启动电容，按手册公式得到约 42.6ms，按典型充电电流/增益估算约 46.1ms；并非精确固定时间。典型斜率下，仅给总线电容充电就约需 **0.65A**，高电容情况约 0.77A。1.68A 标称限流并不能同时保证任何启动阶段都有额外 1.5A 给负载。

原 U23 LMR16030P 的 EN 直接接 VIN，约 4V 即可能开始启动，内部软启动典型 4ms。它不会等母线到 24V 再开启。若所有模块在母线 8V 时已经各取 1W，负载总电流是 **3A**，超过该入口约 1.58…1.78A 的限流估计范围，母线不能继续正常爬升，可能掉压或最终热关断锁存。

这是符合“每格最多 1W”约束的失败情景，**不是声称已经观察到实物失败**。实际是否避开它，取决于 ESP32、屏幕、LED、RFID 和各降压输出电容的上电负载曲线。

关闭此项需要测量 24 模块实际冷启动电流，或为每个模块设计经过公差校核的较高欠压启用门槛/上电时序。只把输入限流或软启动电容随意加大不能自动解决恒功率负载问题。每个模块的降压 EN 位于当前授权矩形之外，且还涉及边长模块，本次没有越界修改。

### B. 输入瞬态保护余量不能签核

TVS2200 在指定 40A、25℃ 8/20µs 浪涌条件下最大钳位 28V，与 STUSB4500 高压引脚 28V 绝对最大值相等，没有给走线寄生尖峰留下裕量；另一项高温浪涌测试最高 28.35V，但该测试温度也超过 STUSB4500 规定环境范围，不能把这两个条件直接当作同一工作点。

因此，现图有保护器件，不等于已经保证所有热插拔/浪涌下保护充分。需按实际热插拔波形和温度重新配合输入 OVP/限压或滤波，再做波形验证。普通合规 PD 的 20V 稳态不等于这个浪涌条件。[TVS2200](https://www.ti.com/lit/ds/symlink/tvs2200.pdf)

### C. 环路与热设计还未完成

TPS55340 补偿初值符合参考拓扑，但 3×10µF 陶瓷电容在 24V 下的有效容量尚未实测，输出 eFuse 后还接约 1.2mF 和多个降压负载。必须把这些因素纳入稳定性分析和负载阶跃测试，不能只看本地标称 30µF 宣称稳定。

保守估算 16V 输入、85% 效率、1.5A 输出、输出电压公差上界，输入电流约 2.78A；取 8µH、400kHz，电感峰值约 3.72A，小于 5A 开关设计能力及电感 7.5A 标称饱和点。这只支持稳态选型方向。二极管损耗约为 Vf×Iout，开关、电感和 eFuse 的散热仍取决于 PCB。大电容启动时 eFuse 瞬时耗散需另用 SOA/热瞬态核算。[TPS55340](https://www.ti.com/lit/ds/symlink/tps55340.pdf)；[TPS2660](https://www.ti.com/lit/ds/symlink/tps2660.pdf)；[LMR16030](https://www.ti.com/lit/ds/symlink/lmr16030.pdf)
