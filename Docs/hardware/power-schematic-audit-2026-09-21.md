## 逐段结果

### 1. 角落 DC 输入

`J301 中心正极 → F301 → D301 阳极 → D301 阴极 → 24V_BUS`

J301 套筒接 GND，开关脚不连接；D302 阴极接 24V_BUS、阳极接 GND；C301/C302 接总线对地。没有接反二极管、把插座开关脚当电源脚或将正负极并接的问题。

| 位号 | 型号／编号 | 电气核查 |
| --- | --- | --- |
| J301 | DC-005-5A-2.0 / C381116 | 已选 24V、5A 插座，使用 5.5×2.1mm 中心正极配套插头；厂家针图 1 中心、2 套筒、3 开关 |
| F301 | S1206-F-4.0A / C553923 | 4A、32VDC；名义 60W 总线电流约 2.6A，额定值方向合理 |
| D301 | SS56B / C14651 | 60V、5A；正向串联提供反接/反灌阻断，电压及电流额定值匹配本方案 |
| D302 | SMBJ26A / C152100 | 26V 持续反向工作电压；吸收瞬态，不能用作连续稳压器 |
| C301/C302 | 1µF / 100nF，50V | 直流极性与额定电压适合 24V 总线 |

**24V_BUS 是网络名称，不是这部分产生的精密 24.000V 输出。** 输入为 24V 时，母线会减去 D301 正向压降和连接损耗。以 0.7V 压降举例，母线约 23.3V；60W 取电约 2.575A，D301 发热约 1.80W。实际压降/温升没有在本轮测量，不能仅凭“5A”额定值承诺持续散热能力。

入口应使用稳压、带过流/短路保护的 24V 电源，60W 总线目标至少留到 72W 电源能力等级；电源的启动/限流行为仍需确认。4A 保险丝不是 4A 精密限流器，3A 限流电源也未必能使其熔断。禁止据此宣称支持任意非限流电池输入、持续错接更高电压或多电源自动均流。

本轮读取的物料参数来源：[SS56B 商城规格](https://item.szlcsc.com/15319.html)、[SART 保险丝商城规格](https://item.szlcsc.com/574960.html)、[BORN TVS 商城规格](https://item.szlcsc.com/163440.html)。商城链接的三份厂家 PDF 本轮在线打开超时，未将其记作本轮已完整读取的厂家资料。额定参数同时与现有物料记录核对；本轮未更换或新增物料，也未重新锁定库存。

### 2. 两板 U201 接入保护

`24V_BUS → U24 → HP_RAW → U201 → 24V_BUCK_IN`

- U201 IN/OUT 方向正确；它保护本地降压支路，没有串在下游所有模块的贯通电源中。
- RTN/裸露焊盘和控制阻容接 HP_RTN，GND 脚接系统 GND；原理图没有将二者误短接。
- UVLO/OVP 分压顺序正确，SHDN 保持开路使用内部上拉；不是必须由 MCU 写入配置才能工作。
- FLT 接 U23 EN，R206 从受控输出上拉。U201 启动及故障时先拉低 EN，充电结束后放行降压器。
- HP_RAW 侧 C53=100nF；47µF 与两颗 2.2µF 位于 U201 输出后，主输入电容有受控充电。

| 参数 | 计算结果 | 意义 |
| --- | --- | --- |
| R201/R202/R204 | 220k / 4.7k / 10k | 欠压、过压共享分压 |
| 欠压启动 | 标称 19.16V；约 18.45–20.05V | 后一范围含数据手册阈值、漏电及 1% 初始电阻公差 |
| 过压关断 | 标称 28.16V；约 27.13–29.47V | 在正常 24V 供电附近不会无故触发 |
| R205 限流 | 44.2k；标称 152mA，约 144–161mA | 是保护阈值，不是建议长期贴着阈值运行 |
| C202=1µF | 24V 输出爬升典型约 0.493s | 先给本模块输入电容预充电 |
| FLT 去毛刺 | 对应此电容典型公式约 0.574s | 不能忽略该项而声称插电立即启动 |
| FLT 拉低 EN | 估算约 0.093V | 明显低于降压器关断阈值，逻辑匹配 |

分压初始公差计算未覆盖电阻温漂全部极限；慢启动时间也不是保证的上下限。[TPS2662 数据手册](https://www.ti.com/lit/ds/symlink/tps2662.pdf)支持此种 FLT→下游 EN 的启动顺序及独立 RTN 连接。

### 3. U23 降压器替换

两板实际型号均为 **LMR16030SDDAR / C136648**，不是原来的 P 版本。第 6 脚接 C203=2.2µF 至 GND，和 S 版本的 SS 功能匹配。没有把旧 PGOOD 输出当软启动使用。

- R34=100k、R35=17.8k，对应标称 4.963V；按反馈基准全温规格和电阻初始 1% 公差约为 4.782–5.150V，不含额外动态纹波和路径压降。
- R39=49.9k 对应约 500kHz；不是悬空 RT/SYNC。
- L2=8.2µH；D3 阳极接地、阴极接 SW；C56=100nF 接 BOOT–SW，方向正确。
- 输入两颗 2.2µF/100V 和 47µF/63V；输出四颗 22µF/16V，耐压正确。电感 XAL6060-822MEC 的额定选择没有发现明显不足。
- C203 的软启动典型约 0.55s。SS 电流只有典型值，不能将 0.55s 当作保证的最短启动时间。
- 该器件为内部补偿降压器，目前外部参数与厂家 24V→5V 示例接近；没有做交流环路/瞬态仿真，不能据此给出相位裕量或全部工况稳定性保证。

参考：[LMR16030 数据手册](https://www.ti.com/lit/ds/symlink/lmr16030.pdf)、[Coilcraft XAL60xx](https://www.coilcraft.com/getmedia/ea51f14b-7f32-4dc6-8dfe-d4b70549040f/xal60xx.pdf)。

### 4. 与原有双路 5V 电源选择的衔接

U23 输出仍经原有 U8 接 TPS2121 IN1，调试 USB 的 5V 经 U7 接 IN2，未将 24V 接入 5V 电源选择器。U201 的自动启动不依赖 ESP32 先启动，因此不存在“必须 MCU 运行才能给 MCU 供电”的死锁。输入选择器自带软启动/反向电流控制，不需要 PD 合同或 NVM。[TPS2121 数据手册](https://www.ti.com/lit/ds/symlink/tps2121.pdf)

## 负载与同时启动边界

1. **按每模块约 1W 的原始负载要求，0.152A/24V 支路阈值有余量。** 在输入 20V、限流下界 143.6mA、假设效率 85% 的示例下，折算 5V 侧约 2.44W 达到限流边界；实际运行仍应低于此边界。不能把 U23 型号的“3A”当作整条支路能持续输出 5V/3A。
2. **60W 指整盘在母线取用的总功率，包含本地转换损耗。** 40 板均摊为每板 1.5W；32 板为 1.875W；16 板若强行均摊满 60W 则为每板 3.75W，会超过当前支路的适用范围。因此“16–40 板可用”不等于所有数量下都必须能耗尽 60W，更不等于单个角落可本地消耗 60W。
3. 单块板能自行启动；增加模块后总电流由各负载自然决定。电路没有模块计数器，也没有把整盘自动钳在 60W 的总功率控制器。原有 INA226 测的是本模块 5V 电流，不是整个 24V 环的电流。
4. 40 板的 U201 预充电模型约 0.10A；加入指定电容容差和辅助电流的示例上界约 0.236A。**这个数字只覆盖 U201 后面的 24V 输入电容充电，不能冒充整个冷启动峰值。** 后续 5V 电容、MCU 和其他负载同时开启另需计算/验证；同值延时也不会自动分散 40 块板的启动时刻。
5. 40 个支路同时达到限流阈值，合计约 5.74–6.42A，明显不是 3A 电源保证能承担的状态。保护应对过载，不负责维持过载下正常运行。
6. 新增保护具备本地受控接入能力，但不能证明连接器接触弹跳、地线先后接触、总线瞬间误短接和拔走一段后剩余供电路径均无扰动。这些不属于本次原理图逻辑“通过”的覆盖范围。

## 最终判定

**指定供电部分在正常稳压 24V、单点输入、每板受控负载且整盘不超预算的前提下，电气结构合理，本轮未发现确定的接线、芯片版本或标称设定错误；没有为消除警告而改动原理图。**

本次没有证明最大功率连续温升、环路相位裕量或 40 板同时启动/热插拔的所有瞬态；也不对用户明确排除的 PCB、显示屏和线圈作结论。若要求无负载边界的“绝不出任何问题”，当前证据不足，不能据此签署这种保证。
