```text
J301.3（开关脚）→ NC                     D302、C301、C302 → GND
```

## 供电能力与验收

- 采用稳压且具备过流/短路保护的24V电源，当前选型建议24V/5A（120W），单点给总线供电。60W是负载设计目标，不是本次已经验证的连续能力；端口、铜皮、板间触点及散热仍需验收。
- 24V_BUS不再有升压闭环，电压约为电源电压减去D301、保险丝、线缆和接点压降。60W负载约2.5–2.6A。按0.7V压降估算D301约1.8W发热，需足够散热铜皮并实测；该估算不是温升合格证明。
- 早期24V/3A（72W）仅作为60W目标的起步等级，后续为启动和损耗余量建议24V/5A（120W）；仍须实测适配器启动/限流与温升。120W不是本板额定可输出功率；不要继续引用旧PD方案的67.13W/24.32V等计算。
- 单个角落独立工作无需配置PD。电源按负载自然提供电流，无需数模块改变电压；系统仍有自身静态功耗。
- F301不提供受控上电或主动限流；TVS只处理限定能量的瞬态，不能长期吸收错误高电压。全盘启动与热插拔依赖所选适配器、原U201软启动和布线；原PD环路分析不能证明新方案通过。
- 验收包括空载/单板/60W、最低输入与最远节点压降、满载温升、全部模块同时启动、逐个接入/断开、电源短路恢复。接触顺序、接插件耐流和浪涌尚须实物确认。
- 默认只接一个24V电源。串联二极管防回灌不意味着允许多电源均流或功率叠加。
