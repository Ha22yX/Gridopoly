# Gridopoly 玩家圆屏验收测试

状态：设计基线 1.0

更新日期：2026-08-02

## 1. 范围

本文定义 2.1 英寸 480×480 圆屏 Demo 的软硬件验收标准，并为未来树莓派主控联调
保留协议测试。首版不要求圆屏本地通过完整规则引擎测试。

## 2. 测试环境记录

每轮验收必须记录：

- 圆屏模块硬件版本和设备 ID
- 调试转接板版本
- ESP32-S3 固件 Git 提交
- 资源包与协议版本
- 树莓派或协议模拟器版本
- 供电方式
- 屏幕亮度
- 物理安装和 50°配置
- 测试日期与测试人员

## 11. 规则界面场景

以下场景只验证圆屏表现和协议结果，不证明本地存在规则引擎：

- 无主地产购买和放弃
- 拍卖
- 地租机会和付款
- 完整地区组与建设
- 抵押、赎回和筹款
- 双方交易
- 限制区三种离开方式
- 城市事件和公共基金
- 玩家破产和最终胜利

每个场景必须满足 `player-console-demo-scenarios.md` 的最终页面、焦点和状态摘要。

## 13. 素材验收

- 22 幅地产缩小到 128 px 后仍可彼此区分。
- 五名角色在 96 px 下可通过轮廓和图标识别。
- 图片中没有伪文字、现实品牌或受保护桌游视觉。
- 图片不包含需要动态替换的名称和金额。
- 资产包、字体和元数据总目标不超过 4.5MB。
- 每个资源在清单中有稳定 ID、源文件、设备文件、尺寸、色深和版本。

## 14. 发布判定

以下任何一项失败都阻止 Demo 发布：

- 方向或触摸逆变换错误
- 关键文字或按钮遮挡
- 危险操作能够单击提交
- 重复付款、交易或掷骰
- 现金不足时出现负余额
- Demo 数据进入正式房间
- 两小时测试出现重启或持续内存泄漏
- 协议日志泄露热点口令或完整会话令牌

验收完成后保存测试记录、串口日志、关键页面照片和固件二进制校验值。
