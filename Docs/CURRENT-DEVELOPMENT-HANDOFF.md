## 当前设计与运行规则

- Pi 5是唯一权威。玩家使用认证Wi-Fi/UDP和HTTP素材，格子使用Wi-Fi/HTTP及物理ORDER；RS485预留且未启用。
- long/corner来自显式烧录profile，默认unknown；没有自动形状识别引脚，不能从GPIO13、MAC或COM号猜板型。
- 自动闭环要求全部在线格子（15秒租约）恰好属于同一个有效ORDER环，数量等于当前地图且实际四角匹配。额外孤岛、第二环或旧无ORDER在线模块不能忽略。最小corner moduleId默认START，沿OUT分配；一致锚点可旋转整环。
- ORDER物理帧仍为V1。开链支持分段锚点；已验证环失效会撤回派生。手动锚点仍为内存状态，不能宣称服务重启持久化。ORDER闭环也不表示RS485 A/B可闭环。
- 新游戏冻结1～4台合格在线屏并补足四席；0台或超过4台拒绝。玩家掉线保留席位；新增屏等待下一局。16/24/32/40地图及单块未分配reader可进入配对，不要求完整物理环。
- 配对遵循新鲜空扫描→新单Tag→绑定/拿回→下一人，优先换reader；旧缓存、重复UID、多Tag和过期session不得误绑。已绑定玩家可同时设置外貌姓名，全部准备完成后进入游戏。
- 自动到达由MoveGuide真实首帧后的Action17开gate，目标稳定Tag与手动到达使用同一权威事务。提前在位、重复识别和掉线恢复分别验，不伪造物理输入来制造通过。

接口细节见[闭环与配对契约](firmware/ring-onboarding-contract-2026-09-26.md)和[ORDER协议](firmware/tile-order-protocol.md)。
