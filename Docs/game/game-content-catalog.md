## 1. 内容原则

- 规则机制采用美国经典地产经营结构。
- 名称、角色、图形、卡片文案和城市设定全部原创。
- 玩家角色只承担身份识别，不提供技能或数值加成。
- 当前视觉目录和圆屏主要名称使用英文；下文旧中文命名仅作为内容设计参考。不能用历史本地化目标覆盖实际目录字符串。
- 图片不得包含文字；名称和金额由程序实时绘制。
- 40 格内容库是完整母集，小地图只引用其中的完整子集。

## 6. 卡组结构

当前 Core 两套卡组各有 8 个运行模板，以随机索引选取；不是顺序洗牌/抽顶/回底，也没有可保留脱困卡或卡片交易。卡片文案不写入位图，圆屏按权威 ID/参数呈现。

| deck / catalog ID | 按 index 0..7 的当前效果 |
| --- | --- |
| Chance / 1..8 | +100、-50、前往起点、前往限制区、后退 3 格、-75、+150、-100 |
| Community Chest / 9..16 | +50、-25、前往起点、前往限制区、后退 3 格、-50、+100、+75 |

当前两阶段流程及 wire ID 见 [Wi-Fi/UDP](../firmware/wifi-udp-player-protocol.md)；实际规则见[游戏规则](game-rules.md)。以下每组 16 张的 CE/CF 表是历史扩展内容草案，未进入当前 Core，不得据其宣称已实现特殊租金、保留卡或按人数收付。

每张卡片可组合类别符号、卡组底色、标题和动态金额。

## 8. 资产交付清单

当前可用运行资产为 36 PNG + 36 份 128×128 LE RGB565 格子图、30 GAVC 中性组件及服务端生成的 128×128 最终头像；GAVC 坐标系 220×300。以下母版/图标项是设计交付清单，是否存在仍须对照资源 manifest，不能从清单推断已全部交付。

### 8.1 高清母版设计清单

- 22 幅地产插画，1024×1024 PNG。
- 4 幅交通枢纽插画，1024×1024 PNG。
- 2 幅基础设施插画，1024×1024 PNG。
- 5 个玩家头像和 1 个未认领头像，透明背景 PNG。
- 当前组合头像已使用 30 个中性组件和本地整数着色，历史固定头像保留为素材参考。
- 4 个角落功能视觉和 2 个服务费视觉。
- 8 个卡片类别符号。
- Gridopoly 启动画面与标志元素。

### 8.2 嵌入式版本

- 地产、枢纽和基础设施导出 128、160 或 192 px 版本。
- 头像导出 96 和 128 px 版本。
- 图标使用透明 Alpha 蒙版或 RGB565/RLE。
- 不在位图中烘焙玩家名、地产名、金额或状态文字。
- 资源清单必须记录源文件、导出尺寸、色深、压缩方式和 Flash 占用。

## 9. 命名与本地化

- 玩家可见名称优先控制在 6 个汉字以内。
- 超过安全宽度时省略，不自动换行推动其他控件。
- 协议和存档只使用稳定 ID，不使用显示名称作为主键。
- 英文短代码只在调试、地图编辑和少量状态标记中显示。
- 新地图可替换显示名称和视觉资源，但不得复用 Hasbro 商标、角色或版面设计。
